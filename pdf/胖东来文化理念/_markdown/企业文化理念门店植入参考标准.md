# 企业文化理念门店植入参考标准

自由·爱的路上，让我们携手同行。

## 一、门店主要入口

### 设置内容

1. 经营理念及欢迎拍照的提示
2. 设备设施供应商名录
3. 超市主入口：参访企业需知

### 经营理念及欢迎拍照提示

设置于综合体商场主入口、门店主入口或进入商场后的柱子等明显位置，体现胖东来欢迎顾客参观企业，帮助顾客了解、学习胖东来企业不同于外界企业、开展与分享先进文化技术、管理经验的愿望。

**文字内容：**

我们真诚欢迎：

一、承担零售企业的责任，为社会提供：

- 商品：质量保证、品类全、功能领先；
- 价格：合理、无暴利；
- 环境：安全、温馨、整洁、方便、文明；
- 服务：清晰的售前、售中、售后服务体系，保证顾客利益、社会利益、顾客放心、开心。

二、与生产企业和供应商的合作原则：尊重、合作、服务、共同提升进步；培养品德高尚、乐观、专业的一流供应商；共同承担和分享零售企业的责任和使命。

三、价值的回馈：公平的利益分配体系；造福员工、造福社会；健康发展、培养专业、真诚、乐观的人；积极推动商业品质提升。

我们永远不要忘记：我们追求的不是巨光灿烂、金碧辉煌的人，而是具有高尚情操和社会责任感的优秀的人。

欢迎同行兄弟单位参观指导；欢迎拍照、多提宝贵意见建议；如需帮助请直接找部门主管，让我们相互学习、共同进步。

### 设备设施供应商名录

在入口和设备设施旁展示供应商信息，体现开放、合作与共同提升。

### 参访企业需知

用于超市主入口。胖东来企业文化：**中外先进的文化理念**；企业管理：**科学化、制度化、人性化**；卖场美陈：**幸福生活、钟祥博雅超市商品规划**。开市客、伊藤洋华堂、山姆会员店等可作为更多优秀企业学习的参照；我们希望更多企业在经营健康幸福的道路上，让国家和社会更美好。

## 二、概括类、大标识使用

凝练的企业文化理念主体，主要用于商场外立面、临近建筑体、卖场进口柱子、存包柜、公共区域的过渡；也可用小字体作为配饰文字辅助其他版面。

### 使用语言

1. 自由·爱
2. 爱在胖东来
3. 让城市更美好
4. 创造爱、分享爱、传播爱

### 使用原则

- 存包柜上方位置展示主体。
- “爱在胖东来”LOGO 性质点缀可使用色彩并保持标志性。
- “自由·爱”图标可根据门进的文字调整，此版为标准版。
- 大标识可通过图片辅助表达感受和内涵；出口、入口及停车场、门柱、面屏等适合使用。
- 符合企业文化理念的图片可以自行选择已专业能力进行基础设计，注意版权使用问题。

## 三、独立版面的墙体

适用于橱窗、文化墙、卷帘门、梯口、通道等独立位置，可具体放大一句理念阐述。

### 通用语言与医药适用语言

**文化墙组合固定标准：**

1. 自由·爱
2. 让城市更美好
3. 培养健全的人格，成就阳光个性的生命
4. 优秀的商业不是规模，而是传承幸福和品质
5. 真正的幸福是状态而非心态
6. 爱是自由，不该束缚
7. 让自己的灵魂从束缚中走向光明和个性

进入卖场过程中，二道门或出入口附近通道可用：

1. 做最精髓透明的企业；
2. 我们不只是满足自己的生存，而是像学校一样去引导和推动这个行业向更加美好的方向进步；
3. 我们是创造美的使者，爱和善良永远是我们最大的信仰；
4. 理性品质消费，健康方式生活。

独立区域可根据设计语言搭配其他图案，文字包括：

- 培养健全的人格，成就阳光个性的生命；
- 生命在于释放而非修行；
- 好的企业培养的是工匠，不是工具；
- 用尊重和爱对待工作和生活；
- 心中有桃源，生活处处有阳光。

入口及卖场主要版面可选：心中有桃源，生活才会有阳光；心中有爱，生活处处有阳光；用一生的爱去做自己喜欢的事；一切幸福都是因为爱与喜欢。

医药、餐饮、熟食区域可选：

1. 用匠心才会做出好菜；
2. 自精月华，成就最好美食；
3. 专注做好点点滴滴，至少对得起光阴岁月；
4. 放慢脚步，用心品味当下的幸福；
5. 无论做什么，都要做出一份热爱；
6. 用一生的爱去做自己喜欢的事；
7. 让生活掌握在自己手中，做一个幸福的工匠；
8. 让每个人都享受食物的美好；
9. 感把所有新鲜滋味，都与你分享；
10. 用爱烧制的美食，可以吃出幸福的味道。

### 文化箴言（适配墙体、柱子、卷帘门等）

以下短句可按现场工艺和材质灵活使用：

- 做自己、活自己、心灵高贵、思想自由，活在当下；
- 每一个热爱的时候，都是对生命的一次采；
- 当内心种下自由和爱的种子，生命就像阳光一样释放着充足的温暖和希望；
- 高贵不是盛装下的酷感，而是真诚的自由和精神的富足；
- 生命在于释放而非修行；
- 生活不是为了证明给别人看，而是热爱及分享生命的美好；
- 敬天爱人、利他之心：在不利用他人、不伤害他人、不违背善良的基础上，做自己喜欢的事情；
- 让生活掌握在自己手中，做一个幸福的工匠；
- 让自己永远像鲜花一样盛开，永远释放着美丽；
- 尊重自己，做和阳光一样美丽的人；
- 永远保持一颗善良的心，走在阳光里一路来；
- 纯粹的爱能开出更多灿烂的花；
- 生活的美好不是别人给予的，是靠自己去点燃和创造的；
- 只有思想自由，才会有无穷的想象力和创造力；
- 希望每个人都成为大国、勇敢的释放温暖和热量。

### 摘要引文

文化墙还收录关于生活、自由、金钱、阅读、教育、尊严和人格的引文。核心主题包括：为梦想坚持、做自己喜欢的事、珍惜生命、理性消费、提高认知、善待自己与他人、在自由和爱的道路上成长。

## 四、柱子文化语言使用

### 使用范围

餐饮区、户外及停车场柱子。柱面文字可从下列内容选择；若没有文化墙，首选文化墙语言；若有文化墙，依次使用。

### 餐饮及熟食区域

1. 让城市更美；
2. 没有格心就没有束缚；
3. 放无心之手，没有情之人；
4. 别让腐朽的思想阻碍这阳光的力量；
5. 黑暗给你能量，阳光让你释放；
6. 让生命多点依托，让灵魂多点慰藉；
7. 不走捷径，一点一滴地做人做事；
8. 放慢脚步，用心品味当下的幸福；
9. 让自己的灵魂从束缚中走向光明和个性；
10. 学会经营生活而非满足生存。

### 户外柱子及停车场柱子

以哲人名言为首选，包括：高贵的灵魂是自己尊敬自己（尼采）；真正的成熟是独特个性的形成和自我的发现（尼采）；人类的生命不能以时间长短来衡量，心中充满爱时，瞬间即为永恒（尼采）；卑微的人服从恐惧，高尚的人服从爱（亚里士多德）；事业是理想和实践的生动统一（亚里士多德）；人生最终价值在于觉醒和思考（亚里士多德）；幸福来源于我们自己（亚里士多德）。

## 五、文化长廊

位置较集中、面积较大，适用于卖场内部卫生间通道、长廊或外围墙体等。

1. **假如系列**：把企业当学校，用“苗火计划”系列假如、唤醒假如、做好假如，如何让自己幸福、个性、自由、尊重、尊严、活自己、活当下。
2. **启迪——星空系列**：让我们了解宇宙是多浩瀚，让我们知道什么是自然，让我们明白生命起源及进化的概念，让我们懂得时间的真实和有限，让我们理解人的本性，乐观、自信地把自身美好发展。
3. **中西方文化对比**：共 18 条，涉及餐厅、旅游、对待孩子、对美标准、周末休闲、眼中的领导、汽车、对待问题、心情与天气、排队秩序、意见、人际关系、老人生​​活方式、时间观念、自我观念、聚会、饮食时尚、日浴等主题。
4. **全球最幸福国家**：可使用时结合实际更新文字。

## 六、员工休息室

### 办公区域适用语言

- 自由·爱是我们每一个胖东来人生活的原则和方向；
- 用理性的方式，改变奴性的习惯走向个性；
- 真正的让胖东来成为学校；
- 思想一致才是同路人；
- 不要让欲望大于能力，欲望是一切痛苦的根源；
- 有格局，才会有目标与好的结果；
- 自精月华，知行合一、说你所做、做你所说；
- 好的指挥官能运筹帷幄，懂得用人和培养；
- 站场上要有主者气派，自信而不是自大；
- 我们的增长不是数据的增加，而是幸福值的增长；
- 用呼吸的态度展开自己的人生，让理会始终围绕着世俗，走出外利的澄澈和柔情，真正活出人生美好的一面；
- 人的眼光一定要看得长远，看到事物背后的东西；
- 工作素养：热爱、专业、科学；
- 喜欢做事的人才会去等待；
- 让苦难沉淀成故事；失去也是一种幸福，因为懂得拥有的珍贵；
- 你们会让你们更成熟、更自信。

### 采购业务办公区域

1. 好的商品能真正为顾客带来幸福；
2. 总有特色才能与众不同；
3. 品牌规划生命；
4. 产品设计：实在、时尚、品质；产品文化：自由、温暖、阳光；产品核心：顾客幸福；
5. 最好的营销是真诚。

### 熟食加工

1. 不做厨子做厨师，不为生存为生活；
2. 厨师的“师”为人师表，代表着专业和最高的水平（加工间、餐饮）；
3. 用匠心才会做出美味。

### 员工休息区域

用企业理念思考而非习惯思考；把事情变成好事；放无心之手、爱有情之人；专注和喜欢才会有好的结果；坚持其本领就不会有恐惧和空虚；做人有自信、有思想、有伟大情怀的人；人自私的时候是最丑陋的；抱怨使人痛苦；真正的成熟是培养自信、阳光、快乐的生命状态；失去也是一种幸福；不要只停留在表面，从精神层面和理念层面去理解事物。

员工休息区还列出：理念不是停留在口头上，而是实践在行为上；真正美好的感情是分享而非束缚；不要把自己当成商品；把父母还给父母、把孩子还给孩子、把自己还给自己；希望每个人都成为大国、勇敢释放温暖和热量；不嫉妒、不道德，看到未来；真正的爱是付出而非索取；精益求精、专注细节；不只为钱而工作，而是在把钱什么是生命和精神方向；走出惨怨情绪文化的束缚；希望每个人都成为大国、勇敢释放温暖和热量；学会经营生活而非满足生存；工匠精神；安全第一。
