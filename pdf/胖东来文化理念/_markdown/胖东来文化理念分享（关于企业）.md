# 胖东来文化理念分享（关于企业）

## 企业文化理念

### 企业信仰

自由·爱。

### 企业目标

传播先进文化理念，培养健全人格。

### 企业准则

扬善·戒恶。

| 扬善 | 戒恶 |
| --- | --- |
| 公平、自由、尊重、信任、真诚、阳光、勇敢、正义、博爱、节制 | 虚伪、无知、自私、自卑、贪婪、嫉妒、束缚、伤害 |

## 企业经营理念

### 经营理念

发自内心的喜欢高于一切。

### 经营目标

保障民生、提供时尚、创造品质和幸福商业模式。

### 经营标准

专业的能力、先进的技术、科学的方法、健康的运营。

| 方面 | 标准 |
| --- | --- |
| 商品 | 安全、实用、实在、时尚 |
| 环境 | 安全、品质、方便、文明 |
| 人员 | 真诚、热情、专业、净心 |
| 服务 | 公平、个性、专业、主动 |
| 系统 | 科学化、数字化、智能化、与时俱进 |

## 企业的方向

自由·爱，是我们每一个胖东来人生活的原则和方向。

培养健全的人格，成就阳光个性的生命！

我们不只是满足自己的生存，而是像学校一样，去引领和推动着这个社会向更加美好的方向进步！

给生命和思想补充营养。

周二休息——停下来歇歇。

做企业不是为了名和利，而是启迪社会对人性的思考！

让商业像绘画艺术一样照亮人们美好生活的方向。

有格局，才会有目标与好的结果。

不背负销售的责任，不做促销和宣传，真诚、实在地做好自己。

用心做，让零售更有思想！

工作素养：热爱、专业、科学。

管理者不要把自己当看门人，而是主人。

好的企业培养的是工匠，而不是工具。

精益求精，专注细节。

执行好每一项制度、每一个标准，用爱分享工作与生活的过程。

静心完善细节。

生命在于发挥长处，而非专注修正不足。——胖东来管理哲学

喜欢做事的人不会去等待。

用爱对待你所喜欢的一切。

乐观愉快地践行我们的梦想。

胖东来发展的目的是为了：

- 让我们的生活更加——轻松、幸福、健康
- 让我们的行为更加——个性、阳光、博爱
- 让我们的思想更加——自由、纯净、自然
- 让我们的人性更加——完整、尊重、高贵
- 让我们的工作更加——快乐、专业、价值
- 让我们的生命更加——多彩、品质、美丽

胖东来制定的企业理念和制度，是要用行动落实，向理念的方向进步，而不是挂在墙上的口号。

## 品牌、商品与服务

品牌犹如生命。

让城市更美好。

让胖东来的使命、愿景标准化。

让胖东来的品牌代表着阳光、品质和信任！

让商业像绘画艺术一样照亮人们美好生活的方向。

让我们这里成为商品的博物馆、商业的卢浮宫。

认真把工作向深度进步，一切围绕着顾客满意、社会满意、自己满意的专业化方向努力。

认真做事是一种幸福。

我们的进步不是数据的增长，而是幸福值的增长。

我们追求的不是在这个城市开多少家店，而是让每一条街道都形成一种文化。

### 一个优秀的服务员

他精通专业，也非常尊重商品的价值，一切为顾客考虑，懂得非常尊重每一位顾客，无微不至地为顾客着想，让顾客彻底放心、开心、幸福地消费。希望将来能培养出这样的榜样！

用爱对待商品，因它是有生命的；

用爱对待顾客，因我们是天使；

用爱对待所有万事万物；

因我们是伟大、善良、快乐的人！

用尊重和爱对待工作与生活。

优秀的商业不是规模，而是传承幸福与品质。

战场上要有王者气派，自信而不是自大！

真正的成就员工，是培养员工阳光、快乐、自信的生命状态。

真诚地付出自己的爱，服务好顾客！

专业让工作成为一种幸福。

专注和喜欢一定会有好结果。

总有特色，才能与众不同。

最好的服务是没有售后的。

做玻璃般透明的企业。

做企业是为了让社会更美好，而不是为了证明自己。
