# 胖东来文化理念分享（关于生活）

> 自由·爱

自由·爱的路上我们携手前行。

本篇以生活、自由、爱与个性为主题。以下收录并按内容关联整理原页引语；重复的页眉、页脚标识与纯装饰图像未录入。

## 生命、生活与幸福

- 心中种下什么样的种子，生活就有什么样的色彩。
- 每个不曾起舞的日子，都是对生命的辜负。
- 何为人生——绽放的灵与肉的自由。
- 何为生活——用思想弹出动听的生命的音符。
- 生活不是为了证明给别人看，而是热爱及分享生命的美好！
- 放下脚步，用心品味当下的幸福；个性活好自己的内心。
- 活得简单，生命必定多彩！
- 让生活掌握在自己手中，做一个幸福的工匠。
- 生命的价值在于分享生命中每个阶段应该分享的快乐！
- 生命的真谛是生活。
- 生命因爱而美。
- 生命在于释放而非修行。
- 幸福不是贪婪，而是热爱和知足。
- 真正的幸福是状态而非心态！
- 失去也是一种幸福，因为懂得了拥有的珍贵！
- 理性地面对得与失，知足才会幸福。
- 钱再多也没有用，给你个地球你也带不走。
- 让苦难沉淀成故事。
- 让生命的纯净，纯洁无穷地绽放。
- 让生命多点依托，让灵魂少点庸俗。
- 放下宽度，活好深度，快乐的生活状态才是自己！

## 爱、善良与关系

- 爱让生活更加轻松。
- 爱是自由，不要束缚自己。
- 我们去释放爱，而不是放纵爱。
- 懂比爱更重要：爱一个人不会轻易放弃，爱一个人没有目的、没有要求，只会让对方因你而幸福！
- 懂得爱不违背初心；放无心之手，爱有情之人。
- 敬天爱人，利他之心：在不利用他人、不伤害他人、不违背善良的基础上，做自己喜欢的事情。
- 心中有爱，生活处处有阳光；心中有桃源，生活才会有阳光。
- 心善路宽；善良是为自己留下的路标。
- 品德高尚其实已在分享了天堂的快乐。
- 美——源自于我们那颗纯洁的心灵！
- 精神富有可让死亡变得伟大而安祥！品德高尚其实已分享了天堂的快乐！
- 人在被尊重、被爱、被关怀的时候，智商基本为零。
- 一切幸福都是因为爱与喜欢。
- 因为真诚和专注，所以收获了更多的感动和幸福。
- 永远保持一颗善良的心，走到哪里自己都是一束光。
- 用爱对待你所喜欢的一切。
- 用行为影响身边的一切。
- 用活法影响他人，而不是说法。
- 真正美好的感情是分享而非束缚！
- 真正的男人的魅力，是勇敢、担当、洒脱、自由的象征，是一个可以让人依靠、让人信赖的对象。
- 真正女人的魅力，一定不只是外在的美，而是由内而外散发出来的、最自然的美！
- 尊重和爱是通向个性的基础。
- 尊重生命的时候，就会懂得爱。

## 自由、个性与自我

- 不要只停留在表面，从精神层面和理念层面去理解事物。
- 不敢面对所以复杂；不忘初心做自己喜欢的事。
- 从奴性走向个性。
- 让我们共同努力，改变劣根性与奴性的文化。
- 心灵思想的自由比什么都重要。
- 让自己的灵魂从束缚中走向光明和个性。
- 只有思想自由，才会有无穷的创造力和想象力。
- 还原本真的自己。
- 尊重自己，做和阳光一样美丽的人。
- 做一个有自信、有思想、有伟大情怀的人。
- 明世理，活自己；心灵高贵，思想自由；活在当下。
- 学会让自己低头，看清自己。

## 选择、欲望与方向

- 希望：是努力就能实现的梦想，而不是高瞻远瞩、遥不可及的海市蜃楼。
- 世界是一张白纸，痛苦和幸福都取决于自己如何去描绘。
- 抱怨使人痛苦！别让腐朽的思想阻碍追求阳光的力量。
- 不要让名利偷走了自己的幸福！不要让欲望大于能力；欲望是一切痛苦的根源。
- 不要让自己赢了功利；不要为了证明自己而去做事！
- 不走捷径，一点一滴地做人做事。
- 人的本性——是善与恶共存的状态，关键看你如何选择自己的方向。
- 人的眼光一定要看得长远，看到事物背后的东西。
- 思想一致才是同路人。
- 无论做什么，都要做出一种境界。
- 无论做什么，我们一定要懂得先进文化的发展方向！
- 喜欢做事的人不会去等待。
- 有格局，才会有目标与好的结果。
- 做智慧的先知，生命必定幸福灿烂。

## 成长、磨炼与创造

- 坎坷会让你们更成熟、更自信！没有私心就没有束缚！
- 黑暗给你能量，阳光让你释放。
- 像阳光一样青春灿烂。
- 越艰难的地方，风景越灿烂！
- 只有经历过磨练的人，在面对风雨的时候，才能更坚毅，更伟岸。
- 学到真本领，就不会有恐惧和空虚。
- 一个优秀的民族，一定是在不断的学习和反思！
- 希望每个人都成为太阳，勇敢地释放能量，让生命温暖而灿烂！
- 让自己永远像鲜花一样盛开，永远释放着美丽。

## 对生活的实践

- 学会经营生活，而非满足生存。
- 静心做事，简单生活！
- 真正的快乐不是拿人格去取悦他人。
