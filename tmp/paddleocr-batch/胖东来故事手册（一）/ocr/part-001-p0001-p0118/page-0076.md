# 遗忘的手机

作者：新乡百货保安

拾金不昧的事情在我们胖东来经常发生，但当你拾金不昧遭到误解的时候，你还会坚持吗？我的回答是一定坚持，因为那是我们做人的准则！

那是在去年夏天的一个下午，天气特别热，没有一丝风，站在太阳下，身上就像着了火，衣服也已湿透。这时过来了一辆出租车，我急忙向出租车跑去，准备打开车门迎接顾客（我的工作经验告诉我，因为天气太热，为了能让顾客少受一会儿热，我要站在车旁稍等一会儿，看到顾客付完车费带齐随身物品时再为顾客打开车门）。

“来了哥，胖东来欢迎您们！”我和下车的两位大哥热情地打招呼。他们没吭声，也不理睬我，径直向商场门口走去。当我正要关出租车门时，工作习惯使我看了一眼车座，这时我发现车座上躺着一部崭新的手机。我马上回头喊要进商场的两个顾客：
