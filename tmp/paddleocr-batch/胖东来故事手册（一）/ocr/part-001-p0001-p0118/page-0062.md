# 讲述 胖东来和您 故事

作者：超市部/杨志香

事情发生在我刚调到服务台没多久，距今已三年多了，但每当想起此事，仿佛发生在昨天，时刻激励着我对工作的热情，为顾客服务时发自内心地真诚、亲切。

当时我正值班，一位五六十岁的阿姨提着一箱伊利牛奶到服务台投诉，经询问得知伊利牛奶累计购买送赠品活动，顾客买的牛奶已经达到送床单的标准，而厂家的床单已全部送完（广告上面印有“数量有限送完为止”的标示）。送别的赠品都不满意，阿姨强调购买伊利牛奶就是为了这条床单。了解顾客的要求后，我立即与伊利经销商取得联系，恳请厂家无论如何想办法满足顾客的要求。最后留下顾客的联系方式和地址，几天后准时把阿姨看中的床单送到了家里。

这本是工作中应该做到的，没想到通过这件小事却和顾客结下深厚的情意。阿姨每天购物时都要到服务台来看我，说上几句暖心话，时常叮嘱我要注意身体，还让她的女儿专门从网上打印了一份如何预防整天

坐着工作对身体不利的健康资料，并亲自送到服务台。2006年传说是无春年不吉利，流行母亲为出嫁的女儿送装满鸡蛋的红脸盆图吉利，阿姨得知我母亲已下世时坚持要买个送我，并说我就是她的亲闺女，当时我就哽咽得说不出话来。

这件事情使我更加理解企业理念

中强调的只有真心付出，才有回报，也使我懂得在今后的工作中，只有做到为民服务时像对待自己的亲人，想顾客所想，急顾客所急，我们才能更好地赢得顾客的心，为我们的品牌添彩增辉。
