# 讲述 胖东来和您 de故事 STORY 53>>>

# 编外“导购”

作者：珠宝部/李娜 ☐

6月的一天，一位大姐来到我们柜台上买黄金项链，她来来回回试了十几条项链，我也不停地将项链拿进拿出，并告诉她每条项链的款式特点。挑了半天大姐不好意思地说：“我看着每一条都很好看，挑了半天我也拿不定主意了，真不好意思，麻烦你这么长时间。”我忙拿瓶水给她说：“姐，先喝瓶水，别着急，这么贵重的东西，当然应该慢慢挑了。我帮你选好吗？”最后大姐在我的推荐下，买了一条价格、款式都非常满意的项链。

就在大姐去交钱的时候，来了一对操外地口音的夫妇。他们询问我拉杆箱在什么地方卖，我告诉他们在三楼，他们有些为难的说：“我们对这里不熟悉，你能找个人带我们去吗？”这话刚好被交钱回来的大姐听到了，热情地对那对外地夫妇说：“我带你们去吧，我经常在这里买东西，对这里很熟悉！”说完，带好她的物品，微笑着对我说了声再见，就领着那对夫妇走了，一边走还一边给那对夫妇介绍沿途的环境和商品。

当我再次看到那对夫妇的时候，已经是一个小时之后了，他们不但买了拉杆箱，还买了满满一购物车的土特产和食品。原来那位大姐一直陪着他们当向导，他们被大姐的热情打动了，决定带一些土特产回家带给亲戚朋友。临走时他们感慨地说：“你们胖

我去过很多地方，这样的事情还是第一次碰到，我相信你们胖东来一定会成为沃尔玛一样的超市巨头！等你们到我们湖南长沙开连锁店时，我一定会天天光顾！”
