# 付出让我心里踏实许多

作者：超市部/任利红

去年冬天，我们生鲜区做特价活动，白萝卜一毛钱10斤。当时抢购的顾客特别多。中午活动结束时，一位衣着破旧，拄着拐杖的80多岁的老奶奶来买萝卜，当得知活动结束后，很有些失望。在与她的交谈中，我了解到她是一名孤寡老人，一直靠低保金生活，想买些萝卜回去。听了她的话，一股同情心油然而生。在征得领导同意后，我到后面用大黄袋子帮她实实在在装了一袋，并帮她送到收银台。交钱时，老奶奶从内衣口袋里拿出一个小袋子，打开一层，还有一层，里面用小手帕裹着小香毛钱。看到这种情况，我忙对收银员说：“别收她的钱，我交。”我将钱交给收银员，并帮她将萝卜放在她的一个破旧手推车上。

现在想起这件事，我心里仍有说不出的滋味：面对那些特别需要帮助的人，我们如果拒绝，将会感到良心的不安。而力所能及的帮助了他们，我们心里就会踏实许多。
