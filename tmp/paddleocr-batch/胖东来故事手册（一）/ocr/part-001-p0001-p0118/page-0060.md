# 讲述 胖东来和您 故事

## 石榴情

作者：服饰部/陈秋霞

2004年的冬天特别冷，一天，店里来了一对老年夫妇，说买了一双男式皮棉鞋，因鞋底不是塑胶的，经常渗水，鞋里面很湿。我们的员工接待后说可以维修，夫妇俩非常通情达理，因粘鞋底需要时间，天气又冷，我们就让老年夫妇先回家，修好后我们送到家里去。第二天又是个风雪天，当我们的员工冒着风雪把鞋给这对老夫妇送到家里的时候，两位老人非常感动。事隔一星期之后，老夫妇俩特意赶来，非要当面感谢。当时，我感到非常惭愧，如果当时把这双鞋给退掉，这么冷的天，也不至于让两位老人再跑一趟。我赶紧给两位老人每人送了一套保暖衣，又把棉鞋垫多拿了几双，老夫妇说什么也不要，我们说一定要收下。这不仅仅是我们的歉意，还有无穷的温暖，更是胖东来人的一片心意。

2005年八月十五前夕，两位老人得知我们服饰鞋业大楼要店庆，又特意赶来给我们送来了贺词，更意外的是，他们送来了几对百年石榴树上结的并蒂大石榴！而且每对并蒂石榴上都有一个手工剪的红心

纸，上面写着“同心”二字！老夫妇说：“石榴从开花到结果，他们都天天留意，石榴长大后，他们的孙子闹着要吃，他们都不舍得，说这是给胖东来的大哥哥、大姐姐留的。我当时感动得热泪盈眶……我知道他们送来的不仅仅是对我们胖东来的祝愿，也是他们那一颗真诚的心！老夫妇至今还和我们保持联系，我们就像一家人一样，逢年过节，我们都要把胖东来的福利给他们送去一份。同时也送去了胖东来全体员工对他们的爱！
