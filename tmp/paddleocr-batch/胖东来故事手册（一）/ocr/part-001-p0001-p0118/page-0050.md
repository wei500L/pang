# 讲述 胖东来和您 故事

记得那是一个很热的下午，有一位满头白发的老大娘和一位看上去十六七岁的女孩，在我们特价车前选了很久，可就是拿不定主意到底要哪一双鞋。这时那个女孩说：“奶奶，别买了，太贵了，等我考试完，再买也不迟。”那位老大娘说：“不行，一定要买，总不能让我的孙女穿着旧鞋去考试吧！”说着老大娘小声对我说：“闺女，这双鞋能不能便宜一点？因为我的钱不是太够，如果买了鞋，回家的路费都不够了。”

在和老大娘的交谈中得知，她的儿子和媳妇在一次车祸中丧生，只剩下这个孙女

相依为命，平时只靠政府的救济和捡烂，供孙女上学，眼看要高考了，可总不能让自己的孙女穿着烂鞋去考试吧！“闺女，你能不能给你们领导说一声，便宜一点。”虽然声音很小，但还是被女孩听到了，说：“奶奶，别说了，再说我也要，我不想让您因为一双鞋和别人说好话。”说完眼里含着泪，跑着离开了卖场，可见老大娘这样做伤到了女孩的自尊心，真是一个要强的女孩。
