# 离家的胖东来人

作者：服饰部/袁红洁

在我们胖东来，有一些兄弟姐妹，由于家庭或者其它方面的原因，离开了我们的大家庭，他们在外边工作，生活得怎样呢？相信大家对这一问题都很关心。下面我就讲一个这方面的故事。

前段时间，我下班回家，我家小姑对我说：“我们幼儿园来了一位新老师，她原来在胖东来工作过，因为小孩上学没人照顾，她才离开了胖东来。她分到我们班上了，虽然只有两星期，但我们班的变化可真大。她把我们班的消毒柜、墙壁、厕所、小孩床都打扫得干干净净。我们打扫卫生只是擦表面，而她打扫得那么彻底，以前消毒柜上面我们从来没人擦过，而她每次都把上面擦得干干净净。厕所异味很大，现在她每天放学后都用消毒液冲一遍，再也没那种难闻的气味了。谁也没要求她这样做，但她却每天如此。她说在胖东来上班养成习惯了，上班总是提前到，我们幼儿园上上下下的人都夸你们胖东来人忠诚、勤快、能干。在她来之后，我们班连续两个星期上了光荣榜，园长把我们班作为全园卫生标杆呢！”是啊，虽然一些兄弟姐妹因为某种原因离开了胖东来，但他们把胖东来优秀的企业文化深深记在了心里，并用自己的实际行动去影响着别人，感动着别人，同时为胖东来品牌增添着光彩。无论他们走到哪里，无论他们做什么工作，胖东来所给予他们品质方面的培养教育，将会使他们受益一生……
