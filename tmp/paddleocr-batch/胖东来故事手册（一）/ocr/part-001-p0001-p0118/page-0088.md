# 我有你同样的经历

作者：超市部/寇会杰 ☐

不知不觉，我在胖东来工作已经有五个年头了，这五年的风雨历程让我明白，哪怕是一件小事，只要你认真去做，去想，就会有让你想不到的意外收获。

我刚调入建安店不久，一天晚上下着小雨，快要下班时，有一位大姐抱着个孩子急匆匆地来到我们店，身上的衣服都被淋湿了。她焦急地对我说：“妹子，给我拿件补品吧，就是有营养的牛奶，孩子的爷爷有病被送进了医院，到现在还没有吃东西呢。”于是，我就给大姐介绍了袋装纯奶，既营养又实惠，大姐听后非常满意。等大姐付账时，“哎呀，因为出门走的太急，钱包忘记带了！”我想起她刚进来时着急匆忙的样子，不禁就想起我的父母因为一次意外出了车祸送进医院，当时没有钱着急的情景，于是，我二话没说，就从钱包里掏出钱给位大姐交上了。当时大姐说啥也不肯，非要回家拿钱去，我对她说，等你把钱拿回来时我们早就下班了，你赶快拿上牛奶去医院吧。

无论是哪位员工，看到这情况，都会这么做的，只要顾客来咱们店，就是对咱们最大的信任，无论什么原因我们都应该让顾客满意！

过了四五天，这位大姐又来到我们店，对我说：“爷爷的病好多了，今天我是来给你送钱的，真的谢谢你！”这件小事让我明白，我们一点真诚的付出，就会让顾客快乐，顾客快乐的同时我们收获了更多的快乐！
