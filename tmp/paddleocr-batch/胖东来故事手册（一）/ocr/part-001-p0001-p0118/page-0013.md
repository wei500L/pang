# 讲述 胖东来和您 de故事 STORY 07>>>

# 心灵的触动] 作者：服饰部/何广辉 ☐

我们店前段时间分时段销售特价袜子，限量每双5角钱，因为卖得特别便宜，每天早早地就有许多人排队。记得那次我在特卖场维持秩序时，发现一位大姐在加队。我过去对她说：“大姐，请不要加队，谢谢合作。”大姐一听不高兴了，大喊道：“你怎么那么多事啊，与你有仇啊！”我笑着说：“大姐，咱俩没仇，但是你看看后面还有那么多老年人在排队，这样做不太好！”这时队伍中的顾客也对她纷纷指责，她生气地说“不买了”，然后又对我说：“你有啥了不起的，不就是个破保安吗，看门狗！”说完她扭头走了。我当时气得涨红了脸，一句话也说不出来了，心里好似打翻了五味瓶。
