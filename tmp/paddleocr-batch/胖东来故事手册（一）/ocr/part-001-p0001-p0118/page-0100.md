# 不能辜负顾客的信任

作者：燕晓峰/胖东来电器

今天上午在卖场值班时，有位顾客大姐向我反映说她家里有套全进口爱华组合音响，因为不会使用，让我们派人上门教她怎样操作（说明书和面板按键全是英文）。顺便借用一下店里的小电视试试有线电视信号。因为是购买亲戚家的二手房，自家的29寸彩电搬上六楼不方便。我告诉大姐：音响可以上门帮忙调试，小电视属于商场内销售的商品，按规定是不能借用的。“要不我压这里两百块钱，把你们的样品机带回去试试，再还给你们。”大姐看着我为难的表情，用商量的口气说。我简单考虑了一下说：“这样吧，你先购买小电视，一百五十元钱，我上门调试的同时，直接办理退货，把退货款一块给你送去，这样也符合商场手序。”大姐点头同意，我留下她的电话号码并约好下午一点左右联系。“没事儿，相信咱胖东来。”大姐先走了，没有要任何相关手续。

中午十二点四十分，我与用户取得了联系。在收银台办理退货后，拿着钱提着小电视向用户家走去，用户家在七一路上，眨眼功夫便到了。把退货款递给用户后，先试过电视，再把音响接线联机，随后教她使用方法及注意事项，直到她学会为止。

从用户家回来的路上，我边走边想，今天这趟上门服务，我们商场没有销售任何商品，我们只是仅仅得到用户一句谢谢。昨天，店长在给我们全体员工开会时，多次强调要让每一位用户满意，要像雷锋那样做好事。我们与用户之间不只是建立在买卖关系上，而是要成为真正的朋友，甚至是亲人关系，我们要努力成为用户可以信赖的人。只要是用户有困难需要帮助时，首先想到我们胖东来就足够了，而我们胖东来人也决不能辜负顾客对我们的信任！
