# 咱们都是胖东来人

作者：服饰部/任丽娜

一个阳光明媚的上午，我提着工装急忙打的上班。出租车司机是一位和蔼可亲的大姐。“姐，我到生活广场，能不能开快点！”“急着上班吧！在车里你先把工装换上，下车就可以签到了。”我怎么没想到呢？真是位善解人意的大姐，我把手机放在了车上。从谈话中得知，大姐以前也在胖东来工作，因家中有事离开胖东来三、四年了，很怀念在胖东来工作的日子。

刚换好衣服，就到了生活广场门前，我赶紧下车跑到收银台一看，还提前20分钟手一摸口袋，“呀！糟糕，手机忘车了。”我急忙跑到门口，可那辆车早就没影了，那可是我新买的手机呢？刚用没多久，想到这些，我的心扑通扑通直跳，垂头丧气的走回收银台，想到那位大姐亲切的笑脸，于是便试试拔了手机号码，没想到通了。我刚说明原由，便听到大姐说：“你现在在门口等我，我马上给你送过去。”听到这些，我简直不敢相信这是真的。我走到门口，看见了大姐的车早已停在了门口，我接过手机，激动地不知说什么好，只是一个劲的谢谢。大姐笑着说：“没事的，小妹，别忘了咱们都是胖东来人！”
