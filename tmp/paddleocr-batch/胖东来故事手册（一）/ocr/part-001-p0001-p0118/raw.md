# 讲述 胖东来和您 故事

作者：新乡百货/崔天伟

我出去送货已经不是第一次了。但今天的送货，又让我想起去年那个炎热的夏天和我那火一样被烧疼的心。

有一对年轻人，在我们那里订了饮料和酒，让去送货，公司的车外出送货了，我只好把货搬到外面装在出租车上，几十件东西把车装得满满的。我把货按照顾客留的地址送了过去，到了以后给顾客打电话，顾客家在六楼，我把货物一件一件往楼上搬。当我气喘吁吁地把货搬到六楼时，发现门口有一双拖鞋和一盆水，那位大姐对我说：“唉！把脚洗一洗，再穿鞋进屋！”以前我出去送货，口袋里装两个袋子就是为了方便顾客，但没有像今天这样的待遇，我洗吗？货已经卸在楼下了，我已经可以走了，可想想咱们的经营理念：“保证让每一位顾客满意！”于是我把鞋脱掉，认真地洗了洗脚，把货从楼下搬到楼上，然后洗脚，换鞋，前后搬了十几次，洗脚也洗了十几次。几十箱货物从上午的10点多一直搬到下午的1点多，搬完最后的一趟，身上的衣服早已经湿透了，看着摆得整齐的饮料，大姐说了一声：“谢谢！”我说：“这是我们应该做的。”临走时我把那双拖鞋洗了洗还给顾客，然后对她说：“欢迎你们常去胖东来。”回来的路上我想了很多，也为大姐的这种行为感到理解。



一年后的今天，大姐的丈夫又来找我

一年后的今天，大姐的丈夫又来了，满脸的高兴，因为他要做爸爸了，来订东西，我很高兴。虽然当时自己心里感觉不舒服，但顾客至少已经通过服务认识了我们，认识了胖东来。

## 秘密

<!-- PDF page: 8 -->

作者：超市部/杨彩娟

“对不起，能听一下我们孩子的道歉吗？”一位三十多岁的女顾客对我说。她的身边是一位六七岁左右的小男孩，男孩神情显得很紧张，嘴巴像贝壳一样闭着，眼睛只是看着地面。母亲以严厉的口气说：“快点，阿姨很忙！”我感到气氛骤然紧张起来，到底是什么事情呢？

我一边猜想，一边仔细看这母子俩。这时我发现那男孩手中握着什么东西，而且小手有点颤抖。“怎么了，说话呀？”母亲眼里噙满了泪水，这时男孩终于哭了。我的心仿佛被猛戳了一下。我又一次面向孩子，我想我必须要听他说句话，我甚至觉得这个瞬间可能会左右孩子一生。这时，他很不自然地伸开了手，被揉搓得破烂的包装中露出了小孩玩具，那是件很受孩子欢迎的玩具。“我没想拿，我不是故意的。”他费了很大力气才说了这句话。最后孩子几乎是泣不成声的说了声：“阿姨，我今后一定改。”那位母亲终于松了一口气，她红着脸对我说：“你们经理在吗？我想向他解释一下。”此时，我第一次懂得了母亲对孩子深深的爱，教育子女的不易，理解了一位母亲的良苦用心。“不用

了，我帮您把钱交了，这件事就作为我们的秘密，孩子也明白自己做错了，这就够了。”虽然只说了几句话，可我的眼泪已流至面颊，临走时那位母亲几次向我道歉的身影，我永远难以忘记。

## 喂 奶

“小妹！你不认识我了？”一位大姐领着一个两岁左右的男孩，面带微笑地对我说。我一脸惊异。“你忘了，你还给我的孩子喂过奶呢！”“噢，想起来了，小家伙长得好结实呀！”我开始与她聊起来，就像久别的朋友一样亲。

这件事已经过去两年多了，那时我在电梯口工作。那天，我推着购物车刚出电梯口，突然听到“哇哇”的啼哭声，我看到一位刚做父亲的大哥正抱着孩子站在那里。我立刻跑过去，对这位大哥说：“小孩饿了吧！”他连连点头：“孩儿她妈进去买奶粉了，进去好一会儿了也没出来，孩子又饿了。”说着说着，小家伙在他怀里更不听话了，哭得小嘴都有点紫了。我心疼得不得了，说：“让我给你抱会儿吧！也许会好一点，我也是刚做妈妈的。”不知为什么，孩子在我怀里不怎么哭了，我就问：“你爱人叫什么名字？我可以通过店内广播找人，让她快点过来！”他告诉我后，我通知播音室广播。可能是小孩饿坏了，又一次大哭起来，他的哭声就像在抽我的心。和大哥打声招呼后，我抱着孩子来到我们更衣室的小屋，开始给孩子喂奶，看着孩子大口大口吃奶的样子，心里踏实多了。孩子小，不大一会儿就吃饱了，小眼睛眯成了一条缝，渐渐地睡着了，我抱着熟睡的小宝宝，来到电梯口，看见了那位大哥和大姐。我说：“姐，我刚给孩子喂过奶，他睡着了！刚才你没回来，小家伙哭得不得了，可让大哥难为坏了。”大哥，大姐不善言语，只是一个劲儿说谢谢。



<div style="text-align: center;"><img src="imgs/img_in_image_box_244_855_594_1249.jpg" alt="Image" width="29%" /></div>


现在，我已换工装了，没想到这位大姐还能认出我。我想我们在工作中，无论大小事都要诚心对待顾客。其实，在你感动了顾客的同时，顾客所给你带来的快乐，也是意想不到的。

善待自己的工作，就是善待每一位顾客。

# 千里之外的感动

作者：宣教部/营凯歌

“太意外了，我真的不敢相信你们会跑到阳泉来。”她激动地说，“我真的不敢相信你们这么重视，为了一瓶小小的香水跑了这么远的路。”

这个女孩儿叫郭芳，家住山西省阳泉市，7月4日和朋友一起到许昌，在生活广场买了一瓶香水，第二天到家后因为办事送给一个要好的朋友，可当朋友打开盒子时却发现瓶子是空的，让她非常尴尬也非常气愤。在胖东来包装袋上发现电话号码后，立即拨通投诉电话反映问题。

7月5日晚客服部接到投诉电话后，立即向顾客道歉，完全按照公司的理念处理，千方百计让每位顾客满意，不折不扣地兑现我们的承诺，并按照公司规定，赔偿顾客500元钱。公司于总得知后，说不论哪一位顾客，不论有多远，我们都要给她送去，哪怕是美国我们也要想办法给她送去，坚决不能让顾客失望，并安排专车登门道歉。7月6日早上5点，我们带着于总的嘱托和胖东来人的真诚出发了。

经过8个多小时的路程，当我们把鲜花和礼物送给她并真诚地道歉时，女孩激动得落泪了。她的家人和朋友都很吃惊，不相信会有这样的“傻子”。女孩的家人说：“真想不到一件小小的客诉却引起了你们公司这么大的重视，我们全家不知该说什么好。”最后他们说什么也不收这500元赔偿金。我们说：“你们一定要收下，这不仅是我们公司的规定，更感谢你给我们提出了宝贵建议，因为我们工作的失误，让你受了不少委屈，感谢你给我们改正的机会，让我们不断进步。无论顾客是谁我们都会这样做的，我们相信任何一家企业都会这样做的。”郭芳说：“你们的诚信太让我感动了，相信你们的企业一定会做得越来越好。”她迅速打电话告诉她的其他朋友这件事情，说她很感动，并盛情挽留我们在她家吃午饭，我们婉言谢绝了。她还希望我们到她们山西开店，因为她们那里超市有很多东西买不到，价格也贵，买东西时一个袋子就要3毛钱。如果我们去开店，她第一个就来报名。看到女孩满意的笑脸，我们的心里涌起一阵阵感动，更感到一份沉甸甸的责任……付出其实是一种快乐，舍得其实是一种美德，让我们共同努力，让商业为更多人带来快乐！

# 平凡创造感动

作者：新乡百货/赵新平

工作中每一个岗位都很平凡，但在这平凡的岗位上却闪烁出不平凡的事情！在平凡中创造着无数的感动！

王锡芳，是我们胖东来百货三楼的一名普通保洁员，每天都能看到她微笑着忙碌于自己的工作当中。这让我不禁想起前几天我去洗手间时，看到一位大爷扶着一位大娘走过来，锡芳姐看到后赶快上前搀扶住，笑着说：“来了。”然后很自然地扶着大娘进了洗手间，帮她把裤子脱掉，等她方便完后，锡芳姐又像女儿一样帮她擦了屁股，又帮她穿好裤子。然后将大娘扶出来交给那位在外边等候的大爷。“锡芳姐，她是你母亲吗？”她笑笑说：“不是。”“那一定是你家亲戚了？”“也不是。”锡芳姐又笑了笑。“那你为什么对她那么好？”锡芳姐这才不好意思地告诉我们：他们是一对老顾客，时常到我们商场来逛逛。儿女们都在外地工作，不在身边，老伴得了偏瘫，行动很不方便。他们每次来的时候，锡芳姐都会毫不犹豫地帮助他们。每次大娘都很不好意思，但每次锡芳姐都会笑着说：没事，你就把我当成你的女儿一样。王锡芳的话很普通，很真实，引得周围的人都向她投来敬佩的眼光，这眼光中不仅有敬佩，还让我们看到了一个充满爱心的天使，她用爱心温暖着这对老人，同时也温暖着身边的每一个人！

付出就会让自己快乐，懂得感恩才会有更美好的未来！我们为锡芳姐感到骄傲，更为胖东来人感到自豪！我们要从自己身上找出不足与差距，更好地为顾客服务，真正做到让每一位顾客满意。

# 母亲的话语

作者：超市部/王磊

母亲离我远去已将近两年时间了，每当想起母亲，总会想起她临终前告诉我的那些话语，其中包含了太多母爱，也包含了员工家属对胖东来浓浓的情意。

在生活广场刚开业的那段时间，我被调到业务部门。一天晚上，母亲拉着我的手说：“孩儿啊，公司把你调到业务上，这可是对你的信任啊！你可一定要操着心干，再苦再累也要挺下去，可不能辜负了人家，家里事你就不要操心了。”那时母亲已经是癌症晚期，刚做完第二次手术。母亲的话语让我意识到如果不干好工作，不但对不起公司，也对不起母亲的期望。

在那段时间里，母亲一直默默用爱在支持着我，激励着我，给我一种无形的力量。有时回家已经很晚了，可母亲仍在等着我，问我工作上的情况。一天晚上，当知道公司让我采购蔬菜及肉类食品时，母亲说：“你以前没干过这些，可千万别买了不好的东西，要多操心，别买贵了，买亏了。妈以前干过业务，要不妈早上陪你一块儿去进货吧？”听着母亲那虚弱的声音，我强忍住泪水对母亲说：“妈，你放心，我不会让你失望的。”我感动的已不仅仅是母亲的爱，更是她对胖东来的这份心，这也是代表着所有员工家属对胖东来的心啊！

如今母亲走了，永远地走了。但她老人家的话语却深深印在了我的脑海中，让我明白：该用怎样的心态去对待工作，对待我们的胖东来大家园！

# 班长教我怎么做

作者：服饰餐饮/李晓颖 ☐

一件看似普通的小事，却让我懂得了怎样用真心去对待顾客。

中午正值吃饭的高峰期，像平时一样，顾客们排起了长队买饭。只见一位中年男子从长队中走出，刚把端出来的热干面放在南边的桌子上，可不知怎的，只听“砰”的一声，这碗还没来得及吃一口的饭已经洒了一地。周围的眼神也在刹那间齐刷刷地转向了他。尴尬的他此时也不知道如何去应对这一场面……这时我们的班长走了过来，面带微笑地说：“哥，没事吧，让我们再给您做一份！”班长边说边把餐巾纸递给了这位大哥，又迅速清理地上的饭菜，不到两分钟的时间，一份热乎乎的热干面就端到了顾客的面前。一时之间，顾客也不晓得该说些什么，只是憨憨地笑着说：“谢谢，谢谢……”周围人的眼光从中年男子身上转到了我们班长身上。那目光中有肯定，有称赞。

作者：超市部/马慧茹

年前，我们散装区来了一位憨憨实实，非常能干的新员工，名字叫赵亚军。一件展现新员工风采和让人可敬的事就发生在他的身上。

2005年春节前夕，店里派我联系团购。当时我的第一目标单位是位于经济开发区的XX公司。因为客户较大，好多企业和我们竞争，而我没有任何的关系，一次一次我在门外等负责人给我报价和表明身份的机会。几次之后，负责人陈总终于肯见我了。当时天冷雪大路滑，我一个人骑着摩托车，前后用了差不多8天时间，不知去了多少趟，苍天不负有心人，终于这次团购谈成了。

拿到订单那一刻，我流泪了，真的好自豪，是胖东来这个品牌给我自信，给我展示自我的机会，这是对我的认可，更是对胖东来的认可。货是订下了，可送货任务更是艰巨和紧张，距离他们员工放假还有4天，陈总要求必须在他们放假前将所有的货送齐。他们订的货是面粉560袋，糖果560桶，瓜子560袋，挂面560箱，油560桶。当回到店里准备要求送货时，看到大家都很辛苦，我真的很不忍心调出任何一个人为我帮忙送货。于是我联系到一个经销商帮我把货送到单位卸下，当时天很冷，风刮着，正在下的雪吹到脸上，生疼生疼的。当我卸货时，我的衣服都湿透了，用了整整3天的时间，才一趟一趟地把货卸完。因为春节忙，送货车都提前走，开发区比较偏远，车不好叫，所以每次我总是步行到工农路附近才能坐到车，基本是一天4趟。

卸货走路，热得出汗，冷得发抖，这一冷一热，我在一天中全部经历了，第三天的时候已经是下午2点多了，我还没空吃饭，实在坚持不下去了，好想打电话让店里帮忙，但是想想临近春节，大家都在各自的岗位上忙，店里调出来任何一个人都将很紧张，人手就又不够了，咬咬牙休息一会儿，吃完饭一直坚持到晚上7点多，终于把货卸完了。看着他们满意的表情，我松了一口气。陈总握着我的手说：“小伙子，辛苦你了，想不到胖东来一名普通员工就能做出让我们560名员工满意的事，非常感谢，你们的服务我们会记住的。”听了这些话，疲劳，寒冷都没有了，我知道我做的一切都值得了。当陈总得知我每次是步行回去的时候，非要开车送我。我知道是我胖东来普通员工的身份深深打动了他，我握着他的手说：“谢谢，陈总，但我们有规定的，这一切都是我分内的事，只是希望你能对我们的服务满意，并且多给我们服务的机会。”

从那以后，XX公司的福利订货，陈总都来找我。2006年春节，他们又在我们店订下福利，并且为我们介绍了别的单位，我知道这些成果源于我们一点一滴的服务，源于我们胖东来形象在他们心中根深蒂固。

这是我这么多年工作中很平常的一件事。我是平凡人，但我深深地感觉到平凡的工作岗位上，只要我们用心去做，用心为顾客服务，就能和顾客之间建立起心与心的桥梁，愿我们

都用心，让我们的家园更完美。

一副小小的鞋套，教我明白一个做人的道理。看到这里，你肯定要笑了，一副普普通通的鞋套，有什么大不了的，别急，听我慢慢道来。

我是电器售后的一名员工，经常上门为用户维修各种电器。在我们公司的服务规范中，要求我们进用户家门的时候，都要在鞋上套一双鞋套，以免弄脏用户家的地板。虽然我也认为这样做是对的，可每次实际操作的时候，总感到心里有些怪怪的——在脚上套个塑料袋，感觉有些低人一等。直到有一天，在我上门服务时遇到了一件小事，才彻底改变了我的认识。

天气炎热，空气中没有一丝风，我去东城区一个乔迁新居的用户家维修煤气灶。到达用户家中时，见到一位大伯正在那里忙碌着，家人都去买东西了。屋里新买的家具杂乱地堆放着，大伯满头大汗过来招呼我。他们家是新装修的：洁白的墙壁，锃亮的木地板，我伸手拿出鞋套，准备套上进门。大伯连连摆手说：“不用了，不用了，刚搬完家具。”然后指了指踩了很多脚印的地板，但我还是坚持套上鞋套，并给大伯解释说：“鞋底容易划伤地板。”

大伯的煤气灶是新买的，经过简单的调试就可以正常使用了。大伯满意地笑着说：“谢谢你啦，要不是我中午没法儿做饭了。”我连忙说：“不用谢，这是我的本职工作。”大伯犹豫了一下，拍着我的肩膀说：“小伙子，能帮帮忙吗？”我欣然答应。大伯家新买的家具摆得有点儿乱，家具公司的人送到家中就走了，大伯年纪大了，搬动起来有些困难。大伯是个开朗的人，我们边干边聊。大伯直夸胖东来员工素质高，我谦虚地说：“我们做得还很不够，别的商场服务也不错嘛。”大伯摇了摇头，指了指脏兮兮的地面，又指了指沙发旁边的墙壁，只见新粉刷的洁白的墙壁上赫然印着一个黑色的手印——那是搬沙发的师傅不小心留下的。我帮大伯出主意想办法，找来一块装修剩下的细砂纸，小心地打磨后，黑手印逐渐隐去。

经过一番忙碌，我们都累得满头大汗，互相看着都开心地笑了。我感觉我们的距离很近很近，似曾相识，大伯就像我的亲人一样和蔼。

在回来的路上，我的心情很好。我领悟了一句话：把快乐带给别人，你自己将更加快乐。假如我不套上鞋套，像别人一样进屋，不注意细节，我和大伯之间会那么容易沟通吗？其实并不是简简单单的穿鞋套，而是通过这个细小动作，表达了我们对于别人的尊重——对别人劳动成果的尊重，对别人家庭的尊重。把别人的家当成是自己的家来爱护，怎么会得不到爱的回应呢，怎么会不使我们的工作事半功倍呢？同时我们不也在工作中找到了快乐，找到了成就感吗？

之后，在每次上门穿鞋套时，心中那种怪怪的感觉荡然无存。我穿鞋套的动作认真而坦然，我认为那是我美好工作的开端。

# 一件紧急要货

作者：配送中心/曹松强

6月份的一天上午，我正在卸车，忽然接到一门店员工的电话，询问我德庄特级火锅料有货没有？我告诉她昨天晚上货已经回来，上午刚办完入库手续，现在可以打货。她急切地对我说：“有一位老客户急需一件300克特级火锅料，现在我把急货单给你传过去，一会儿我们店的车就去拉。”

接完电话，我赶紧跑到电脑室去拿急货单，电脑员说单据还没有传过来，我又转身回到调料库，从货架上扛出来一件火锅料先放到库区门口，等店里车一到就可以快速装车。又过了十几分钟时间，我又去了三趟电脑室，都空空而归，并且也没有看到这个门店的员工和拉货车的影子。心想：难道情况有变化，顾客不要货了。我急忙给这位员工打电话询问情况，这位员工在电话中既着急而又无可奈何地告诉我：他们店的电脑这会儿反应太慢，单据无法传过来，而且店里的车出去送货到现在还没有回来，顾客已经等不及了，问我库里有没有车，能否把货先给她们送过去。原来如此，我告诉她：“货我们想办法马上送到，等你们收到货后再补办手续。”

我迅速来到送货处，准备向司机班长说明情况，不料今天上午因为货多，司机班长也开车送货去了。这时，经理王红伟走过来，问我有什么事。我向他说明了情况，他听后马上说：“把货准备好，我去找车。”库里一共有四台送货车，有三台车司机已经开走送货去了。剩下的一台车里面货也装得满满的，红伟正想让我去对面大路上找辆出租车，这时刚好碰到库里那台送冷冻食品的保温车送完货回来，红伟二话没说，火速钻进驾驶室，亲自开车送货去了。

等红伟送货回来，我才知道因为店里一直找不到车，红伟开车又跑了20多里路把货一直送到这位顾客家里，顾客很是感动。事后店里这位员工也给我特意打来电话，向我表达了真诚的谢意。

从这件事情上，我受到了很大的启发：无论公司哪一个部门或是哪一个门店，在顾客眼里我们都拥有一个共同的名字——胖东来。让每一位顾客满意，也同样是我们每一位胖东来人的共同追求和责任。我们配送中心虽然是超市的大后方，每天很少有机会与顾客接触，但如果我们能够一心为门店着想，时刻树立服务意识，也就等于让顾客满意，你说对吗？
