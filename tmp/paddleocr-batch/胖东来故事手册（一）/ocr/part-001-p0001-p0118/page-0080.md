# 难忘雨中情

作者：杜文育 ☐

6月2日傍晚7时许，在许昌市跑出租车的李相军，开着面的回家。半道上，一辆机动三轮车突然转弯，他急忙踩刹车，打方向。下雨路滑，加上路面一层麦秸秆，面的滑出十多米后，轰然一声侧倒在地，他的左臂，左肋被破碎的玻璃扎伤。

受伤的李相军，从车尾爬出，站在路旁开始拦车。雨，哗哗下着，左臂钻心的伤痛阵阵袭来，鲜血顺着手指和着雨水快速流下。一辆车过来了，他抬手求救，该车一看出了车祸，加速而去。又一辆车过来了，减速了，当看到浑身是水是血的伤者时，又一加油门离去。三四辆车来来往往，但没人停下来。此地点在许昌至繁城的公路上，距许昌约5公里，前不着村，后不着店。

天越来越黑，雨越下越大。他心中的希望越来越小，当一辆车从北面开过来时，他已懒得举手求助。这辆车在他面前停下，车门打开，下来4个小伙子，其中一个问道：“需要帮助吗？”几乎熄灭的希望之火，在李相军的体内腾然而起。4个小伙子脱下鞋，踏着泥水，把倒在地上的面的抬起，并安排一过路的村民看管。之后，他们（转下一页）
