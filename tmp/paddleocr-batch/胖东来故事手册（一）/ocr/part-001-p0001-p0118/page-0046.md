# 我为顾客当红娘

作者：企划部/张伟芳 ☐

在五一量贩的那段快乐日子里，我曾为一男一女做过红娘。

那是个满世界都飘着宝石绿的季节。人们的心情也像绿宝石一样熠熠生辉。某一天上午，我接到一个陌生女士的电话。我并不认识她，但她却说找我：“听说胖东人不光竭尽全力帮助顾客购物，而且还在生活中帮助顾客，您能帮我一个忙吗？”就是这句话，让我当了一次红娘。更贴切地说是“电波红娘”。这位女士姓王，她有个好朋友，即将与男友走进婚姻殿堂。但此时风云乍起，一对将要相依为伴的伴侣发生了矛盾。而且已不遥远的婚期变得遥遥无期了。今天是他们分手的日子。作为好朋友，这位女士想最后为他们尽一份朋友之力。她请我在中午12点为她的朋友在店内广播处点一首歌，因为她的这位朋友和男友经常来五一量贩。我被这位王女士感动了，她并不了解我，只是每周六，周日晚在文艺活动中见过我，但是却选中了我作为“祝福使者”。根据她的要求，我首先向她的朋友打了电话。

告诉她中午12点有好友为她点歌，歌曲的名字叫《真心真意过一生》。最后，我对她说：“有人曾说过，大街上与你擦肩而过的那个人，你们前世修了五百年的缘，你与他亲密无间，该是修了多少年的缘啊！”

事后两天同一时间，我又接到王女士的电话，她告诉我她的朋友与男友重归于好了，谢谢我的《真心真意过一生》。
