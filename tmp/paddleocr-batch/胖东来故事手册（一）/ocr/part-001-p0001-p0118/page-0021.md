# 讲述 胖东来和您 de故事

作者：禹州电器/卢明星

从刚开始顾客对我们持怀疑态度，购物时提出即买即送，跟车送货，货到付款等要求，到现在购物时的完全放心。这一切的变化，凝聚了禹州店兄弟姐妹太多辛勤的付出，其间所发生的故事也让人深为感动。

记得刚开业不久的一天早晨，大雨刚停，一位来自鸠山的顾客在我们店购买了一台彩电，要求当天送货。虽然雨后的山路很不好走，但为了让顾客满意，我们还是早早安排了车辆送货（鸠山一带全是山路，路窄拉煤车多，下雨天满山泥泞）。正常情况下，到鸠山5个小时就能回来，可到了下午5点多钟，送货车仍未回来，司机的电话也打不通，我们急得团团转。6点多钟的时候，司机打回来电话说：“这里手机没信号，车陷在泥里走不了，我跑了五里路才找到这个电话，你们来车接吧。”听到这个消息时，我们心里很不好受。当我们经过艰难的行驶到达那里时，被眼前的一幕惊呆了：只见司机师傅像个泥人似的光着上身蜷缩在角落里，再看看车停在两米多高的桥上，再往前滑一点后果不堪设想。司机师傅说：“路太滑，离顾客家还有2里路，实在上不去了，我背着电视送到了顾客家……”100多斤重的电视机，我们无法想象他是怎样一步一步背到顾客家里的。借着灯光，我们看到司机师傅肩上磨破了皮，此时每个人都低下头沉默不语，泪水夺眶而出。
