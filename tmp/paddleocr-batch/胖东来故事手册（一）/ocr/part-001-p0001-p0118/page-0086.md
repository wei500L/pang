# 讲述 胖东来和您 故事

作者：服饰部/李冬冬

那是一个周一的上午，因为是周一所以客流量比较小，我正在厅内打扫卫生，忽然听到一位顾客问我洗手间在哪儿。我一抬头猛然发现她竟然和我妈妈长的很像。她上完洗手间后，在对面看饰品，我就一直盯着她看，说起来很不好意思，因为好长时间都没有见过妈妈了，所以特别地想她。她看完饰品准备走了，我真想多留她一会儿，于是我鼓起勇气走上前说：“您好，阿姨，您气质这么好，我们厅有件衣服很适合您。你看看吧？”她说：“我不买衣服。”“没事，您不买来试试吧！”当时心里真的很着急，害怕她会走掉，也许是我满脸的真诚打动了她，她走进我们厅，然后我开始给她选衣服拿衣服。转眼一个多小时过去了，她说：“算了，我穿上都不好看，真不好意思，耽误你这么长时间。”我说：“没事，阿姨，我有一个小小的请求，在您闲的时候多来我们这里转转和我聊聊天行吗？”她
