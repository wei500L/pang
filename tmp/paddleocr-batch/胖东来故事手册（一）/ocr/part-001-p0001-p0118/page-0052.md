# 讲述 胖东来和您 故事 STORY

# 信任的感动

作者：超市部/张少华

进胖东来将近一年了，许多事情让我感慨万千。顾客的一言一行中都透露出对胖东来的信任。在如今人们自我保护意识越来越强的社会中，这份信任是如此艰难，如此珍贵。

就说说最近发生的一件事情吧！我们劳动店员工上厕所要到路边巷子里的公厕。这天，我们服装区售后服务部的丽丽姐（她是我店的年度优秀员工）急匆匆地直奔说远不远、说近不近的“卫生间”而去。刚走到门口还没来得及抬脚往里边，突然，胳膊被人扯住了，丽丽姐回头一看，只见一位白发苍苍的老大娘，怀里抱着一个不满周岁的“小宝贝”，满脸通红地对丽丽说了一句“总算有个可靠的人了”，说完就把宝宝往丽丽姐怀里送，等丽丽反应过来时，怀里已多了一个小女孩，而那位老大娘已“冲”进了厕所（当时那位老大娘好像等了不短的时间）。丽丽姐望着怀里正对她扑闪着大眼睛，一脸笑容的女孩，心中一片迷茫。不过，一切问题都在那位老大娘“从容不迫”地从厕所出来后，有了答案。只见那个老大娘笑眯眯地从丽丽手中接过孩子，对丽丽姐说：“闺女呀！刚才可真多亏你了，不然我这么大年纪的人，非要在这儿出丑不可！这小家伙不会走，不会站的，我又急着上厕所，来来往往的这么多人，我给谁都不放心，都不可靠。”那你还敢问道。“不怕，我看见你穿着胖东来的制服呀！虽然这年头坏人挺多的，可俺相信，只要是胖东来的人肯定没问题，不管是人品还是卖东西，俺就是相信你们。”

丽丽姐当时觉得心里暖暖的，一种自豪感油然而生。回来后，丽丽姐一边对我们叙述这件事，一边不停地自言自语：“做胖东来人，真好！”
