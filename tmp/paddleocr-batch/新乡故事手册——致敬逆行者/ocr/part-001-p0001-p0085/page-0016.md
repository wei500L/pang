# 一份特别的生日祝福

电器部/施彩霞

2020年2月23日，在疫情形势仍旧非常严峻，电器部手机区的员工彭敏收到了一条来自新乡“小汤山”的信息——我想送给我父亲一部手机，可以送到家里吗？

原来，发信息的是我们的一位老顾客，她是一位医务工作者。彭敏在和顾客的聊天中得知，当医院动员医护人员前去支援新乡“小汤山”（新乡新冠肺炎重症患者定点医院——太公山医院）时，她便毅然地按下了红手印，踏上了与病毒抗击的征程……现在，她已经在医院工作数日了，可什么时候能回家还是个未知数。过两天就是她父亲的生日了，她想送一部手机给父亲，联系我们就是看我们能否帮忙送货上门，给她父亲一个惊喜。

考虑到这位顾客的情况特殊，彭敏立即与主管联系，详细说明了情况，并要求亲自送货。那时候，我们电器部原本是暂停营业的，全员在家隔离待命的，但大家一想到这位顾客正为了我们城市的安全，与病毒抗争在一线，就下定决心一定不能辜负她的委托！于是，我们的主管驾车带着彭敏来到卖场，拿上手机和特意为顾客准备的礼品，在做好消毒工作后，来到了顾客父亲所居住的小区。

彭敏根据顾客提供的电话与叔叔取得了联系，并约好了在小区卡点处见面，她双手递上了这份意义非凡的礼物，并再次替顾客向其父亲转达祝福。那时，叔叔满眼都是幸福和感动。我想，这应该是叔叔最难忘的一个生日了吧！此刻，他一定还担忧着自己奋战在一线的孩子，也一定为自己的孩子深深骄傲着。随后，彭敏送上了我们特意准备的礼品，并满怀敬意地对叔叔说：“叔叔，谢谢您！谢谢您培养出了如此优秀的女儿，如此伟大的白衣天使！这是我们对抗疫英雄的敬意。”

我们很幸运生长在这片土地上，总是被勇敢的人保护得很好，对我们来说，这是一次十分有意义的上门送货。国难当前，是一个个可爱的
