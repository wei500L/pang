# 疫情随感

服装部/段军花

终于，终于，终于，

到了我们复工的时刻，

我穿戴整齐，化好妆容，

走在复工的路上，

一路上行人很少，甚至有些许荒凉感，

可我知道，我的城市、我的国家

已经渐渐走向康复。

2019年末，本以为我们马上就要迎来生命中的一个平凡年，但没有想到“新型冠状病毒肺炎”这个不速之客，让我们的年变得如此不平凡。

起初听说湖北有一种病毒在传播时，我还以为只是一种类似于流行性感冒的病毒罢了，但随着相关新闻报道的增多，我突然意识到它的“不同”。
