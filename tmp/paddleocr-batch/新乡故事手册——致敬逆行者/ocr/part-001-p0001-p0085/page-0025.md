# 一张地图

保洁部/蔡星星

疫情发生，封村、封路一时间成了各个媒体的新闻爆点，也正因此，我们初五恢复营业时，很多兄弟姐妹都无法到岗。按照年前计划，我们初四到公司为第二天的营业做准备。和许多兄弟姐妹一样，在那个时候从村里出来，真的太不容易了，只记得出来的路上有零星的几人，偶尔碰见辆车也是疫情巡查车，好不荒凉。

我想，很多人一定都和我一样，即使内心很忐忑，但看到大哥的随笔消息时，内心是无比沸腾的。病毒虽然可怕，但比病毒更强大的是我们勇敢的心！那时，我就暗下决心——无论如何都要去上班！更何况我年轻力壮身体好，怎么能不上？

上班后，我看到公司为我们准备了很多防护工具，所有蔬菜进价销售，生鲜商品打包好再上架；我看到公司为应对民生需求，紧锣密鼓地筹备并开启了无接触安心送……公司的一系列举措，让我深刻地认识到一个公司正如何以“大爱之心，勇敢地承担与参与”。

在这期间，有件事令我印象深刻。有位家住翡翠城的老顾客给我发信息说家里走不开，希望我能帮忙买点东西。随后，她给我发了一张自己制作的CAD图，这张图的详细和精细程度都让我觉得太不可思议了！那是一张从超市入口处到南边冷藏区的平面图，图上清楚地标明了每个区域的名称以及在这个区域她想要购买的东西，连买多少、买哪个价位的都标注得一清二楚。这么详尽、准确的图，是得逛过多少遍大胖，才能画出来的呀，对她来说，大胖就像是自己的家一样吧。

我问顾客，为什么要那么麻烦地画张图，一定用了很多时间吧？顾客说：“给你画张图，你看着路线清晰，方便你好找商品呀！本来你们担着风险上班就已经很不容易了，下了班还要帮我买东西，我就想着帮你节约点时间。”手中的图画的是关心，耳边的话听的是温暖，我能感受到她对我们的那份理解与厚爱。
