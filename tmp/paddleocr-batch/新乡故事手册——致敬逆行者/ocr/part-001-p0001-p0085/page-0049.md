# 当下的要紧事儿

超市部/杨菲

本来是要欢天喜地地过大年，谁知道一场疫情把所有人都关在了家里。电视上、手机里每天都能看到新型冠状病毒的最新消息，防护和消毒成了我们每天最重要的事。

我们原计划本初五才营业的，但是医药超市初二就提前开启了售药窗口。在大哥的随笔中，我们一直关注着公司的抗疫动态，丝毫不意外的是，到了初五正式营业的时候，营业部门没有一个人因为害怕感染而逃避，大家都义无反顾地站在了自己的岗位上。

自助收银区域是我的工作岗位，从上岗的第一天开始，除了做好自己的防护措施外，每天将所在区域进行无死角的消毒成了我最重要的工作之一。在这个阶段，顾客一般都会一次性购买好几天要用的东西，为了减少顾客在卖场停留的时间，我们会主动帮助顾客扫描商品并进行装袋，同时还会提醒顾客，疫情期间刷脸功能已关闭（避免摘下口罩），引导大家使用手机扫码支付。

一天上午，一个女孩子提着一篮商品急匆匆地跑过来，对我说：“我着急走，但是没带手机，能不能刷脸支付？”我立刻抱歉地告诉她，说：“不好意思，美女，现在正是疫情期间，为了您和他人的健康、安全，我们的刷脸功能已经关闭了。”女孩很着急地说道：“那怎么办？要不你能不能先帮我付了？你加我微信，我到家拿手机给你转账。”看她着急的样子，没等女孩说完，我就已经在帮她扫描商品了。特殊时期，不能让顾客白跑一趟。我迅速地结完账后，将商品打包好递到了女孩手中，女孩激动地说：“谢谢，谢谢！你放心，我不会跑的，我到家就给你转钱！”说完便要求我加她微信。女孩走后，我将情况反馈给主管，主管也非常认可我的做法，我们都觉得，当下让顾客买到东西是最要紧的。当天下午，女孩就把钱转了过来。
