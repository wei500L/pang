# 致敬——疫情中的城市美容师

电器部/孟令海

在这段日子里，我们哭过、笑过、感动过，甚至也痛过、煎熬过。在同一片天空下，我们正亲历着同一场永生难忘的灾难。在这段日子里，我看到了不同的生活样貌，也有了很多关于爱和生命的感慨与感动。

在全社会的共同努力下，疫情逐步得到控制，很多的小区、村庄也都不再强制性封闭了，只要办理好健康通行卡就能自由出入，方便了很多需要工作、有事要办的人。我们在家里待了半个多月，头发也都长长了不少，刚好，我堂哥是做理发工作的，趁着和他去镇上医院办理健康证的时候，我们决定去他的店里拿上剪发工具理理头发。

我堂哥的理发店在辉县市区里，离老家有点距离，我们开着车一路上边走边聊。刚出发的时候，我堂哥还说：“现在疫情刚刚稳定住，工厂、公司都没复工，那清洁工人们应该也没上班吧？”我说：“有可能，各个行业基本都停工了，要是清洁工人不上班的话，马路上估计得有好多垃圾……”我们越聊越感觉像世界末日要来了一样，这次疫情实在对各行各业的影响太大了！抱着忐忑的心情，我们进入了市区，可映入眼帘的一切和想象中完全不一样。
