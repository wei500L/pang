# 齐心抗疫

# ——期待春暖花开

超市部/岳海艳

初五是我们返岗的日子，在此之前，已经有很多地方开始戒严或封闭了，因此，我们必须在上岗前对能够到岗的人数做出准确的统计，为营业后的工作安排做准备。

我在部门群中发了一条信息：“初五能正常到岗的请在群内回复下。”很快，我就看到了一连串简短有力的应答：“张智力，初五正常上班！”“王小芳，初五正常上班！”“赵素玲，初五正常上班！”“柳梅，初五正常上班！”大家都在积极地回应着，这时，我看到一个让我十分意外的名字——茹倩楠。茹倩楠？小茹年前就说过，因为家里需要人照顾孩子，忙完春节她就准备离职了，没想到她也回复能过来上班。看到她的名字我是又惊讶又感动，在人手紧缺的非常时期，能有人多贡献一份力量可以说是太给力了！我私信小茹，问她是怎么想的，她特别自然地对我说了句：“我得跟你们统一战线啊！”虽然是很简短的一句话，但在这时候说出来却十分有力量。

说到茹情楠这个姑娘，不得不提的是她身上那可贵的温柔。就像前面提到的一样，小茹因为家庭需要，在春节前就已经和主管报备了离职，但是考虑到年底了，客流量大，怕同事们太辛苦，就说是等忙完过年再走，可谁成想年后又来了疫情，于是，她果断报名要和大家一起战斗。终于，在疫情稳定后，大家的紧张劲儿可以松一松了，公司通知大家可以进行年休，而在这时，小茹却选择等对班歇了年休，和大家一起忙完五一再走。心思细腻的她总是用她的温柔先照顾到同事，考虑到他人，像她这样的胖东来人，相信无论走到哪里都是一束温暖的光。
