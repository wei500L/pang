# 一张遗失的餐卡

餐饮部/王慧敏

我是一名餐饮收银员，平时的工作内容就是在保证收款无误的同时做好窗口服务。作为最直接面对顾客的岗位之一，我深知自己的言行举止时刻代表着胖东来。

那天，有两个抱小孩的顾客来收银台寻找餐卡，据她们说，餐卡是她们刚刚买的，是一张100元的。看到她们着急的样子，我一边安抚她们的情绪，一边想办法寻找。我向办公室和就近收餐的同事询问，大家都说没有见到，收餐的同事还特地询问了她们可能丢东西的地方，再次帮着一起寻找，但最终也没有找到，我只能很遗憾地向她们致歉，并留下了她们的联系方式，以便找到后与她们联系。这时，我听到她们中的一位很沮丧地和同伴说：“我们走吧，不吃了，就剩100块完成卡还丢了，饿着回家吧！”想到她们丢了100元再饿着肚子回家，那该多不开心啊，既然她们走到我们店里来了，就不能让她们失望而归，我想请她们留下来吃完饭再走。于是，我连忙叫住了她们说：“美女，要不这样吧，吃什么你们先点着，我这边帮忙给你再找找餐卡。”她们听后很惊讶地说：“那多不好意思呀！”我说：“没关系的，你们先点餐吧！”于是，我让保洁大姐领着她们去点餐了。她们那天也没点多少，两人份的餐，还给孩子点了一份甩饼，我又让大姐给她们送去了一份果盘。

饭后，那两位顾客专门来跟我告别，她们开心地对我说：“谢谢你们的帮忙，你们这儿的服务太好了！真的让我们非常感动，我儿子今天吃了五个馄饨呢！”临走时，她们说，改日要把钱还回来，我赶紧拒绝她说：“不用客气，这顿饭就算我们请的，很抱歉没有帮忙找到餐卡。”她们特别理解地说：“又不是你们的错，是我们自己没有拿好才把餐卡弄丢的，今天太谢谢你们了，没饿着孩子，我们走了啊！”说罢，我们互相微笑地说了再见。
