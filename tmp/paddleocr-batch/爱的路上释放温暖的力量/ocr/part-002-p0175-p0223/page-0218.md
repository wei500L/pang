# 暴雨后的中厅

防损部/张岩

那是2019年的4月17日的晚上，送宾后，我和同事们像往常一样整理购物车清场交班，没想到就在这时，我们突然接到了主管的电话，通知我们立刻到一楼大厅集合，处理大雨应急问题。

刚到楼下，我就看到许多顾客滞留在中厅内，在狂风骤雨的席卷下，大家只能选择等候，而与此同时发生的一幕幕，着实令我难忘。我看到兄弟们不断给顾客搬来凳子让顾客休息，并耐心地安抚着顾客的情绪；我看到保洁部的哥哥、姐姐们给顾客拿来了湿巾、抽纸，帮助中途返回的顾客擦去头上的雨水和身上的污渍；我看到总台的同事们拿出爱心雨衣和雨伞为顾客办理免费租借，雨具租完了，甚至将自己的雨伞也派发了出去……一场大雨困住了回家的人们，打湿了兄弟姐妹们的衣衫，可是胖东来真诚、贴心的服务却像是一把无形的大伞，为顾客们撑起了一片晴朗的天空。

这零碎的一幕幕或许称不上是故事，但的确是一段珍贵的记忆，让我心生感动，又不禁深思。仔细想想，我们做了什么很伟大的事情吗？并没有，我们只不过是做了些力所能及的事儿来服务顾客、方便顾客，而这些方便和帮助对于那晚被大雨困住的人们来说，无疑都是一份温暖。东汉时期蜀国主公刘备曾说过：“勿以善小而不为。”我常常也这样告诉自己，要抱着善良的心去做事，就算事情不是什么大事，但真诚无价，我们能为顾客提供到切实的方便，也是让自己幸福的方式。同时，我认为，在我们服务行业也应该秉承着这样的态度，只要是力所能及的“好事”、方便他人的“好事”，我们都要敢于去做、主动去做，不要在乎大小，因为善良是一切美好的源泉，而我们正在创造着的正是自己都喜欢和赞美的结果。
