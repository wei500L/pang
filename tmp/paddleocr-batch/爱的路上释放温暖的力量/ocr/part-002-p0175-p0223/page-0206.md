# 收银台的尴尬一幕

超市部/郑如月

读读新闻，看看视频，打打电话，再发发短信……手机在我们的生活中扮演着越来越重要的角色，它使我们的通讯更加便捷，让我们人在家中坐，即可悉知天下事。特别是“手机支付”这种付款方式，很大程度上解放了人们的钱包，真是方便了不少呢！可是，已经习惯零现金出行的你，有没有遇到过手机没电关机，寸步难行的情况呢？那真是尴尬极了！大胖超市收银台就曾发生过这样的一幕。

一天晚上，正值周一，第二天就是我们的周二闭店休息日了，当悠扬的送宾曲渐渐响起，伴着轻松、柔美的音乐，顾客们有序地在收银台排队结账，一位大姐推了几箱牛奶赶到收银台，我们的收银员李祥琴热情地问候道：“姐，买这么多牛奶呀！”大姐高兴地回答道：“是呀，明天我女儿返校，给她准备的！幸好赶在你们下班前买到了。”说罢，大姐便准备从包里掏钱包，可谁成想，大姐出门着急竟然忘了带钱包，于是她拿起手机准备扫码支付，但是手机也没电了，大姐着急地试了几次都开不了机，这可把她急坏了。“明天女儿就返校了，这可咋办呀！”大姐不安地说道。李祥琴灵机一动，对大姐说：“姐，您别着急，您稍微等我一会儿，我去找找看有没有充电器。”她确认了大姐的手机型号后便赶紧跑回了办公室。因为那时候超市收银台是没有配备充电宝的，李祥琴在办公室里问了好几个人才找到了适配的充电宝和充电线，拿到后，就又一路小跑着回去，赶紧让大姐充上了电，帮助大姐顺利地付了款。

让人没想到的是，一周后，大姐竟送来了一封感谢信。信中写着：“李祥琴同志用实际行动践行着‘爱在胖东来’！由衷感谢公司和这样的好员工！”看着大姐字迹工整的信件，我的心里不禁涌上一股暖意。大姐这封信一定酝酿了很久吧。
