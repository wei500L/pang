# 突如其来的感谢

保洁部/张金霞

“妹子，你还记得我吗？我带孩子去医院看了，医生说烫后处理得非常及时，没有什么大碍，真是谢谢你们了！”我抬起头，一位大姐激动地拉住我，说：“如果不是你们的及时帮忙，孩子的手还不知道成什么样子呢！”我看着眼前的大姐，回想起了那天的故事。

那天，卫生间岗位的同事正好休年假，我到卫生间替岗，当我正在打扫洗手台时，突然听到身旁的孩子“哎哟”了一声，我的目光立刻就投向了她，只见她表情痛苦地在水龙头前冲洗着自己的手，孩子的母亲站在旁边手足无措，我赶紧上前询问孩子的情况，孩子强忍着疼痛，眼含泪水地望着我说：“我……我刚才接热水，不小心烫到了，好疼呀……好疼呀……”看着孩子眼眶红红的模样，我的心也跟着揪了起来，但是转念间就想到洗手台的水是温热的，烫伤应立即用凉水冲洗，于是我快速放下手中的拖把，把孩子带到了保洁室，将孩子的手放在凉水下不停地冲，以快速降低烫伤给孩子带来的伤害和灼痛感。我拉着孩子的袖口，边给她冲手边时不时地问道：“乖，手指还疼不疼啊？”孩子很懂事地说：“阿姨，我好多了。”看到孩子的面容越来越舒缓，我揪着的心才慢慢放下。

一般轻度烫伤的冲洗时间为10~15分钟，但考虑到孩子的皮肤娇嫩，我们那天冲洗了有20多分钟才停止，随后，我联系母婴室的同事帮忙把药箱里的京万红烫伤膏拿了过来，经过家长的同意，我们一起给孩子涂抹了药膏，最后，我建议家长最好还是带着孩子去医院看一下比较稳妥。没想到孩子的妈妈今天又专程找到我表达谢意。

善良和真诚总是在为美好蓄势，我们平时的学习和积累，能让我们在特殊情况下学会理智对待，科学处理，这是对顾客的负责，更是对爱的践行。在工作中，我渐渐理解了很多理念中的词汇，那是爱的力量。真诚地帮助他人、善待他人，让我的每一天都充满了阳光、浪漫和美好的味道。
