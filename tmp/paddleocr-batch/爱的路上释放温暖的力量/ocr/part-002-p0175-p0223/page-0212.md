# 最入心的温暖

服装部/郭亚楠

时光匆匆，转眼间我已在大胖工作了两个年头。至今我还记得，在我生完孩子刚来上班的时候，那种无所适从、惶恐不安的感觉，我感觉自己好像突然什么都不会了。在同事和主管的悉心帮助下，我全身像被一团暖暖的火包裹着似的，四周立马看见了光明。这是一种炽热却不会灼人的温暖，也让我在那时更加深刻地体会到了什么叫“爱在胖东来”。

企业文化教我们要有一颗包容之心、善良之心、宽厚之心，教导我们如何爱别人、爱自己，在生活和工作上都给了我们很多指引。记得那一次，我们家的老顾客张姐来店里，我远远地就迎了上去：“姐，又来逛了？”相比我的热情相迎，张姐的反应很淡，就只是“嗯”了一声，当时我的心里难免有些落差，但是转念间我又想到公司教我们对待顾客要像亲人一样，哪有跟亲人计较的呀？于是，我依然很热情地服务着她。过了一会儿，张姐接了个电话，挂完电话后她的表情还是很严肃，她问我们谁有电动车，说要去别的地方给她母亲换件衣服，我想都没想就说：“姐，我有！你骑我的车去吧。”我把她带到我的车前，还特意和她讲了一下使用方法，因为我的车比较大，怕她骑不好。

大概二十分钟后，张姐回来了，说什么都要给我的车充电，说就剩两格电了，怕我下班回不了家，我说：“没事，我家离得近，肯定能骑回去！”她怕我找不到她停车的位置，还专门带我去停车的地方看了看，最后临走时还不忘问我，车用不用落大锁，我跟张姐解释说，我的车是用钥匙控制的，不用上锁，她这才放心。

车还给我后，张姐没有立马走，她拉着我的手对我说：“乖，对不起呀，姐刚才心里有事儿，态度不好，你别放在心上啊！”那一瞬间，我的眼泪差点就流了出来，张姐竟然那么细心。
