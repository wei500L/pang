# 宠物“专家”

超市部/边丽佳

在胖东来大爱的故事有很多，小温暖的故事更是数不胜数，我的故事没有那么跌宕起伏，甚至可以说是平平无奇，但对我来说，却是意义非凡的。

故事发生在我刚进入胖东来工作的时候，宠物用品是我负责的区域。那天，我遇到了一位大姐，大姐很面善，四十岁左右的样子，她家里原本养了一只小猫，以前她每次到胖东来买猫粮都会来找我，顺便聊聊关于养猫的那些事儿。后来，朋友又送了她一只小泰迪，但是没有养犬经验的大姐很是手足无措，特地来找我咨询，我就将我所知道的都告诉了她。大姐听得特别认真，每一条都用手机详细地记录着。

之后，大姐和我一起探讨的话题就更多了，我特别喜欢和大姐一起聊天，大姐说她每一次都有收获，但有一次，大姐的问题难住了我。大姐说：“昨天我遛狗的时候遇到别人家的小狗狗拉肚子，那以后我家的小狗狗拉肚子怎么解决呢？”我一下子被问蒙了，因为宠物疾病方面的知识我还没有深入了解。大姐看到我的反应后，好像也注意到了我的小吊卡（季节工牌），她说：“没事，没事，不要紧的，乖，别慌，都有不知道的问题。”我立马将大姐的问题记录了下来，希望下次大姐来的时候能告诉她答案。这件事也让我深刻地意识到自己在专业和经验上的不足，那时我想：“我是不是应该去养一只小狗呢？那样我也许会更了解狗狗的习性，也能充分了解到更多狗狗问题的来源。”就这样，一只可爱的狗狗走进了我的生活，到现在，小家伙已经两岁四个月啦！

在之后的日子里，大姐还是会常常来找我一起，讨论家里小猫、小狗一段时间发生的事儿。她会把她知道的东西分享给我，帮我开拓视野、增加经验，我也会把自己学到的东西和大姐分享。我们就这样互相交流着经验，一起在养宠物的道路上成长。到现在，我们两个在饲养小动物方面都成了半个“专家”。她总说，我能让她买到最称心的商品。还说，在任何地方都体会不到像胖东来这样用心的服务。
