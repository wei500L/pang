# 平凡中的星光

超市部/张炎

黑夜中的繁星最明亮，平凡中的感动最入心。别看我们从事着平凡的工作，但也正是因为这种平凡，让我们收获的感动显得更纯粹、真实，也愈加弥足珍贵。

她是一位年轻的孕妈，记得那天，我刚上完货，还在孕期的她正在货架旁仔细端详着眼前各式各样的纸尿裤，只见她边仔细查看商品说明，边用手机搜索着，于是，我便主动上前和她打了招呼，礼貌地询问道：“有什么可以帮您的吗？”她看了看穿着工装的我，可能以为我是来推销产品的，所以并不理睬。那时候，我想可能是因为自己看起来年龄小，不像是有经验的样子，所以她才不愿与我讨论。于是，我在她身旁小声地提示道：“我们每个品牌的纸尿裤都是有展示样品的，我可以带您一个一个地去了解。”说着，我跟她聊起了她正在看的那款纸尿裤，也借此与她讲起了选购方面的技巧及注意事项。她好像突然对我说的话有了兴趣，开始时不时地问我一些问题，我用我所掌握的专业知识一一为她解答了。就这样一来二去，她开始放下戒备与我交谈了起来。那时的我呀，别提多开心啦！我相信她一定是被我的诚意打动了，我也很感动她看到了我的真心。我们的目的从来就不只是销售，而是在顾客有所需、有所惑时为她们提供有效的帮助。

那天，我们聊得很开心，临走前我还特地为她送上了几款新生儿试用装让她试用，也在那时，我们互加了微信。

时光流转，几个月后，我突然收到了那位孕妈的信息，问我现在能不能帮忙送货，得知她因为早产不方便到店采买婴儿用品，而需要的东西都是急用的，我立刻与主管沟通，想要尽快为她送货，主管听后非常支持，还特意叮嘱我说：“看看顾客还有什么需要的，都可以及时与我们联系。”随后，我准备好商品，打车赶往了她所在的医院。

在我把商品送到后，她对我连声地感谢，看到她们一家人因为喜添
