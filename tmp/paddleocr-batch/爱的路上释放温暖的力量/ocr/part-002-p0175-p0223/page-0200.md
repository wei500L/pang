# 发现更好的自己

超市部/王纪娟

英国作家切斯特顿曾说过：“人们也许了解宇宙，但从来不了解自我，自我比任何星球更遥远。”可见，人生的确是一段不断探索、努力发现自我的旅程。下面，我想和大家分享一下我工作中的快乐，以及我在工作中发现的“自我”。

在来胖东来之前，我做过很多工作，比如加油站的加油工、汉堡店的收银员、火锅店的服务员等，虽然涉足了很多岗位，学到了很多技能，但是光有技术上的学习，内心的成长却稍有欠缺，生活和工作中也总觉得少点什么。一次偶然的机会，我来到了胖东来，在这里，我认识到一种“信念”，在胖东来这三年的工作经历让我深深地感受到“爱”是如此美好，创造和分享爱是如此伟大。
