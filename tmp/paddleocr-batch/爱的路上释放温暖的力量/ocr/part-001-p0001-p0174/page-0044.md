# 研磨的是药，传递的是情

医药部/曹苗苗

片仔癀距今已有460年的历史，最早叫八宝丹，是由牛黄、麝香、蛇胆、三七等配制而成，为什么说“等等”呢？因为它是国家级保密配方。

此药对急性、慢性肝炎，刀、枪、骨折、烧、烫等多种创伤、脓肿、无名肿毒及一切炎症引起的疼痛、发热都有显著疗效，外科手术后服用能消炎止痛，防止伤口感染，并加快愈合，因此被国际友人誉为“中国特效抗菌素”，是他们心中的灵丹妙药。

记得有一次，一位阿姨来购买片仔癀，她每次需要的用药量是0.3克，而一粒片仔癀的药量是3克，于是我就按照剂量跟阿姨说：“阿姨，您要把这一粒药分成10份来吃。”她一脸迷茫地看着我，说：“姑娘，这个药能帮我分分吗？你看我眼也花了，手也抖，这我回家也没法吃啊！”“其实这药我只在广东那儿买过，上次家人从广东带来了一盒，我每次都是在家约摸着拿刀刮一点吃了，太麻烦了，而且听说吃多了也不好，还会中毒啥的，但我的病确实需要这个药。”阿姨忧心忡忡地说。听完阿姨的话我很担心，因为阿姨这么随意地服用是存在很大安全隐患的，于是我就决定帮阿姨分好再给她，也方便她服用。

考虑到药品的贵重及在分装时的损耗，我便找来主管一起想办法，终于，经过大家慎重地研究、讨论，我们商量出了办法。为方便分装，我们先是借来了中药的电子秤，但后来发现因为要分装的量实在太少，电子称上的数据是不显示的，于是我们就拿出了老古董天平秤进行称量。称量的问题解决了，我们又开始商量怎样打粉，其实，我们本来也想过用电动打粉机，但是考虑到东西少、损耗大，机器的散热也有可能会影响药效等情况，最后，我们决定使用手工研磨锤进行打粉。
