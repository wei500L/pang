# 电工也骄傲

电工部/张国选

我们电工部的工作就是做好卖场的后勤保障，对日常用电设备进行保养和维修。保障卖场用电安全，为大家营造一个安全、舒适的环境是我们的光荣使命。

每年的夏、冬两季用电高峰期时，我们电工部都会为各个部门进行用电安全知识培训，对存在安全隐患的员工家庭无条件地提供安检和维修，这也是我们胖东来员工的“爱的福利”。

去年夏天的一个傍晚，我接到主管打来的电话，说我们有一名员工家里突然停电，让我尽快赶过去看看什么情况。根据主管提供的住址，我来到了关帝庙附近，那是一幢八九十年代的楼房，离公司不远，略显破旧的建筑外到处都是东拉西扯的电线。那天天气非常热，开门的是一位阿姨，她正在手忙脚乱地照顾着一个一岁多的小宝宝，可能是由于断电的缘故，房间里非常闷热，光线也不是很好，孩子一直在哭闹。和阿姨简单沟通后，我了解到可能是线路老化导致的停电。果然，经检查后，我发现，她家的线路相当老旧，布线也比较乱，存在多处氧化、烧断的情况。找到原因后，我及时更换了电线并开始规整线路，等到完全解决了问题，我和阿姨又讲了一些用电安全常识，例如：家里的家用电器断电后才能擦拭；线路潮湿、老化会有漏电现象，要请专业的电工进行处理等。

维修结束的时候，天已经黑了，看到我身上的工作服都湿透了，阿姨感动坏了，又是倒水，又是表达谢意。看到不再哭闹的孩子在明亮、凉爽的屋子开心地摆弄玩具，我的心情也是无比轻快。

像上门维修这样的工作，我们电工部的所有成员都经常做，不管是哪个员工家中的电器遇到了问题，只要大家向我们寻求帮助，我们都义不容辞，因为这是我们引以为豪的工作，也是大家对我们最大的信任。
