# 梅姐

防损部/方文

你们认识的梅姐是什么样的？我心目中的梅姐呀，她是一个风风火火的女人，做什么事都有自己独树一帜的风格。别看她身材有点壮，嗓门有点大，但实际上内心十分的温柔。

一次偶然的机会，梅姐结识了一位大姐。那一天，大姐是和她的母亲一起来超市购物的，大姐腿脚不便，大姐的母亲也有八十多岁了，一路上都是咱们的保安兄弟照顾帮忙，临走时超市的卢萍姐特意将她们送下电梯，恰好碰见刚下班的梅姐，于是卢萍姐就拜托梅姐顺路将两位送到出租车上，梅姐和大姐就这样认识了。

后来，梅姐的老母亲被儿子接走了，只剩大姐一个人住，行动、购物就更不方便了，梅姐对大姐说：“要不我加你个微信，你不方便的时候咱们开视频我帮你买。”就这样，一种特殊的购物方式被创造了出来。大姐虽然偏瘫多年，但吐字依旧清晰流畅，所以每次需要买什么都能很清楚地表达出来。时间久了，梅姐对大姐的习惯和喜好也越来越了解，大姐喜欢吃的小点心每次都得带点，买水果要买点能放的，还要买些能立马吃的，合计着大姐家的包子、馒头快吃完了，就问问大姐需不需要再备点……梅姐走到哪手机就举到哪，大姐在家里看着手机跟去逛街是一样的。两人一边逛着一边聊着，吃什么，怎么做，怎么吃对身体好，什么水果、蔬菜正当季……两人跟姐俩一样唠着家常。

不光管买还管送，梅姐下班回家路上骑着电车拐个弯就到了大姐家，每次一进门梅姐便熟络地忙活起来，麻利地打扫地面、刷洗碗筷、收拾垃圾的样子就跟照顾自己家的大姐一样。说起来梅姐对自己的照顾，大姐感动的泪水在眼眶里直打转。大姐在早些年离异，自己的两个小女儿工作繁忙，母亲年迈，自己又是偏瘫，生活非常艰难，所幸能够靠自己的退休金生活，梅姐对她这么长时间无微不至的照顾让她心里十
