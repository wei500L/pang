# 幸福会发芽

超市部/张昕昊

进入大胖已经两年了，对产品知识的不断学习和研究让我的生活更加充实。自从来到这里，我们每个人都有或多或少的改变，这样的改变不仅仅让我们的生活更加阳光，思维也更加开阔。

在我们日常的工作中，总会收到顾客的种种提问，专业知识和工作经验为我们给顾客的解答提供了有力的支持。当然，还要依赖于我们现有的工作标准。例如：当顾客给我们反应食品口感不好或食用方法有问题的时候，我们通常会用正确的方法烹饪后，再次以一名顾客的身份品尝、讨论，然后给予顾客满意的答复。这些问题都是需要我们去相互学习、共同进步的。在我的工作中也曾发生过类似的问题，这就要从“一把黄豆”说起了。

那天早晨，一位阿姨在我们粮食区溜达了好久，左看看、右看看，她的神情看起来还有些许迷惑，当我准备上前询问时，阿姨竟先向我迈步走了过来，原来，阿姨不久前买了一些黄豆，想自己在家培育豆芽，但是经过几次试验都没能成功。看到阿姨失落的表情，我觉得自己应该做些什么了。于是，我先询问了一下阿姨最开始的培育方法，然后我又将自己所学到的方法耐心地讲给了阿姨。我们的方法略有差异，所以我让她按我的方法再试一下，我还告诉阿姨，我也会和她一起做个小实验，等结果出来了立马就告诉她，并留下了她的电话以便后期回访。

阿姨一离开我就行动起来了，由于卖场光黄豆的品种就有四五种，为了更清楚地知道哪一个品种的豆子会发芽、发芽好，我找来了好几个小盒子，把每样豆子都分别泡了起来，只等小黄豆们快快发芽、长大。经过一夜的浸泡，豆子已经吸足了水分，我给它们盖上了一张湿润的纸巾，等到第二天，几个盒子里的豆芽都露出了白色的胚芽，看着盒子里长出的一颗颗白色小芽儿，我心中的希望也跟着萌生了出来，不出意外的话，豆芽们一定可以长成的！我激动地打电话告诉了阿姨这个好消息。在电话里，我还和阿姨讨论了一下她先前为什么没能培育出来豆
