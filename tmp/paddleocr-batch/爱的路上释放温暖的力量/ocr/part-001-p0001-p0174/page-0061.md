# 一条松紧表带的故事

珠宝部/邢云苹

分秒在腕间流转，嘀嗒声中，我听到了流逝的光阴，也听到了爱的细语。一条松紧表带，带着我们的诚心和诚意，就这样系在了顾客的手腕上。

记得那一天，有位60岁左右的阿姨来我们柜台购买了一款手链式女装。表扣是挂扣式的，要全部打开才能摘取，我怕阿姨用不惯，帮忙试了很多遍，确保阿姨能熟练使用表扣后，才送老人离开。第三天，阿姨再次来到了柜台，说表扣扣得有些费劲，我本着“让顾客满意”的原则，建议阿姨换一款或者先退货，日后再买，但阿姨却不舍得调换，随后还拿出一条老式的松紧表带问我能不能把这两只表带换过来戴。但两条表带宽度不同是不能调换的，我不忍心看老人那么着急，便一边安慰阿姨，一边帮她上网找找看有没有合适的松紧表带。终于，我找到了！我告诉阿姨这个好消息后，便让她耐心回家等候。

又过了三四天，我们帮阿姨买的表带到了，与阿姨的手表十分相配，阿姨特别开心。她连忙询问表带的价钱，边说，边从包里掏出一卷零钱就往我手里塞，看着老人慈祥的笑容，想到老人大冷天来回跑的那份辛苦和对我们的信任，听到老人那一声声亲切的“谢谢你，姑娘”，一股暖流从我的心间涌上眼眶……我婉言谢绝了阿姨再三塞向我手里的那一沓钱，对阿姨说：“阿姨，您满意就太好了，这表带是送您的，不要钱。”阿姨听后很吃惊，对我们又是一番感谢。

过了一段时间，我给阿姨打了一通回访电话，询问她表带的松紧度如何，电话里阿姨的声音充满了亲切感，电话这头的我，也感到无比的满足和幸福。

这就是我的故事，一条松紧表带的故事，虽然表带不值什么钱，但从那以后，一想到它将带着我们的爱陪伴着老人度过生活的分分秒秒，
