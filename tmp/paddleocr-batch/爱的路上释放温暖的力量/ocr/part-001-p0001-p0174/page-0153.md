# 一封特殊的感谢信

电器部/苏琪

2018年10月14日下午，大胖电器服务台收到了一封特别来信，这个美丽故事的主人翁正是我们售后部的韩建恩、王继中师傅。信中这样写道：“我于10月2日在胖东来买了一台洗衣机，因此和送货上门的师傅结识。在处理旧洗衣机时，找人未果（别人都嫌这活小，不挣钱），情急之下，我想到了这两位送货师傅。当他们在电话里听到我的求助后，二话不说，立刻答应我在忙完后过来帮忙。我家住在新区，大胖的电器售后这两位师傅从南环住宅区别人家干完活，本可以早早回去休息，却因为我的一个求助电话大老远跑过来，从二楼把旧洗衣机拉走，并送到拥挤不堪的健康路附近住宅区。两个师傅顾不上擦一把汗、喘一口气，一鼓作气把洗衣机抬到三楼，其中一个师傅扛着洗衣机落地的时候把屁股先坐下去，唯恐摔碰到机器。服务中见细节，细节中见品质，胖东来员工就是与众不同啊！两个师傅楼上楼下，扛来扛去，忙活半天不收一分钱，不喝一口水。胖东来这种只为了方便顾客，处处替顾客着想的雷锋精神百闻不如一见，让我有久违的感动。感动之余，我作为中心医院的一名心血管专家，也想将这种雷锋精神传承下去，将这种服务理念发扬下去。我决定凡是胖东来员工持工作证来我院找我看病，均免收挂号费。”

这位顾客将她在胖东来接收到的感动生动地记述在信中，用她独特的方式来表达谢意，看到信的每一个东来人都为此动容。问起事情的缘由，两位师傅相视一笑对我说：“大姐打电话给我们说，家里有台旧电器要送到另一个地方，我们把车上的货送完，腾出地方就直接去了，可送完机器后大姐又是给钱又是拿酒的，那哪儿行？那可是我们的超值服务。”两人只是笑笑，谁都没有具体说说那天的过程。说实话，我们这群哥嘴不巧，却真真儿的踏实肯干，问起此类的“好事”他们总是挥挥手，笑着说：“没啥，应该的。”我们都知道，在他们那些男人那儿，
