# 勇敢的底气

餐饮部/李亚飞

2019年4月30日，东来哥发布了一条令人心潮澎湃又倍感温暖的随笔：“每一个胖东来人如果在街上刚好遇到需要救援的人，如果自己有时间，在保护好自己的同时，要勇敢地去帮助他们，即便是被误解和冤枉，公司也一定不会让你失望或遭受损失……我们努力让社会多些温暖和爱的力量！”

巧的是，就在三天后，大胖餐饮部的员工李保伟在下晚班后就遇到了这样的一件事。保伟哥在路过平原桥附近的时候，远远地看到路中间躺着一个人，被摩托车压着，可人来人往却没有一个人敢上前帮忙。回忆起那个时刻，保伟哥说，是东来哥的随笔让他坚定地迈出了那一步，给了他勇敢的底气。

他停下车子，走近一看，被摩托车压住的原来是一位醉酒的大哥，大哥身上散发着浓浓的酒气。保伟哥二话不说，立马将摩托车挪开，蹲在地上查看了大哥的情况。经过查看，保伟哥发现他并没有大碍，只是因为醉酒，意识不太清醒，当保伟哥将他扶起，向他询问家人电话的时候，他语无伦次的，也说不出什么有效信息，还满身酒气地往保伟哥身上靠，可一想到他喝多了，保伟哥也就顾不得计较。

由于路边不时就会有车辆经过，出于安全考虑，保伟哥用手机打开了闪光灯，方便大家路过时注意到这里。不一会儿，又有几位年长的大爷凑过来和保伟哥一起询问，但是醉酒的大哥还是说不清楚自己家的具体地址，家人电话也说不出。后来，大家从他的身上找到了手机，抓着他的手好不容易才让他配合解锁，与他的家人取得了联系。在给他的家人报过平安，并详细地描述了大哥所在的位置后，大家合力将摩托车和大哥转移到了安全的地方。看到醉酒大哥状态平稳，又有保伟哥照顾，大家便各自回家了。保伟哥在路边陪着大哥，一直等到他的家人过来后才骑车离开。
