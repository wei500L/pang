# 特殊人的故事

防损部 / 范乃杰

<div style="text-align: center;"><img src="imgs/img_in_image_box_260_471_999_942.jpg" alt="Image" width="62%" /></div>


两年前，我刚退伍回来，对未来十分迷茫，找工作也很迷茫。那时，我的朋友在大胖防损部工作，他总是会跟我讲胖东来企业文化好。作为一个基层员工，他从来不会跟我讲他一个月多少钱，一个月休息几天，累不累，而是总和我讲胖东来的文化理念和企业精神，每当他提到“胖东来”这三个字的时候，他的眼睛总是格外亮。我特别好奇究竟是什么样的企业让员工如此热爱，终于有一天，我带着满腔好奇与憧憬来到了这里。

工作中，我发现在我们的顾客中有这样一些特别的人，他们不同于其他的顾客，从外表上可能看不出有什么不同，但是他们的行为告诉我们，他们就是我们口中的“特殊人”。我不知道如何定义他们，就像我们不知道他们背后有着什么样的故事。
