# 一束直达心底的光

防损部/王绍立

某杂志社曾做过一个调查：“你最欣赏的品质是什么？”大部分人的回答是“乐于助人”。而当问到“别人遇到困难的时候，你会怎么办”时，大部分人的选择则是悄悄走开。殊不知“人”字是由一撇一捺巧妙地构架起来的，也正是因为这一撇一捺，才让它具有高度的稳定性和平衡感，这不正是告诉我们，人与人之间要在互相帮助和互相支撑中走完人生的路途吗？当我们遇到困难或挫折时，他人的帮助和关怀就成了莫大的温暖，也是一束直达我们心底的光。

那是2019年2月26日的下午，我像往常一样整理着散落的购物车，一位孕妇悄然走进了我的视线。她挺着圆滚滚的肚子，走得缓慢小心，正当她准备上手扶电梯的时候，突然弯下了身子，我意识到她是想去系自己散开的鞋带，奈何她架在身子中间的孕肚实在太大，她尝试了几次都只是勉强能摸到鞋带。没有家人的陪同，在那一刻她显得是那么无助。她缓缓地直起身来，有些尴尬地环顾四周，因为鞋带没有系好，所以她丝毫不敢移动。我见状赶忙放下手头的工作，一路向她小跑过去。我蹲下身，边安抚她，让她不要慌张，边伸出手来准备帮她系鞋带，她看出了我的意图，连忙摆手说：“不用了！不用了！”我微笑着对她说：“没事的，谁都有不方便的时候！”然后，我迅速帮她系好了散开的鞋带，又顺手把另一边的鞋带也重新系紧了一下。她激动地不停说道：“胖东来的人真好！”我站起身来微笑地说：“这都是我们应该做的，您上下电梯注意脚下安全！”说完，我便将她送上了电梯。只见她回头望着我，脸上露出了幸福的笑容。

“赠人玫瑰，手有余香”，当我们带给他人快乐时，愉快的心情就会被复制，当我们伸出援助之手时，温暖将会在顷刻间释放，一份来自陌生人的爱，想必意外中更藏有温暖。
