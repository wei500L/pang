# 给胡大爷送货

超市部/郑如月

迎宾前夕，超市部的小伙伴们早已准备好丰足的商品，等待着顾客前来开启新鲜的一天。就在兄弟姐妹们热情地迎接第一批顾客时，超市部的值班电话响了起来，值班主管琚珺姐接起电话，一边说着一边拿笔在纸上记录着什么，原来，这是一通点单电话。

打电话的是胡大爷，他是一位伤残军人，也是我们的老顾客了，来胖东来买东西是他和老伴儿的共同爱好，也是多年的习惯，但最近因为身体不适，出门就不太方便了。得知胡大爷的情况，超市部专门给胡大爷留了值班部的电话，并告诉胡大爷：“以后有需要，我们来帮您！”

军属家庭享受国家照顾，伤残军人更需要整个社会的关怀，这已经不是胡大爷第一次点单了，虽然胡大爷每次点单都没有满足免费送货条件，但接到电话的主管都会第一时间安排员工为胡大爷送货上门。

胡大爷这次的点单内容有：面粉、麦片、大葱、水果等，想到胡大爷要了大葱，可能是中午饭时就要用，所以琚珺姐安排好自己的工作就赶紧为大爷进行配货，在配货的同时联系卖场抽调人手为大爷送货。由于每天早上生鲜区的员工都比较繁忙，抽不开手，所以主管安排了杂货休闲课的李帅为大爷送货，可这时后勤的送货车已经满额运转，最后琚珺姐决定让李帅打车去为大爷送货，而我也有幸参与其中。
