# 守护善良， 做勇敢的践行者

防损部/孙泽东

2019年8月24日清晨5点40分左右，在许昌东湖游园大转盘发生了一起车祸，一辆白色轿车突然失控，冲破了大转盘的护栏，飞入了灌木丛，滑行了20多米远后起火。事情发生得非常突然，正在晨跑的夜保大哥郭付军和跑友们当时听到一声巨响，随即便跟随声音跑向事发地点。

到达事发地点时，肇事车辆已经燃起了火苗，他们几个人的第一反应就是去看看车里是否有人。他们走到车前，发现车内有一名昏迷不醒的男士，于是几个人二话不说合力将昏迷者抬出了危险区域。当他们几个刚把人抬到马路边上的时候，一回头，那辆车已经燃起了熊熊大火。

到达安全区域的付军哥一行人随即拨打了120和119，当120抵达现场时，那位男士已经清醒，经过急救人员的检查后，确认是因为酒后驾车造成的事故。救护车急速地从熊熊烈火前驶过，一切都显得那么侥幸……

事后再问及付军哥当时救人的想法时，他说：“那时候就想着怎么把人给救出来。当时的火势较小，是施救的最佳时机，再过会儿就算我们有心去救也无从下手了，因为火势太大了！还好没有人员伤亡，所以说喝酒不开车，开车不喝酒！”这是付军哥内心真实的想法，也是当时情景的真实写照，眼前的惊险在告诫我们——切勿酒后驾车。同时，这番告诫也让我们警钟长鸣。

就像东来哥所说的那样：“每一个胖东来人如果在街上刚好遇到需要救援的人，如果自己有时间，在保护好自己的同时，勇敢地去帮助他们。”恰逢其时，付军哥与他的跑友们勇敢地迈出了那一步，即使面对燃起的火团，第一时间想到的仍是有人需要救援，是付军哥他们见义勇为的行为挽救了一条年轻的生命，避免了一个家庭陷入不幸。在救人的那一刻，付军哥他们身上是发着光的。
