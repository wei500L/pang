# 我的阿姨粉

超市部/宋贤坤

可能是因为我有较高的颜值吧，在卖场我深受老大爷和阿姨们的喜爱，他们经常让我帮忙推荐商品，我也很乐意跟他们唠唠家常。别看我年纪不大，我可是有众多的阿姨粉呢！

那是刚立秋后不久的一天下午，一位阿姨在卖场闲逛，她时不时停留和观察，让我感觉她好像是在找什么东西，于是，我上前询问道：“阿姨，您需要什么我可以帮您找！”阿姨问：“咱们这儿有没有保温袋啊？我想买点儿冷冻的东西去看望病人。”保温袋？我们的保温袋当前季节储备较少，这两天刚送完，新订的货厂家还没发到，但是阿姨说她要去看病人，我得帮她想想办法……于是，我对阿姨说：“您等我一下，我去仓库找找。”去仓库的一路上我都在想，绝不能让阿姨失望。

功夫不负有心人，我翻遍了仓库终于找到了一个。我拿着保温袋，心里激动得像住了个欢呼雀跃的孩子似的。当我将保温袋递给阿姨时，阿姨有些不好意思地看了看我，说：“最好有两个。”可是，这已经是目前仅剩的一个了，正当我为此苦恼时，突然想起来家里上次买饺子送了一个保温袋，于是我跟阿姨说：“阿姨，我家里应该有一个，就用过一次还很新，我明天上午给您拿过来，您看行吗？”阿姨好像一下看到了希望，一个劲儿地跟我说谢谢，我连忙说：“没事，姨！您给我留个电话吧，保温袋拿来了我给您送。”阿姨说：“不用了，我自己来拿！”第二天一上班，我就联系了阿姨，让阿姨随时过来都行，挂过电话我又特地跟课里的人都交待了一遍，保温袋一定要放好，会有顾客来拿。

到了下午，主管在工作群里说我被一位阿姨表扬了，而表扬人就是这位阿姨，她虽然不知道我的名字，但是她特意到服务台报了我的手机号，一个劲儿地夸我，表扬我服务好。得知这个消息，我心中的雀跃少年再次跳了起来，我给阿姨回了个电话，以感谢阿姨的认可。
