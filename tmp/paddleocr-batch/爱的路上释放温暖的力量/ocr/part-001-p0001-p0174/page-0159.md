# 美丽的遇见

保洁部/郭学芬

我们一直说“对待顾客要像对待自己的亲人一样”，那么在顾客遇到困难的时候，第一时间为顾客解决问题，就是我们东来人应有的行动。

记得爱红姐给我讲过一件事，那是她的亲身经历。有一次她在珠宝区巡查地面卫生时，远远地看到有一位阿姨正往垃圾桶里翻找着什么，爱红姐赶紧上前询问，阿姨急切地对她说：“我不小心把我的金耳环扔进去了！今天咱们这儿的黄金以旧换新，我就想把我的旧耳环换成新的，可谁成想，把耳环当垃圾一起扔进去了。”听完阿姨的话，爱红姐赶紧安慰阿姨，说：“阿姨，您别着急，让我来帮您找！”说完，她就将垃圾桶移到了不影响顾客的地方，然后从垃圾中一点点地分拣、寻找，最后终于找到了金耳环。当金耳环重新回到阿姨手里的时候，阿姨激动地拉着爱红姐的手说：“谢谢你呀，姐，今天多亏有你帮忙，怪不得大家都喜欢来胖东来嘞，你们这儿的人真好！”阿姨边说边竖起了大拇指，说罢，阿姨就拿着金耳环高高兴兴地朝着珠宝柜台走去了。

爱红姐的帮助让阿姨的耳环失而复得，也在服务中为顾客创造了小的幸福，可你有想过吗？有时候，顾客也在为我们创造着温暖。那是初冬的一个下午，天空阴沉沉的还飘着小雨，来往的人们早已裹上了厚厚的冬装，我正站在伞套机前为进卖场的顾客的套雨伞袋，由于不停地和雨水接触，手在不知不觉中就被冻得通红，就在我停歇的片刻，突然注意到身边站着一个十五六岁的小女孩。“小美女，外面冷，去屋里暖和暖和吧！”我主动地和她打招呼说。小姑娘并没有要走的意思，她犹豫了一下，说：“阿姨，天这么冷，你又没有戴手套，会把手冻坏的。”然后从兜里掏出一片暖宝宝，双手拿着递给了我，我连忙挥着手笑着对她说：“阿姨不冷，你自己……”还没等说我完，小姑娘就把暖宝宝塞到了我的怀里，嗖地一下跑进了卖场。我拿着暖宝宝，看着小姑娘远去
