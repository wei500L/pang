# 加油呀！小美新

服装部/郭亚新

来到胖东来后，我就结识了一位姐姐，大家都称她为“秀姐”。那天，在商场快要送宾的时候秀姐来店里转了一圈儿，看上了一件大衣，在她试穿的过程中，我和她闲聊了一些和穿搭无关的话题，对！就是没有聊衣服，因为我觉得她挑的那件衣服并不适合她。

当时秀姐一身休闲装扮来到店里，很能凸显她爽朗、中性的风格。秀姐试穿了一款修身的时装版大衣，我问她是否想要换个风格，姐姐直接拒绝了我，说她喜欢舒服的感觉。很显然，眼前的这件大衣看起来确实不是她的风格，于是我就委婉地告诉她，说：“姐，这种修身款，并不能够很好的凸显出你干练的中性风，要不试试这款？”说着，我帮她拿了件宽松阔版的休闲大衣递给了她。我到现在还能回想起秀姐穿上那件高级灰的斜纹羊绒大衣的样子，很大气，也很显气质。我很开心，因为在那一刻我是真正站到顾客的立场考虑问题的，只推荐适合的，并非只是为了买卖，我猜秀姐也能感受到我的真心。

最后，虽然秀姐看似很喜欢的样子，但她还是委婉地提出了想要再去转一下，考虑考虑，我想，也许姐姐心里还有其他选择没有放下，她要斟酌下单，虽然我很想让她带走这件大衣，但也不能强买强卖呀，是吧？所以我还是很热情地把秀姐送出了门，并建议她就算到别家去买，还是宽松一点的版型更为合适。尽管单子没有成交，但我完全没有失落感，有的却是满足和幸福，觉得这一天的工作都圆满了起来。

你一定很好奇这个故事的后续吧，我也没有想到，第二天一早秀姐又来了！我并没有因为她的再次光顾而窃喜，而是用比前一天更多的热情来接待。后来我才知道，秀姐原来一直惦记的是另一个品牌的一款大衣，早起先去试了那件，最终还是觉得我们这款更适合自己。

从那以后，秀姐就记住了我的名字，每次来逛商场的时候，都会特地来店里看看我，我特别喜欢听她的那句：“诶，小美新呢？小美新在吗？”那种能走进顾客心里的感觉是很美妙的、很幸福的。
