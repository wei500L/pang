# 不可替代的名片

保洁部/丁兰君

那是3月中旬的一个下午，我正拿着拖把经过卫生间门口，刚好碰见月红姐和一位大爷正在说话，听大爷的大概意思，是希望月红姐能帮他老伴儿上一下厕所。看见大娘坐在轮椅上行动不便，我对月红姐说：“姐，我和你一起去吧，两个人会更安全些。”我赶忙把手上的拖把放到拖把池，和月红姐一起把大娘推进了卫生间。

我们配合着搀扶着大娘，慢慢地让大娘坐到了座便器上，大娘缓了口气告诉我们，她是一位脑梗患者，平常在家都是老伴儿照顾，因为明天孩子们要回家吃饭，就想来胖东来买点孩子们爱吃的东西，可是在外边上厕所太不方便了，以至于她从家出来到现在都不敢喝水，说到这儿，大娘的情绪有些低落，她低声说：“人老了，不中用了，现在就连上个厕所还得麻烦别人。”月红姐蹲在大娘的面前安慰她说：“大娘，您可别这样说啊！俺不麻烦，这都是应该做的！今天能遇到您也是咱们的缘分，您心里别不好受，您就把胖东来当成家，把我俩当成您闺女使。”这时大娘笑了，我跟大娘说：“您如果好了，我帮您擦一下。”大娘说：“不用啦，就这都已经够麻烦你们了。”我说：“没事儿，您这不是不方便吗，我来也是一样的！您别有心理负担，今天能帮您您，我俩也很开心。”等大娘方便完，我俯下身去帮大娘擦干净，随后，月红姐又帮大娘整理好了衣服，拉着大娘的手洗干净，又擦上了护手霜。

当我们扶着大娘从卫生间出来的时候，大爷一个劲儿地对我说：“谢谢你们！谢谢你们了！这要不是在胖东来，我老伴上厕所都不知道该咋办。”大爷夸我和月红姐都挺不好意思的，我笑着说：“大爷，您别这样说，真的不用谢，这都是应该的！要是还有什么需要，您尽管来找我们。”看着两位老人远去的背影，我俩相视一笑，心里暖暖的。这时，月红姐向我伸出了大拇指说：“丁，我没想到你的岗不在卫生间也能这样去做，姐给你点赞！”我笑着回答：“姐，虽然我的岗位不在卫生间，但我也是一名合格的保洁员，你们能干的，我一样也能干！”
