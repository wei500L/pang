# 我们的豆豆姐

餐饮部/李亚飞

每天，我们大胖餐饮总是能看到一个身影，她不停地穿梭在餐桌和各个档口之间，哪里有需要哪里就有她，她就是我们餐饮部的保洁姐姐——李艳菊。她负责我们的后勤工作，大家都喜欢亲切地称她“豆豆姐”。

小朋友的蟹棒掉在了地上，她马上再拿一只新的给他；顾客的柠檬水洒了，她立刻送上一杯新的，并及时清理地面，缓解顾客的尴尬；要是在收餐时发现顾客买的凉皮没有吃，她就会主动上前询问情况，如果是因为不合口味，就立刻为顾客办理退货。豆豆姐总是很细心地观察着周围的顾客，在他们需要的时候提供帮助。

2018年初秋的一天晚上，送宾后的餐饮区顾客已经寥寥无几，一位先生着急慌忙地在座位周围寻找着什么，豆豆姐看到了，赶忙过去询问情况，原来是顾客的牙套不见了。顾客说，他坐在就餐区吃过凉皮后就离开了，过了好一阵子才觉察到牙套不见了，于是赶快折返回来寻找。这位顾客是一名教授，明天早上还有很重要的演讲，而牙套不巧是门牙的位置，现在这么晚了也没地方买了，所以顾客焦急得不知如何是好，特别希望能找到。据顾客回忆，吃饭前他把牙套摘下来裹在了一张纸巾里，应该是自己在饭后收餐的时候，顺手把裹着牙套的纸巾当杂物扔了。豆豆姐根据顾客离开的时间迅速判断出那一批垃圾已经不在卖场了，应该在户外的垃圾池里，在垃圾车来之前还有找到的希望。
