# 一台收音机的故事

服装部/徐梦瑶

收音机是一个年代留下的记忆，也是很多人难以割舍的情怀，而我的故事就要从一台收音机开始讲起。

记得那是去年夏天，一位大哥信步走进厅里，我一眼就认出了他，那可是我们家的老顾客了！大哥挑选过衣服后，在厅里等候他的母亲，没一会儿阿姨就到了，看到阿姨有些疲惫，我们赶紧让阿姨坐在按摩椅上休息，性格开朗的阿姨很自然地就和我们唠起了家常。
