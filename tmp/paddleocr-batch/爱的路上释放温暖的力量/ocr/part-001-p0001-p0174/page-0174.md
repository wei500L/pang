# 大爷摔倒后

保洁部/杨涛

说说曾经发生在二楼卫生间里的一件事儿吧。那是2019年冬天的一个下午，我如往常一样进行着手头的工作，远远地就看见一位步履蹒跚的老大爷向卫生间走来，于是，我赶忙放下手中的活上前搀扶老人，并提醒道：“大爷，这里有台阶，您进出的时候要小心台阶。”我搀扶着老人来到坐便前，将坐便二次消毒，告知老人手纸的位置，然后嘱咐说：“大爷，您上完厕所就按这个红色的按钮呼叫我，我马上就到！”说着，我指了指卫生间门上的讯铃按钮给老人看。

将老人安顿好以后，我就继续工作了，过了一会儿，我约摸着老人快好了，便准备返回卫生间查看，可就在这时，发生了惊险的一幕，我刚好看到推门而出的老人，他一只脚已经迈了出来，眼看着就要踏空台阶，说时迟那时快，我三步并作两步上前，一把抱住了即将倾倒的老人，老人整个身体都倒在了我的怀里，我看到老人表情痛苦，忙问道：“大爷，您哪里不舒服？是不是伤到哪儿了？”老人可能也被吓到了，缓了一会儿神才开口说：“哎呀，谢谢你呀，孩子！要不是你扶着我，那真不知道会发生什么事。”听完老人的话，我慌乱不安的心稍稍平静了些，我说：“大爷，您说哪里话！让您受惊了。”说着，我将老人慢慢地搀扶到门口的休息区坐下，看到老人又皱起了眉头，我忙蹲下身问道：“大爷，您还有哪里觉得不舒服吗？”“我大拇脚指有点疼。”老人轻声说道。我小心翼翼地将老人的鞋袜脱下来查看，发现老人在下台阶时还是踩空了，脚指碰破了，正在不停地渗血。老人看到自己受伤的脚趾，刚刚才放松的身体又紧绷了起来。我开始不断地安慰老人，一边和他聊着天转移他的注意力，一边联系母婴室的同事赶快拿医药箱来为老人处理伤口，又接了一杯热水端到老人跟前。我询问了老人的家庭住址及亲属的联系方式，并通知了他的家人，与此同时，同班的同事也及时通知了相关主管，当主管们赶到时，大爷的伤口已经处理完毕，保安主管看见老人的袜子上沾满了血迹，便马上去给老人买了一双崭新的袜子，等老人的伤口凝血后，我便帮老人换上了干净的袜子，随后，保安
