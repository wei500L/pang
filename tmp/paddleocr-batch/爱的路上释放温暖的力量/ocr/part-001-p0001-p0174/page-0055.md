# 最帅的新郎

服装部 / 赵培

2005年，我入职胖东来百货，成为鞋区的一名销售人员，从恋爱、结婚，再到后来做了妈妈，都是胖东来陪我一起的。沉浸在这个充满爱的环境中，我感受到生命的意义就是要创造幸福。

2009年，我还在老百货一楼劲王工作，一对老夫妇进到我们厅给儿子选购婚鞋。在大爷、大娘的一番精心挑选后，最终给儿子选了一双商务男鞋，又各自选了一双。考虑到大爷、大娘是帮儿子买鞋，他本人没有试穿，所以在他们临走前我还特意嘱咐，回去一定要提前试穿一下，万一有不合脚的情况好及时来换。我把自己的电话也留给了大爷，告诉他们，如果鞋子不合适，抽不出时间来换的话，我们也可以上门办理调换。

过了几天我也没有等到老两口的电话，我想鞋子应该是没有问题了，可随后的一天，就在我准备出门上班的时候，电话突然响了。电话那头一个小伙子急切地直奔主题地说：“鞋大了，怎么办？”我赶忙询问情况，原来小伙子是老两口的儿子，他因为婚礼前事情比较多，只是随便上脚试了一下就放在一边了，直到结婚当天去接新娘的时候才发现鞋子走路不跟脚，而鞋子本身又是一脚蹬的款式，实在不能将就。这可是结婚的大事儿啊，挂断电话后，我第一时间与厅里联系，确定有小一码的库存后，便飞奔去厅里拿货，然后又以最快的速度赶到了国际饭店。到达目的地后，我赶紧为顾客试穿新鞋。小伙子拖着穿了一上午的鞋子不好意思地看着我，说：“这个鞋……”我看出了他的心思，便微笑地告诉他说：“没事的，别担心，这个我们自己处理！您只管开开心心地把心爱的姑娘娶进门，做个最帅的新郎就行了！”其实，鞋子的状况我去之前就有想到，但心里只有一个念想：“一定要让小伙和他心爱的姑娘开开心心、顺顺利利地完成结婚典礼。”
