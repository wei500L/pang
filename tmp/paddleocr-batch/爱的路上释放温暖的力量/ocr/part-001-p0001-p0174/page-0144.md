# 新鲜的三文鱼

超市部/李楠

转眼间，我成为“胖东来人”已经两年了。时间过得飞快，记得我初来乍到时，还因为在工作中遇到了好同事、好伙伴而欣喜不已，但随着时间的推移和我对公司文化的理解，我渐渐感受到“遇到好同事”只是我幸运的表象，真正幸运的原因是我“工作在胖东来”，在这里我感受到了前所未有的轻松和温暖。

两年的时间里，我的身边发生了太多的故事，每一件事都承载着我的回忆，同时也记录着我工作中的点点滴滴。记得有一次，我们接到了一家公司晚宴的三文鱼订单，当时，和我们对接的是位和善的大姐，她们公司举办晚宴需要2斤三文鱼刺身，我们约定好次日晚上6点钟取货，但是第二天中午就又见到了大姐。大姐焦急地到柜台前询问：“妹子，你能不能现在把鱼帮我们准备好啊？我一会儿直接拿走。”“没问题的，姐！”我爽快地回答道。想着大姐比约定时间早来了那么久，她一定是想提前备好，于是我立马和同事着手准备，大姐还不忘叮嘱我多放些冰袋，还特意询问了三文鱼的保鲜时间，我回答说：“姐，虽然现在是秋天，气温没那么高，但冰袋也只能让三文鱼短暂储存两三个小时，建议放冰箱里冰鲜保存。”大姐听后，发愁地说：“啊？我们公司办公室没有冰箱啊，但是我晚上还要忙晚宴的事儿，实在来不了啊。”看见大姐一脸愁容，我们几个赶紧商量了起来。虽然大姐的订单金额还不够免费送货的条件，但是最后我们一致决定，自己给顾客免费送货上门。于是，我对大姐说：“您尽管放心去忙吧，三文鱼交给我们，保证准时送到！一定让大家吃到新鲜的三文鱼。”我到现在都还记得大姐那意外又感动的神情。
