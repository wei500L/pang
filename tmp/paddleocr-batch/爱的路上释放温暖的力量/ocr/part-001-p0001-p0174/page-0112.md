# 为爱归来，因爱精彩

超市部/张余凡

“你为什么来到胖东来？”在岗前培训中老师曾问过这个问题，小伙伴们都非常积极地回答，我当时也在心里暗暗思考了这个问题，奈何彼时的我胆怯、紧张，当我鼓起勇气准备回答时，这个问题却已经翻篇了，为此我有些遗憾，所以在这里我想先回答一下这个问题——为爱归来。

大胖是为爱归来，而我也是为了我爱的家人归来。为什么这样说呢？因为我之前的工作总是四处漂泊，跟家人聚少离多，我们的沟通只能通过电话、视频维系，我缺席了孩子的成长，也没能在亲人身边陪伴，所以对家庭有很多亏欠。记得有一次，我刚从四川回家，凌晨两点才进家门，刚进卧室，孩子就从被窝里迅速地爬了出来，在我的脸上亲了一口，又立刻害羞地钻回被窝，他小声地喊了一声“爸爸”，这声夹杂着生分的“爸爸”，让我内心的愧疚更深了一分。

深情不及久伴，厚爱无需多言，陪伴才是最长情的告白，为了我爱的人我回到了新乡。在大胖工作，离家很近，公司“爱的福利”能让我在生活中有时间与家人快乐相伴，在工作中全身心地投入做事，找到了很好的平衡。

美好是在爱中滋养和成长的，其实我发现不仅是在胖东来，在很多人身上都有着美好的一面。记得那是一个冬天，我出去为顾客送货，那天刚下过雪，风也很大。按照惯例，我们需要提前联系顾客确认送货时间和地址，然后根据车程分配送货路线，在我们为一位大哥送收纳柜时，由于地址信息模糊，需要再次打电话确认，可当我们按照确认的信息到达时，却敲了半天门都没人。我再次给大哥打电话确认，得知刚才顾客提供的信息还是有误，为了不影响送货进度，我急忙背起柜子下楼。小区很大布局又比较复杂，本想再次给大哥打电话询问具体位置，可想到我们是给顾客送方便的，不是送麻烦的，已经打了两次，再打怕大哥心烦，于是我背着柜子问了好几个人，几乎横穿了整个小区，终于找到了大哥所在的那栋楼。
