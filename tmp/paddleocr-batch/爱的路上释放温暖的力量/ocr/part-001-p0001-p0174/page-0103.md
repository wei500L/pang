# 温暖这个年

电器部/苏琪

<div style="text-align: center;"><img src="imgs/img_in_image_box_270_419_1031_937.jpg" alt="Image" width="63%" /></div>


农历新年的前一周，我们接到了一条一个老年顾客的报修信息，老人家说是家里的电视机出故障了，维修师傅刘世杰随即上门为其检查，发现是主板故障，便为老人家设计了两种维修方案：第一，直接更换新主板，这样以来使用期限长，但价格相对高一些；第二，将主板发至厂家售后维修，价格低一些，但维修周期会比较长。

经过两天考虑，老人家表示，还是直接更换新主板，但是这时候已经是腊月二十三了，普通快递已经停止发货，正当我们努力争取让厂家为这位顾客配发配件的时候，老人家表示已经和品牌售后预约了维修，不用我们修了。本以为事情已经妥当解决，但谁成想到了腊月二十五，这位顾客又打来了电话，说还是希望我们帮忙维修，因为品牌售后表示配件要到元宵节后才能发货，那样就赶不上过年了。听到老人家失望的声音，我们也替他着急，这临近年根儿了，快递和物流基本上都停运了，而且大年三十儿的春晚咱也不能不看呐！一家人欢聚一堂看春晚，
