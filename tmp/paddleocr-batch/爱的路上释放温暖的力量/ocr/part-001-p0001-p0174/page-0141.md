# 我们的胜利

超市部/李恒蕊

作为一线员工，我们每天都在与顾客打交道，在服务顾客的过程中，我深深地感受到真诚的重要性。想顾客之所想，急顾客之所急，把顾客的事儿当作自己的事儿，才能与顾客达到心与心的交流，情与情的沟通，而我的这番感悟，源于我认识了这样一位老大爷。

和大爷初见是在一个上午，当时，我正在整理货品，他朝我径直走了过来，大爷两手撑着柜台，对着在柜台后的我大声地说道：“闺女，给我绞两斤瘦肉丝！”我问大爷：“您是要里脊肉丝吗？”大爷用两手支着耳朵对我说：“你说的啥？你看着弄吧，我听不清楚，反正两斤瘦肉丝就行！啥都行！”大爷这伸手的动作让我想起了我的父亲。我的父亲和大爷差不多，每次别人跟他说话都很费劲。大声地说吧，不礼貌，小声地说，他又听不清楚。可听不清楚吧，他又不好意思问，这么一来，他与别人的交流就越来越少，话也越来越少了。其实，他们的内心应该是很孤独的吧。想到这儿，一股亲切感油然而生，我看着大爷不自
