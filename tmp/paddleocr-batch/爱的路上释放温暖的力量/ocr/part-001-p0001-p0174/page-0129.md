# 天使在身边

超市部/杨健

东来哥曾说过：“要把顾客当作自己的朋友、家人，站在顾客的角度去思考问题。”一开始我是真的不理解，因为我很难想象在买家和卖家之间能有什么样的情感交流，虽然不是特别理解，但是我还是按照东来哥所说的去做，直到一个姐姐的出现彻底改变了我的想法，让我坚定地将企业理念作为我做人、做事的准则和信仰。

那是很平常的一天，一位姐姐来我们水产区买了条小鲫鱼，当我正准备处理的时候，姐对我说：“小师傅，这是我的鱼，能不能给我弄点鱼内脏？”当时我乐呵呵地对姐说：“可以！姐，我给您多弄点！”于是我顺手从鱼杂桶里拾了兜鱼，将内脏装好，递给了姐，姐拿着东西开心地走了。

在之后的很长一段时间里，我总觉得姐好像摸清楚我上班的时间似的，每次来都会找我买一条小鱼，然后再要一兜鱼内脏，时间久了，我们之间也有了默契，姐只要一来水产买鱼，就会先瞄一眼我那不大的杀鱼间，当我们四目交汇时，千言万语都不如一句“来了，姐？”然后，我就开始把刚杀出来的内脏给姐留着，因为刚杀出来的干净、新鲜。等姐买完鱼，不用她开口对我说，我就对姐说：“一看到你我就懂了，这不都准备好了？您看看够不，不够再弄点！”姐总会在这时露出特别灿烂的笑容。

就这样一来二往，我和姐成了默契十足的朋友。有一次我不忙的时候，姐来到我跟前跟我唠了起来，她说：“其实我上午就已经来了，不过看你太忙了，就没有打扰你，这不，我估摸着现在人少了就来找你了，其实呀，我要内脏就是去喂我们家的小猫，我可喜欢猫了！我家就有一只猫，是我在下班的路上捡回来的，当时它身上全是血和泥土，好像是被车压断了腿，如果不仔细看，你很难看出来那是一个生命，就这样还一瘸一拐地向我爬过来，当时我的心啊……然后我就把小猫抱回家收养起来了，只是我家里面只能养两只，可我家周围还有好多的流浪
