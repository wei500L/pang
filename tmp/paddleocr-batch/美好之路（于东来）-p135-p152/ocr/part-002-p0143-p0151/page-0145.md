# 学员班系列分享实录第六课 懂得生命的真谛，做轻松快乐的企业家

会议时间：2022年6月24日下午

会议地点：许昌胖东来时代广场六楼会议室

和大家分享一下，我们为什么要做这个课。因为我是没有计划的人，也不懂得计划，但是我的内心又有非常多对人性、对企业、对社会各个方面的感悟和经验，在带胖东来的过程当中，我发现做企业其实是，我想用这个企业去研究，要用什么样的方式、什么样的文化，才能够让我们在生活状态和方法上有更好的进步。
