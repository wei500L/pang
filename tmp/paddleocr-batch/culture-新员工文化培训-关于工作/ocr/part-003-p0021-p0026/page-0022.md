# 02送人玫瑰手留余香

值班电话响起后.....

“喂，生活广场鞋区吗？我想买一双鞋子等着急用”

“好的，您请讲有什么要求”……

昨天晚上八点半，鞋区主管张蕴接到顾客电话说是第二天早上9点多急用鞋，要参加一个比较重要的仪式，张蕴和他沟通选了几款鞋，最后选定老北京布鞋的黑布鞋，因为第二天早上急用但是晚上还没有时间过来买，就想让我们给送货，张蕴马上联系保安，开车去节约时间，让老北京布鞋区的张京和保安郭路一块去，想到顾客这么急，时间一点都不能耽误，张京赶紧检查整理好鞋，保安郭路开车，俩人一起尽快地把鞋送到顾客指定的地方——三鼎大酒店。

刚到地方就发现顾客已经在路边等，下车后马上给他重新确认了一下鞋子的款式，大小码和小票，顾客激动的说“你们真是帮了我大忙了，已经晚上了还麻烦你们跑过来”，并执意要他俩到里面吃饭，表示感谢后拒绝，“这是我们应该做的，其实也没什么，你有什么需要尽管说，我们会尽所能帮助”

帮助别人快乐自己，送人玫瑰手留余香，付出时是自己价值的体现，收获的是成就与感动，一个故事的结尾是另一个故事的开始，每一个表扬背后都是顾客对我们满满的鼓励与赞美，我们唯有把这种美好的力量传递下去，才能让爱的火焰越来越高，让我们享受做事的过程，享受生命的美好，创造爱，分享爱，传播爱，让爱的故事一直延续！

## 03聆听心声

在一次下午收碗的过程中，无意中听到了这样的一些对话，“唉，您说麻辣烫上是不是换师傅了？

“对面一个美女听了问：”为什么这么说呢？“”以前的麻辣烫可好吃了，这次吃着味道不怎么样？也没味，“这时我刚好路过的，听到了，立马询问美女：”怎么了？你感觉不好吃吗？“她说”嗯，你们这是不是换师傅了？“

感觉今天的麻辣烫不太对味，看到顾客吃的不开心，我心里怪怪的，说要不然我让师傅，再给你调点料，好，好，谢谢！不一会儿我从厨师那端来了小碗的调料，又担心他们添的多了，太辣受不了，便告知他们酌量添加，此时美女又问：这里没有放花生脆吗？我说有啊，她说为什么吃不到呢？

我告诉他们，因为花生脆太细小，他们用筷子在碗里是很难捞得到的，此时我又回到麻辣烫上，用小碗又为他们加了一些花生脆，并告知它们放在就餐的小碗里，用勺子才能吃得到，此时美女很开心的告诉我们说，其实我只是和同伴随便说了一下麻辣烫的口感，没想到你听到了会这么不厌其烦的帮助我们，我连忙说应该的应该的，看他们两个都是长发，而且吃饭特别的不方便，于是我又在腰包里拿出了我们为顾客备用的皮筋，她们把头发扎起来，这样吃饭就更加方便了，他俩最后笑着说，怪不到你们胖东来总是这么多人呢！
