# 胖东来如何打造快乐团队

信息来源：中国营销咨询网/周亮

他是8000多名员工的“大家长”，走进企业就像走进一个快乐的大家庭。他提倡“财聚人散，财散人聚”，他所领导的企业普通员工拿着全省零售业最高的工资。他用自己半生的坎坷遭遇，总结出的200字的企业文化里，“快乐”字样出现四次。他没有太多文化，却把“以人为本”这一最朴素的管理哲学演绎得淋漓尽致。他说自己是一个“行商”，一年待在办公室里的时间总共不到5天，所有权力下放，用人不疑，充分发挥员工个人才智。

## 8000 人的大家庭其乐融融

生鲜分割师比赛现场

走在许昌的大街小巷，无论是大型综合

商场、超市、服装市场，还是家电卖场、手机卖场及便利店，看到最多的是“胖东来”字样。而走进任何一家“胖东来”店，都挤满了正在购物的消费者。据了解，11年前“胖东来”还是一个只有4名下岗职工的30多平方米的小烟酒店。十几年来坚持“用真品换真心，不满意就退货”的承诺，赢得了广大消费者的信任，如今已发展成为拥有8000多名职工、

22个连锁店、年销售额5亿多元的大型综合零售企业。
