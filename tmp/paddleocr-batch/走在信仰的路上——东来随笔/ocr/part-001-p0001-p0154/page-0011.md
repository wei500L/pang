# 我们的使命

—— 传播先进的文化理念

先进的文化理念能够让人们更加懂得生命的真谛，用科学的方法引导和改善落后的思想观念，从苦悲文化向自信文化转变，从盲目的惯性追求向智慧的享受生命转变，并逐步向普世价值的文化方向进步！启迪理性、健康、科学、阳光的思维方式，成就轻松、自由、个性、品质的生活状态！
