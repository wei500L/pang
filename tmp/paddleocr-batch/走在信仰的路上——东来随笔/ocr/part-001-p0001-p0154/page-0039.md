# 我们的生活准则

—— 健康、安全、爱情、家庭、理财、居家、休假

当我们懂得了好的文化理念，

懂得了生活和生命是为了快乐和

幸福，就会逐步地摒弃掉不好的

奴性习惯，逐步地践行和运用先

进的思想和方法！关于健康、安

全、爱情、家庭、理财、居家、

休假等各个方面，无论在什么样

的物质基础上，都能合理地安排

和规划自己的生活，活得更加轻

松、热情、阳光、品质！
