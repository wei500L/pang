# 我们的愿景

# —— 培养健全的人格，成就阳光个性的生命

在公平、正义、自由、尊重、信任的体制下，引导大家懂得先进的文化理念，坚定“自由·爱”的信仰、践行行为准则及生活准则的基本要求，理性对待和完善人性的不足，丰盈精神世界，释放生命中美好的东西，从奴性走向个性，让每个人都拥有完整的、健康的、自信的生命状态。
