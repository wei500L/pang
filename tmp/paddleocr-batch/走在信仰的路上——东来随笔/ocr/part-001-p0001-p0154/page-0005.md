# 我们的信仰

# 自由·爱——用真诚和善良坚守着自由和爱的信仰！

以法律和不违背人性的道德标准为底线，以突出善良和个性为原则，不接受束缚，既不束缚自己、更不束缚他人，保持对每个生命、每个物质的尊重和敬畏。在此基础上，从精神自由落实到行为自由。

爱自己、爱家人、爱员工、爱顾客、爱社会，懂得爱自己、爱别人、爱万事万物！不违背自己的内心，做自己喜欢的事情，学会释放自己的爱，发挥自己的智慧和价值。
