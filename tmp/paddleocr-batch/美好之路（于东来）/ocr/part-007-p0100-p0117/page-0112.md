# 学员班系列分享实录第四课

时间：2022年5月24日

形式：线上视频会议分享

通过这几次的课程，我相信大家一定也有了一个相对比较明显的认识，大家对胖东来的了解还是非常表面的，我跟大家分享了好多胖东来的理念，这些理念都是世界上优秀的企业走过的路，包括他们现在应该做的。胖东来追求的目标也是为了让更多的人真正能活出轻松的、阳光的这种生活状态，体现更文明的环境，充满着公平、正义、尊重、自由，这样的概念。

胖东来能走到今天，就是因为坚定这些好的理念，然后去落实。用这个理念来鞭策企业的文化，鞭策企业的制度、标准和行为，才有了今天的结果。这种结果对现在的社会来说，可能是完全不一样的，在中国的企业家当中目前是没有的，包括我们这次的学员。

我们无论做什么事情，起码要有一个非常清晰的方向，知道走这个方向的时候，如果心不专，可能会有冲突，但这个问题将来我们再去讨论。现在需要解决的是最基本的，也就是做企业需要具备的基本条件，或者是做人最基本的条件。做人我们要真诚、要尊重、要信任、要友善，做企业也是要体现这样的理念。这样的情况下，我们才能让企业在一个健康的状态中发展。

现在大家没有考虑这些精神层面的问题，更多追求的是人生的成功，追求荣耀、面子、责任、使命。胖东来跟大家分享的是，要让大家做自己喜欢
