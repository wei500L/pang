# 实地指导分享 (江西上饶·嘉百乐)

江西嘉百乐商业集团管理有限公司成立于2009年，总部位于江西上饶。在以品质为本、德行天下的价值观引领下，用敢、快、好的作风致力于成为幸福的商业零售企业。集团下设行政、财务、市场、拓展、营运、采购与新零售等7大中心，确立“立足赣东北”的发展战略。以商业零售与儿童娱乐的“双核”引擎连锁模式，实行跨业态向消费者提供高品质的零售服务。
