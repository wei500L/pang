# 学员班系列分享实录第八课 工资决定企业生存，文化决定企业品质

会议时间：2022年7月21日

会议地点：许昌胖东来时代广场六楼会议室

参会人员：安徽六安绿篮子、江西上饶嘉百乐、浙江丽水万家惠、浙江杭州氿悦里、辽宁大石桥真实惠企业高管及业务团队，共74人

## 成就幸福团队，促进企业稳健进步，健康成长

今天，前段时间走访、调整的几家企业基本上都到齐了。这次让这几家企业来，就是让你们了解胖东来现在整个的经营状况，让大家慢慢地去熟悉怎样让自己的企业往健康的方向去发展。我们的目标就是要成就幸福的团队，促进企业稳健进步，健康成长。

胖东来也是第一次组织这种形式的学习，肯定也有很多的不足，第一是对大家的企业有所帮助，第二是对胖东来的团队也有所帮助。我们学习一定要是平常心，目的就是要成就自己，成就自己的企业。不要把胖东来这个企业看得很高，跟大家都一样，它只是一个平台。
