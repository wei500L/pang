# 胖东来是做文化，比做企业有价值

就像先进的理念，做企业是因为喜欢才做，不是因为钱，活得很累。

我一生奋斗的目标就是用理性的方法，从奴性走向个性。去做点事情，能用一些方法解决落后的生活习惯，是非常难的，但是能做一点是一点。起码让大家知道有一个成型的东西，知道怎么做能实现幸福的人生，现在我们初稿差不多有雏形了，下一步慢慢开始引导大家。

比方爱情，不喜欢就要放手，不能束缚对方，不能有家暴。总之，爱情是幸福的，不幸福就是错误的，要么改变你的方式，让两个人往一起走，快乐一点，要么就放手。底线是不能因为爱情变得痛苦，不能有束缚，首先是自由，在底线的基础上懂得什么是爱情，去实现爱情的美好。

还包括居家、孩子、父母、事业、休假、健康、安全等，每个方面都应该是美好的。

比如居家，挣钱少，租房子一样快乐。就像在清远，普通的员工租房子1500元到2000元就可以了吧，30%的收入租房子，一个月拿5000元，如果用心做工作，你的价值，你的专业能力，一年都会翻倍。但我们因为不懂怎样工作，干了10年还是个营业员。

像德国很多技术工人，干多少年，技工达到哪一级，收入达到哪一级，有最基本的技术底线，最低的工资能保持人们体面的生活状态，可能一个月是1600欧元到1800欧元，多少有点能力的可能都能拿到3000欧元、4000欧元了，除非不干活拿800欧元到1000欧元能保证生活，让人能有尊严地生活。

企业要规划员工应该怎样生活。做这些东西就是希望大家懂得应该怎样对待居家、理财等，即便一个月在清远拿3000元的生活，也会非常有品质。1300元租一个房子，独立的，有卫生间、厨房，自己屋里面打理得干干净净，上班的时候非常用心地去做，慢慢工作能力提升，用不了一年你可能就从普通岗位上升到技术岗位，工资会达到4000元，甚至第二年的时候达到管理层了。
