# 实地指导分享 (广东清远·满家欢)

满家欢超市成立于2006年，是一家坚持为消费人群带来幸福购物的美好商超。企业“以家文化”为核心、仁爱为发心，以使命、愿景、价值观为驱动，弘扬中华优秀文化理念和西方先进哲学思想，全力为家人提供快乐学习工作，开心生活娱乐的经营氛围。

以 “顾客得安心、家人得成长” 的经营宗旨，让大家享有健康、安全、轻松、自由的快乐生活。引导家人在科学信仰的路上创造感动、分享幸福、传播爱！让每位家人物质与精神双丰收，事业与生命双成长。共同打造为顾客、员工、行业、社会带来更大价值的美好商业。做清远幸福的企业，让零售更美好！
