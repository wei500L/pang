# 学员班系列分享实录第五课

时间：2022年6月1日

形式：线上视频会议分享

今天我们是第五节课了，我们也是边沟通边总结。上节课我就跟大家分享如何让我们的企业走到一个健康的运营状态，分享了相关的理念和方法。那么，我们现在面临的是非常关键的一步，我们要怎样走向一个科学的企业运营状态呢？可能我们大家都没有思考过这个问题。这也是我们举办联商东来商业研究院的一个初衷。我们想让更多企业家明白我们做企业的概念和方法。胖东来确确实实不是在做企业，而是研究怎样让更多的人活出轻松、阳光、自由的精神状态和生活状态。

目前我们所处的社会，一、缺乏信仰。这就导致我们做人、做事没有底线，不知道我们的人生应该往哪个方向走。二、我们的法律相对滞后。有的专业研究这方面的人或机构可能会让我们明白，我们的很多东西得不到保证。

谈到信仰，佛教对中国人影响最大，但是我们还不懂佛教。因为佛教是教我们活出人的状态，活出健康的生命。但是，我们可能是由于社会文化误读了佛教的真正价值和初心。我们的社会文化更多的是祈求索取，更多的观念还是想让老天保佑，求老天照顾，而不是让我们更多人懂得应该活出什么样的状态，应该有什么样的做人做事的标准。这就导致我们做企业形成了为了赚钱、为了利益、为了责任的风气。
