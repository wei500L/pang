# 零售的核心竞争力是什么

零售的核心竞争力是什么？最好的服务是什么？零售的核心竞争力就是商品。做零售的价值和使命就是服务民生，要保障民众的生活需求。民众的生活需求是什么？就是商品。所以说，我们核心价值就是商品。把商品做好，这就是我们企业最好的特点，也是我们企业最好的能力。最好的服务一定不是我们员工的行为服务，而是我们的商品。商品好才能让客户满意，客户满意中商品占80%，其他的占20%，这个概念大家要重视。

商品的价值我也写了，优秀的品类管理决定了企业的价值。什么是优秀的品类管理呢？要根据你的顾客群体决定品类范围，根据你的品类范围决定你规划的商品质量，选择哪种商品质量、哪个价位的商品。

企业的最大的特点是什么？就是价值。价值就是我卖的所有的商品都是物有所值，值得客户信任和放心，这也是非常幸福的。一定要让我们的企业走在价值目标上。

我们的目标到底是什么？我觉得还是自由和幸福吧。
