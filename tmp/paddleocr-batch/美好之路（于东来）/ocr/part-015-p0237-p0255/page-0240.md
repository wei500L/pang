# 实地指导分享 （辽宁营口·真实惠）

辽宁营口大石桥真实惠百货有限公司成立于2007年，初创于1999年。至今有32家连锁超市，包括便利店、标超、大卖场多业态经营模式，营业面积5万余平方米，员工愈2000人。企业始终秉承“诚信为本，服务为先”的理念，以“爱”为核心，通过“丰富的商品、合理的价格、温馨的环境、完善的服务”，将真实惠打造成为辽宁乃至整个东北地区的幸福企业。

2022年8月11日到8月12日，东来哥与真实惠全体管理层、店长、业务、企划、后勤人员沟通两次，分享内容较多，摘编如下。
