# 实地指导分享（青海·一家亲）

青海一家亲农产品有限公司成立于2011年，是集精品生鲜自采为主的本土特色超市，现有员工1700余人，目前共经营6家生鲜超市（其中5家门店位于西宁市，1家门店位于海南州共和县），总计经营面积42700平方米。在建配送中心1处，占地47亩，总建筑面积30000平方米，公司年营业额约6.7亿元。

一家亲生鲜超市自经营以来，始终坚持“诚信为本、商品为道、品质为魂、服务为尊”的经营理念，以“学习、改变、传播一家亲”为使命，致力于打造一个像家一样幸福温暖的企业，用优质的产品与服务回馈每一位消费者，承担更多的社会责任，给城市带来更多的美好。

公司的愿景是 “2030 年成为全国创新零售行业标杆”，未来一家亲将用更先进的理念，更时尚的购物场景，进一步提升超市服务功能和城市生活品质，传播爱与美好，努力成为青海乃至西北地区的地方名片。
