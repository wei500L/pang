# 学员班系列分享实录第二课

时间：2022年5月12日

形式：线上视频会议分享

零售有不同方向的路。你选择哪个方向，就要往哪个方向走。不同方向的路有不同的状态，有不同的结果。选择了哪条路，就会得到相应的结果。

我以前也跟大家一样，实现不了非常轻松自由的状态。身处的社会环境决定了我们不可能做到完全轻松自由的状态，我们还是要有相应的责任，这样就多少会累。

至于选择什么路，其实就在一念之差。打个比方，现在我们已经走了这条传统的路，如果我们想往另外一条路上走，不是说重新拐回来重新走，而是要转变思想，直接跳过来从这个点开始往那条路上走。这样的习惯导致整个生活状态完全不一样，这是我的经验，我以前跟大家也都一样。

## 与同频者同行

我主要想表达的意思是我们这十家企业大家相互也不是非常了解，对胖东来也不是非常了解。原来大家也没有想那么多，现在忽然之间就好像有点约束一样，这个跟大家平时想的不一样。原来你们只是想学胖东来，想把自己的企业经营好。我没有考虑过，大家也没有考虑过，现在要我们跳出经营企业的范围之外去思考。
