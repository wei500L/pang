# 爱和文明的布道者

媒体：《许昌晨报》 作者：刘丹凤 日期：2010年12月1日

他的名字无论是在零售行业，还是在企业界，都如雷贯耳。他的秉性、爱好，都是市民津津乐道的话题。自然，关于他的各种传说也多了去了。媒体朋友称他为“侠客”或“侠商”；老百姓喜欢叫他“东来”；而在集团内部员工之间，大家则亲切地叫他“东来哥”。

16年来，于东来从曾经的热血青年锤炼成了一个淡泊名利，追求“公平、自由、平等、博爱”的布道者；胖东来已然成为一个充满友爱、温暖满溢的大家庭，为推动许昌经济发展、加快许昌城镇化进程作出了杰出贡献。河南胖东来商贸集团已然成为许昌乃至河南的一张“名片”。

11月30日，河南日报、大河报、河南电视台、河南人民广播电台驻许昌记者站负责人，许昌市老新闻记者协会主席以及此次活动主办方——许昌日报社、许昌晨报相关负责人一行，相约胖东来时代广场，和于东来进行了一次历时两个多小时的深入交谈，力争还原一个真实的胖东来、真实的“东来哥”。

细节服务是永远的追求

做零售的企业千千万万，大浪淘沙，硝烟散尽，最让许昌人难忘、感动的是谁？非胖东来莫属。为啥？服务好呗！

从望月楼胖子店的“用真品换真心”，到“创造财富，播撒文明，分享快乐”，再到“公平、自由、平等、博爱”，胖东来最核心、最不容易让同行超越的地方就是服务。更进一步地说，是细节服务。这是胖东来的核心竞争力，也是东来迄今为止一直强调的东西。
