# 简简单单真汉子

媒体：《联商网》2008年6月23日

编者按：6月20日，“联商网月度人物”上线，22日晚20：09，一位不愿透露姓名的上海网友给联商网编辑部发来邮件，说他所知道的于东来。乍一看，惊讶；仔细端详，费思量；再看，可不是极有张力的一个画面，瞄的是多棱、复合的于东来？正如有网友在联商网月度人物官方群里所说：“自从联商出品月度人物，我便向河南的几个朋友咨询。碰巧，还有消息灵通人士，知道与（于）东来的一些私生活，甚至公开场合下出演（言）不俗的语录（语不惊人死不休的样子）。但这次，东来，超炫超牛，尤其在这次赈灾！”以下为邮件节选，以飨读者。

陆续听过一些业内朋友谈到于东来，本人也有幸见过其真人。看了联商的月度人物，就也想谈谈自己认识的于。随性率真，敢说敢做，是我对他的第一印象。他敢在公共场合上说黄段子，大谈性爱。也敢在私下面对陌生朋友袒露心迹。

年轻时，为感情，他几次割腕自杀，有了这些经历，他把生与死都看得很透彻，往往经历过生死的人都会明白，至少他更明白，爱惜自己才能爱别人。

对待员工，他保证，只要跟他干，让他们都能住上房子，买上车。目前他给企业处级以上的干部都配备了轿车。而现在他正在考虑为员工办理住房公积金。据悉，目前他所给员工的待遇在中国的零售企业中也是屈指可数。因此企业的员工流失率极少，除非被开除。他在公开场合说过多次，自己只需要2-3千万，余下赚的钱大部分给予员工，其余就留给企业做发展，所以员工都很敬重他，纷纷称呼他为“东来哥”。

对待朋友，他又慷慨仁义，在其他几位四方联采的老总面前，他谦称自己是小孩。与他们各自驾越野车往返滇藏，昼夜星辰，直抵布达拉宫，一路上所有的费用全部由他
