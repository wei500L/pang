# 胖东来辉煌真谛——战胜自我

媒体：联商网《店长》

作者：张一夫 日期：2009年9月

东来的成功只有一句话：战胜自我

许昌胖东来又一家店开业了。4月25日，人头攒动的许昌七一路周边，来自本市和周边县市的人们把胖东来新店包围得水泄不通。胖东来时代广场也叫国际商城，总体面积7.8万平方米，投资3.5亿，据本地商务局所发布的信息称，新开业的胖东来时代广场是河南省单体建筑规模最大的商业项目，预期未来年销售收入8亿人民币。

一座商业设施的开张，也许可以在本地局部范围内造成一些轰动，但是，没有哪个商超能像胖东来那样，早在商超筹建初期就一直备受市民关注。不知从何时期，当地五县（市）一区，大人孩子购物休闲言必“胖东来”。由于家乡在此，我从几年前至今很多次走进胖东来不同的店面，的确感觉到她的与众不同。每一次踏进她的超市或生活广场，叩击心扉的色彩，流光溢彩的店堂，意想不到的细微服务，充满强烈冲击力的林林总总的商品，总会让你不忍空手而归。我想，众多的许昌人钟情胖东来，也许还有很多无法言传的新鲜感觉。

关于胖东来，笔者至今没有进行过面对面深度的研究。惭愧的很，虽然我是许昌人，但是迄今为止，我对胖东来内部运作的一切也只是局外人远距离的感受而已。东来的管理人员包括于东来本人，对我来说从未谋面，形同陌路，去年末在第十届全国连锁经营大会上，本来有和于东来面见的机会，但最终因为事务缠身而失之交臂。

但是年轻的时候已经知道胖东来了。后来随着笔者涉入零售业，对胖东来和于东来本人的变化也就不自觉关注了很多。更多时候人们只是看到东来像一颗树苗一样，风里雨里日渐参天，但是很少有人去考究它最终成材的原因。10年前，甚至更远，当地几家呼声很高的连锁零售企业，做梦也不会想到，短短三四年会被东来远远甩在身后，有的
