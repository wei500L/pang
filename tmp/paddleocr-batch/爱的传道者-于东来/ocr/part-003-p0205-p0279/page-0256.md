# 满分100分，我只给自己打10分《许昌晨报》之城市运营功臣展示

媒体：《许昌晨报》

作者：刘丹凤

日期：2010年12月8日





当一个普通人的名字成为家喻户晓的品牌，成为一种商业现象后，想必很多人都知道，这究竟是怎样一个人？这究竟是一个什么样的品牌？又怎么成为一种商业现象的呢？带着种种疑问，11月30日，记者和于东来相约时代广场，进行了一场2个多小时的长谈。

“活得真实、坦荡，把身上美好的东西释放出来”

从1995年开店至今，胖东来已经走过了15个年头。“像个孩子一样慢慢长大，明白了很多道理。从当初的急功近利，到后来总结出来要踏踏实实地干，一步步地来。”东来说，自己也是一个有血有肉的人，不是神。本性很善良，但也有贪婪、自私、小心眼儿的时候。该玩的时候玩了，该干的时候干了。“我觉得人应该活得真实、坦荡些，让我们能更好地控制、主宰自我，越来越真实。无论身上存在善良与丑恶，都能正确理解和控制，并鞭策自己，不断向善良的方向学习和提升。把自己身上美好的东西释放出来，真诚对待亲人、朋友、员工、顾客。只有商品丰富、服务好了，员工、顾客、大家彼此之间有了更多真正的尊重和真爱，感情才会越来越深。”

东来说，这些年，通过不断学习国内外企业的长处，他对人、信仰、生活、事理的理解更深了。现在，他希望做个心底纯净的人，让自己善良的一面发扬出来。相信自己，相信身边的人，相信只要不断让思想和行为向善良和博爱的方向成长，明天一定更美好。

“我要扫厕所的话，就要扫出世界上最干净的厕所”
