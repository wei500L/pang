# 用积极的心态去欣赏世界 选自2010年第9期《胖东来人》

从宇宙到大千世界、从宗教神灵到万物苍生，一切生灵都在按照自然界的规律繁衍生息，享受着生命带给自己的快乐与苦难，追寻着美丽、自由、爱与梦想。人类从未因灾难和失去生命而放弃自己对美好事物的追求，信仰是沙漠中的一片绿色，信仰是暴风骤雨后彩虹高挂的天空，信仰是离别后梦中的拥抱，信仰是晨曦涅盘的重生，信仰是活在世间的坚强，信仰是眼睛里清澈如泉的自信。在今天这个灯红酒绿熙熙攘攘的世界，我们丧失了追求梦想的信念，忽略了内心的声音，原本洁净的心灵被无度的自私、贪欲、仇视、猜疑所束缚。当我们满足了温饱私欲，拥有了金钱权贵，突然发现自己失去了很多，再也找不到梦想中的自己。很多人都在抱怨和苦恼，究竟快乐去了那里？究竟自己是谁？为什么痛苦与磨难重重？是谁夺走了自己的幸福？脑海中疑问重重，百思不解。记得有一位哲学家说过当今社会人类最大的危机不是环境恶化、战争和瘟疫，而是人类信仰与道德的丧失。最终导致自私、仇恨、贪欲、灾难充斥整个世界，嫉妒与贪念让你无法控制自我，迷失方向深陷苦难。我们究竟要付出多大的代价才能拯救自己，很多人都迷茫。很多人都在寻找、在怀念儿时与最初的自己，也有很多人在无止无休抱怨这个世界种种的不公带给自己生存的压力。为什么如今物质生活超级丰富的今天，我们却缺乏幸福感与轻松愉悦，为什么我们的内心会矛盾重重纠结不堪，究竟信仰是什么？为什么我们会失去自己的信仰？今天我们就通过自己的工作和身边的事情来重新认识信仰，寻找属于我们的幸福。
