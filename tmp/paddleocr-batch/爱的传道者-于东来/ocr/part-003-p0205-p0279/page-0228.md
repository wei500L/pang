# 草根商人与“河南现象” 2009年5月8日《建业》76期

连锁零售业是我国目前发展最快的商业业态之一。自上世纪90年代初始，各地零售企业如雨后春笋纷纷成立。但近年来，丹尼斯、世纪联华等大型商超自郑州向其他地市的渗透，使本土中小零售企业面临的竞争和挑战日益激烈。

中小零售企业的出路到底在哪？是提升经营和管理水平、建立物流配送中心，还是联合采购？

作为本土零售连锁的代表企业——胖东来，13年前不过是许昌街头一家40平方米的糖烟酒店，而如今，它已成长为30多家连锁店，8000多名员工，年零售额5亿多元的大型连锁零售企业。而以其老总于东来为核心灵魂，结盟洛阳大张、南阳万德隆、信阳西亚等河南其他零售企业所创建的“四方联采”，更为国内更多的中小连锁超市企业突破目前桎梏提供了一种全新的思路和范本。

作为劳动密集型产业，零售企业所提供的产品，需要通过员工的服务来承载，其商品、服务、环境、价格，等等，最终去落实的，也是每一个员工。对此，于东来有清晰的认识：“做企业最根本的就是要让顾客满意，顾客满意了，我们的效益才能提升。”而要想让顾客满意，“企业老总首先要让员工满意”。

那么，如何让员工满意？

于东来说应该“让创造财富的人享受财富”，所以河南零售行业的最高工资，不在省会郑州，而在许昌、新乡：“胖东来”最基层的员工平均每月可以拿到2200元，课长每年收入在6万元，店长50万元，区域经理100万元，企业副总100万元以上，每个处长助理以上的管理人员都给配车。
