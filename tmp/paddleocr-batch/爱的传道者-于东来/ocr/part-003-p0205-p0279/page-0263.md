# 怀着阳光善良去做人

选自2011年第7期《胖东来人》

无论是顾客还是我们的员工，说起对企业的印象很多人都会谈到服务，从95年至今让我们感受最多的就是服务带给企业和身边所有人的变化。服务是我们企业的特色，也是我们企业文化的核心与灵魂再现，但是我们在面对各种糖衣炮弹和功利的种种诱惑时，我们却忽视了顾客的感受，忘记了自己的职责与使命，迷失了纯净信仰和真实的自己，最终让鲁迅先生笔下《阿Q》变成了现实中的自己，自欺欺人又妄自尊大、自我陶醉、自私自利，在失败与苦难面前，不敢正视现实，而是让自己的内心充满虚伪、自私、贪婪和自卑，用这种精神进行自我安慰，自我麻醉，最终伤害了自己又伤害了他人对您的信任与爱。服务是我们的每天工作的关键，爱是优质服务的核心，这种爱的服务充满自信、自然、没有任何利益的驱使，不多于做作，不走任何形式这种服务能让顾客感受到回家一样的舒服与温馨，同时也能让我们感受到个人价值的魅力与他人对您尊重，这种尊重与魅力会让您充满信心热爱这个行业、尊重这个行业。
