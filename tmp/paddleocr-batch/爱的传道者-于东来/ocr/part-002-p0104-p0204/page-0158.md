# 2007年关于春节放假的一封信

亲爱的兄弟姐妹：

随着企业的发展，虽然我们企业在管理方面还存在非常多的问题，但公司始终按照企业文化的核心，围绕着民主、自由、快乐的基础上，坚持以人为本的发展方向，而不断提升企业理念的品位。的确公司逐年在各方面（政策、收入、福利、技能、分配、标准、制度、系统等）有了很大的进步，但这与世界先进文化和先进企业还有很大差距，还有很长的路要走。但我们始终以满怀豪放的激情，投入到追求目标的行动中，让生活更有质量，让生命更有价值。

商业因与老百姓的生活息息相关，的确我们在节假日牺牲了很多的快乐，但为社会带来了方便，我们也觉得失落有了一些安慰，这也是这个行业的特殊性。

随着社会的发展，文明的不断进步，考虑到春节对中国人的文化生活有深远的影响，企业也想在这个行业逐步改变有些现状，让大家在这个重要的节日与亲人团聚、享受，分享一年成就的喜悦，放假时间为初一初二两天，相信大家会很开心。

因春节放假影响了老百姓的生活，固我们必须在节前给顾客做好解释工作，取得社会的谅解，在货源和销售方面努力弥补对老百姓正常生活的影响，这样我们也能轻松放心的享受假日的快乐。相信吧！我们的企业环境将越来越宽松，工作更高效，生活更幸福。

提前祝大家双节幸福、快乐、美丽、健康！

于东来

2007年12月21日
