# 2007年新年致辞

我最亲爱的兄弟姐妹们：新年好！

感谢你们辛勤的付出，感谢你们心灵的配合，感谢你们无数次的感动，感谢你们对胖东来的信任和执着，感谢你们对实现胖东来美好明天崇高信念的坚强意志，感谢你们为胖东来、为许昌的老百姓受了太多的委屈，感谢苍天让我们品尝了这么多感受，让我们经历那么多的酸与甜，更要感谢自己那一颗永不言败而且非常善良的心。

有梦才会有缘。相信每一位胖东来的兄弟姐妹们，在07年的每一天，团结在一起，开心、快乐、工作、生活。为了让我们的企业早一天规范，成为一个优秀现代化企业的楷模，配合公司的发展，倾尽我们每一个人的力量。相信吧，我们的工作环境会越来越好，工作时间会越来越少，工作效率会越来越高，工资福利会越来越多。整个公司的愿望是一定要让商业变成一个快乐的行业，让胖东来变成一个快乐的企业。

我们有了这种梦想，那就让我们心连在一起，用青春和热血铸就我们美好、浪漫的明天。相信自己是强者，相信自己是不可战胜的，相信自己是伟大的爱的传播者，爱的使者。

从今天起我们将忘掉成绩，一起从零开始，整装待发，为了共同的目标，勇往直前。

祝所有的胖东来人及其家属朋友新年吉祥，快乐健康。愿温暖、美丽、快乐、灿烂、亲情、健康、自由、幸福永远呵护着大家。

谢谢！

于东来

2007年2月17日
