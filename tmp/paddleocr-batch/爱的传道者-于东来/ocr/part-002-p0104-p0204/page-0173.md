# 不折不扣地兑现我们的承诺 选自2001年第3期《胖东来人》

1996年，在假货充斥，真假难辨的市场环境中，我们率先做出了“用真品换真心”的承诺，赢得了消费者的信任。

1999年11月，我们经过市场调研，了解顾客需求，又果断地做出了“不满意、就退货”的承诺，解除了后顾之忧的顾客，又对我们多了一份厚爱。

“用真品，换真心；不满意，就退货”，构成了胖东来承诺的全部内容。我们的目的只有一个——让每一位顾客都满意。承诺，也成为了我们企业文化中最具魅力的特色之一。

一诺千金！

在大大小小的13个连锁店中，我们的承诺随处可见；

每天班前的晨会上，我们的员工也常把我们的理念倒背如流……

承诺了，理所当然应该兑现。

反思一下，我们的承诺究竟履行得怎样呢？

翻翻我们的退货登记薄，每天都有几十起退货记录历历在目。从经理，值班经理，直至我们的员工，绝大多数人都能够理解我们的承诺内涵，都在实践中认真履行我们的承诺。

一位脾气暴躁的顾客，没听值班经理解释清楚，就砸烂了值班桌上的玻璃，我们值班经理眼里噙着泪水，脸上仍然挂着微笑。直到给顾客办完了退货手续，才躲到一个角落里让眼泪流个痛快……
