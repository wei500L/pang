# 放下功利 做生命的主人 ——2011年6月14日胖东来合作伙伴交流座谈会议纪实

“真正恒久的幸福和快乐是要靠用心去做、用心去体验的。”

很早以前，就想去举办这方面的座谈，对象就是那些想做小生意或者是想做些事的人。因为中国的现状很多方面还都在发展过程中，经济也在发展，很多方面还不规范。可能适合做小生意，因为做大企业技术底子相对都比较薄弱，从整个知识方面、技术方面来说可能都是一张白纸，更多是靠人生当中的经验去沉淀，并不是说是靠很多的技术和知识来支撑我们的事业，支撑我们的生活。我从刚开始做小生意的时候就有自己的梦想，那时候是为了挣钱满足自己，每月存几百块就知足了，谁知道后来赔了钱就只想挣钱把账还了，能让我回家就算非常幸福了。再到企业一步一步做的过程当中，不知不觉的就又多开一家店，又发生这样那样的故事。我也从一个无知的孩子逐步走向了成熟，不知不觉现在40多岁了，也感悟到了很多东西。只是有些东西明白了，并不意味着我能做到。但是在自己的心目当中，整体上是自卑的，因为有许多人都是自卑的，从脸上就能看出。自信的人看到任何东西眼神都是非常灿烂的、有热情的，我喜欢那样的心态。由于现实生活中方方面面的原因，自身性格又比较外向、心眼还比较小，有时候嫉妒心、占有欲也比较强。要控制自己不好的东西，真的是很难很难。所以我们每个人都一样，都有自己优秀和善良的一面、同时还有丑恶和不足的一面。我们要很好的主宰自己的命运，很好的主宰自己的人生。那我想更多的是通过这个企业的成长，通过我人生的这些经历，通过对这个社会的感悟，然后看我们到底想要什么，我们到底每个人的梦想是什么？可能像我这个年龄的人，都有很强烈的梦想。因为那时候还很单纯，不像现在社会比较复杂。每个人都有梦想，但是梦想是虚幻的。随着经济的发展，社会的发展，
