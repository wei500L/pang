# 如何看待物质财富

大家好！

胖东来发展这么多年，很多人为公司付出的太多太多，得到的太少，让你们受的委屈也太多啦，在这里我真诚的向你们道歉，我本意也是希望公司的发展能让更多的人有更好的未来，更多的人能随着企业的发展，理解怎样做人，怎样经商，怎样做管理，不断提升自己的综合能力，尽力体现自己的价值，靠自己的能力，无论是否在胖东来来工作，都能很好的主宰自己的人生，生活品质也会有更好的提高。但是由于我的能力有限，也不可能让每一个人都能满意，为员工发三年一万元的奖励，企业本身是根据能力尽量让大家多收获，企业发展经营的同时，不可能马上兑现，钱都发了，拿什么经营。既然有些人认为是白条，那就从今年起，取消这个奖励，也不要再为这件事情烦恼，公司对你们的回报就是每个月的工资。如果觉得在胖东来工作不值，我希望你们另谋出路，找自己喜欢的工作，觉得值就开心的工作生活每一天，这样也有易于自己的身心健康。以前的白条你们可以通过主管随时到公司换取，集资的钱早已通知，可随时取回，利息一同结算，请大家放心。如果在胖东来工作，哪些地方对不住你们的，请多谅解，这都是我的责任，无论结果如何，我都衷心祝福你们越来越幸福开心。也希望你们能把公司好的东西，用在你今后的事业上，对大家能有所帮助，不好的也不要太计较，当经验教训就行啦。我的确也觉得太累了，我也会根据自己的能力决定带多大的团队，公司今后不会有什么大的发展，机会有限，你们的路怎样走，你们自己选择，希望我们能开心的走自己的路。幸福取决于心态，好的心态一生都是幸福的，功利永远都是辅助自己幸福的伴侣，而不是唯一的目的。很多东西只有时间才能明白什么是好，什么是坏！祝愿更多的人更真诚，更善良，更幸福！

于东来

2009年10月29日

雪爱
