# 2011年关于春节放假的一封信

顾客朋友们：

新年好！

胖东来发展到今天，溶入了太多人的心血和温暖，我们时刻没有忘记我们的责任和使命。我们身上存在太多的不足和问题，我们不断强化着企业的管理和培训，让每一位胖东来人都不断提高专业能力和思想品质，尽最大努力保证顾客利益和顾客满意，让老百姓买到质量好、价格实、功能丰富，健康安全、放心、无暴利的商品。真心朝着让老百姓放心、满意、高兴这个目标奋斗，让更多人感受商业的快乐和尊重，而不是虚伪和奸诈。最起码不辜负社会的厚爱和期望。虽然我们还很年轻，还很不成熟，我们会用坚强的意志，不断学习，不断完善和成长，把胖东来品牌做成让老百姓放心的商业榜样，让商业这个行业为老百姓生活品质的提升，体现商业自身真实的价值和意义，让更多的商人都能承担起为维护老百姓的利益、健康、安全而做事。

由于中国传统文化的情结，春节家人团聚对于每一个中国人是多么的重要，从今年开始我们将在三十、初一、初二关门停业三天，让员工也感受一年最重要的幸福时刻，这对他们来说是多么重要的期盼，希望大家理解。

在这里全体胖东来人向大家说对不起，来年我们会用更大的激情严格要求自己不断提高，为大家提供更加舒心、快乐的服务。相信我们不会辜负大家的期望。

最后祝愿我们的国家更加和谐，祝愿所有的人春节快乐，在人生的旅途上幸福安康、生活充满更多激情和阳光。

于东来

2011年元月
