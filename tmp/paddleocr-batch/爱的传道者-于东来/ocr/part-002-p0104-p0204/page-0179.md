# 亦庄亦谐于东来

媒体：《超市周刊》 记者：陈岳峰 日期：2006年7月12日

在魏都许昌，平日里哪儿人群聚集最多？

答案恐怕非“胖东来”莫属。

拥有一两家人流不息的卖场，对于较为成功的零售企业来讲并不稀奇。但偏偏稀奇的是，“胖东来”在许昌的任何一家卖场，从早到晚，几乎每一个角落都塞满了正在购物的消费者，而且，人流永远都是在源源不断地涌入。

“如果是大幅度促销带来短期的这种现象，正常；但常年如此，简直就是奇迹。”某业内人士如此评价，于东来创造并正在持续着这个奇迹。

“经营奇才。”四方联采成员之一——河南大张实业有限公司董事长张国贤用这四字评价于东来。

短短10年工夫，靠着诚信、热情和踏实经营，胖东来集团有限公司董事长于东来把“胖东来”打造成了许昌零售业第一品牌，多年稳坐许昌商业第一把交椅。当地人把这个现象称为“东来现象”。

于东来和“胖东来”——这个人和他所领导的这家企业，靠什么成就了这等魅力？
