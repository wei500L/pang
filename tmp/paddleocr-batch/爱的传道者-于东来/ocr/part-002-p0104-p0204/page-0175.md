# 东来发展纵横谈 选自2002年第5期《胖东来人》

在集团公司成立，面临发展机遇的关键时刻，最重要的就是转变观念。

所有工作都必须严格遵循公司理念，任何时候都不能偏离公司理念。公司理念体现的使我们企业文化的精髓，也是我们企业的核心竞争力。

“不满意，就退货”的承诺、“让每一位顾客满意”的职责一定要落实到位，不能变通，更不能走偏。要让顾客真正满意，最终满意，而不是一时的满意。要在让顾客满意的基础上尽量为公司节省费用，而不是相反。所有退还商品的损失由公司统一承担，让顾客真正感受到我们的“超值服务”。上级要为下级创造优良环境，让他们轻装上阵，没有后顾之忧。各部门要克服本位主义、小农意识，用更宽广的胸怀，对待我们的事业，为我们的品牌增值。

要尽快制定、完善各部门职责范围、工作流程、工作标准和考核标准，明确各部门的职责范围、权利。要落实到每个部门、每个单位、每个楼层、每个区域、，每位员工、使我们的各项工作真正规范起来。

沟通必须加强。既要严格管理，又要关心爱护。当员工有困难时，要给他温暖、给他帮助，真正体会出兄弟姐妹心与心的融合，让员工焕发出青春的热情，投入到工作中去。要让我们的员工在工作时的心情，象外出旅游和生日晚会时那样灿烂，我们的企业才能充满活力，我们的环境才会更加健康，我们的团队才会更有凝聚力和战斗力。

对有潜力的员工，要有意安排他们轮岗，让他们熟悉工作流程及业务知识，要把他们培养成复合型人才。

公司在发展，人员素质要不断提高。要树立团队学习意识，要把对外招聘和对内竞聘相结合，让层层都看到希望，要给人才一个充分发展的平台，要用宽阔的胸怀接纳人才、包容人才、拥抱人才。
