# 做有明确目标和人生信念的人

大家好：

转眼之间又进入了新的一年，总结十五年来的每段过程，企业始终围绕向善的原则，逐步提升企业的文化品位。企业文化更清晰化，而且不断深化，企业文化的方向也一直坚持服务员工、鞭策员工、指导员工，确定清晰高尚、乐观人性化的人生目标的原则，使大家有明确的人生信念和鞭策自己行为的标准，使大家在有限的人生旅途上用乐观的态度充分分享生命中的酸甜苦辣。尽能力让每一天都是健康的、充实的，有意义的、有价值的，让每一个胖东来人能了解自然的形成及循环的规律，了解大自然的博大；了解人类的形成与进化；了解人类文明的进步与各种文化信仰的发展；了解东西方文化的差异与现状；了解地球每个区域、环境、文化之间的关系和相关作用；了解我们中国文化的历史和现状；了解我们文化的优点和缺点；了解目前世界多种文化信仰中，有哪些是要学习的，那种文化能让我们身上的嫉妒心、贪婪和过度自私，能控制在合理的不影响心理健康，不影响乐观快乐的尺度之内。使我们自己能更好的控制主宰自我，越来越真实，无论身上存在善良与丑恶，都能正确理解和控制并鞭策自己不断向善良的方向学习和提升。使自己的心胸越来越宽广，使自己更阳光和自信，让自己的心灵越来越纯净，让自己能很好的对待和主宰生命中的功利，而不是成为功利的奴隶，能让大家彼此之间有更多真正的尊重与真爱。
