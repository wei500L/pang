# 生死不顾，救人揣着身份证

媒体：《许昌晨报》

记者：罗校远、张铮 日期：2008年5月26日



5月20日上午，胖东来商贸集团有限公司救援队从四川灾区回来了。

回家了，他们应该高兴。在救援队员的脸上，却看不到一丝笑容，有的是对灾区人民的牵挂和不舍，有的是想用行动延续对受灾者的爱。

## 每天 救援队员都要疏散很多群众

5月13日下午，胖东来紧急组建救援队，带着100万元现金、几十万元的救灾物资驰援灾区。次日，安全抵达距离汶川县100多公里的绵阳市，救援队将100万元现金和救灾物资捐给当地政府后，赶到了受灾严重的绵阳市安县。经过大家努力，截至5月18日，他们一共救出16名幸存者，疏散5000多名群众。

5月20日下午，从救援队员几度哽咽的讲述中，我们看到了他们冒着生命危险救人的场景，听到了“有困难，找河南人”这句由衷的赞许，闻到了让灾区群众一生难忘的菜香……

## 首日 援救一名被埋老人 只用30分钟

5月14日，到达四川省绵阳市后，救援队员顾不上休息，在当地政府的安排下，直接来到灾情比较严重的绵阳市安县。道路被阻断、房屋倒塌，无家可归的群众在废墟旁呼唤着亲人的名字。这些情景让救援队员揪心。救人，救人，救人，成了救援队员共同的心声。

长途跋涉千余公里，来不及休整，就有群众向正在集体啃方便面的救援队员求救，说安县秀水镇有一位老人急需抢救。时间就是生命，初来乍到的救援队员立即跑步前往。
