# 2002年新年慰问信

亲爱的兄弟姐妹和员工家属们：

你们好！伴随着新年的钟声，沐浴着和煦的春风，中华民族的传统节日——春节的即将来临。我代表东来公司领导班子，向我们的1700多名兄弟姐妹，以及你们的新人们拜个早年，你们辛苦了！愿你们在新的一年里身心健康，万事如意，幸福快乐天天伴随！

过去的一年，是我们的事业迅猛发展的一年，劳动店、建安店相继开业，新年伊始，我们好戏连台，生活广场、光明店、望田店三喜临门，尤其是总面积20000多平方米的胖东来生活广场的开业，标志着我们的事业又发展到了一个崭新阶段

随着事业的发展，我们的思想逐步走向成熟，我们的精神境界也随之得以升华，我们更加明白了做人和经商的道理，反思我们的不足，清理我们的思路，为我们的事业稳步、健康发展奠定坚实的基础。

事业发展的每一个台阶上，都洒下了全体兄弟姐妹辛勤的汗水，也凝聚着我们员工家属的心血，每一位员工的背后，都有着无数亲人们默默无闻的牺牲和无怨无悔的奉献。你们也是胖东来的功臣，同样也是我们事业的坚强后盾。

“每逢佳节倍思亲”为了万家团圆，为了父老乡亲的方便，我们全体员工仍然要坚守在工作岗位。“辛苦我一个，方便千万人”能为家乡父老乡亲做点事情，我们虽苦尤甜。相信也能得到员工家属的支持与理解！

展望未来，迎接挑战，我们任重而道远。请大家相信，东来会带领胖东来领导班子，努力给大家营造一个优良的氛围，使大家能够充分体验工作的快乐，感受生活的幸福。前面的路也许还会有风有雨，但只要我们上下一致，齐心协力，我们的今天会更加充实，我们明天会更加美好，我们“创中国名店”的目标一定能实现！

祝大家春节愉快，合家欢乐，年年开心，天天快乐！

于东来

2002年2月10日
