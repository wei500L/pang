# 让我们的爱如玻璃一样透明 ——摘自2011年3月30日中国合作贸易协会会议讲话纪实

非常感谢大家到许昌来，举办这样的沟通会议还是第一次，因为我们在很多地方相对比较保守，我们的理念和观点可能与现实生活还存在很多差距需要磨合，所以我们现在做的更多的事情就是用心练内功，不断去寻找学习的目标和优秀榜样，让自己的行为与爱能给更多人带去幸福与浪漫。

企业发展到今天这个结果谁也没有想到，走过了十几年的路程感悟了很多，让我们明白了我们需要什么，我们应该设定什么样的目标，制定什么样的战略，到底我们要怎样来让自己的一生更有意义、更有价值，因为我带这个企业有十多年了，这里面也融入了很多我个人的性格。

我这个人从外表看是没有规划和计划的，很随便，喜欢追求自由，喜欢围绕公平的道理去做事，追求浪漫、追求幸福、追求快乐，最向往的地方是像瑞士、法国、德国、奥地利，像北欧一样很有风情，很坦诚，很真实，不喜欢虚伪的东西，喜欢做人做事彼此沟通都能讲实话，说真话，没有那么多客套。我们在做的过程当中，一直在培养我们到底应该怎样去获取这种幸福，怎样让自己过的更充实，怎样让自己能找到真实的自己、知道自己是谁，最终慢慢明白什么是幸福。
