# 如何做后勤

地点：时代广场会议室 时间：2010年11月29日

昨天晚上贴子上写时代广场湘菜馆和电器电梯装修过程中出现安全事故，虽然没有形成大的事故，每次我在会议上非常明显的传达一个信息，就是安全，公司发展到今天，有这么多的店我不可能每天跑去守着，这要有一个完善的制度，很多地方要有一个标准，各个方面不允许我们对工作有任何敷衍。最近一段时间一直在说这种事情，公司的安全，包括公司高层的，那么公司未来希望追求这种公平，自由、快乐、博爱，这种理念最终的结果希望在这个平台上生活的人明白什么是真理，什么是道理，什么是乐观，什么是幸福，什么是价值，什么是人生，到底追求的是什么，我希望在这个企业工作的人，都能有所收获，能真实感悟到人生最宝贵的是什么，感悟到我们应该往那个方面去做，更多的社会现实造就了我们，促使了我们对功利的追逐，整天去讲这种道理，但是更多的人回到现实当中，听的时候可以理解，但是做的时候忘完了，也不说完全忘完了，忘掉80%，只剩20%，所以才会有这样的结果，但一个企业的最终的发展结果，是去造福一方人，发展过程当中这个平台能让创造这种价值的人，去分享他的快乐，分享他的酸甜苦辣，分享他的成就。在我们的企业当中，走着学着，我们努力去探索，最终我们越来越清晰，越来越明白，应该往那个方向去做，去走，我们可以适当的去改变自己，像我们的嫉妒、自私、贪婪一样，我们改变不了，因为传统文化已经融入到我们的基因当中了，在方方面面都体现出来了，不可能在我们这一代说改变就改变了，这需要一个好的环境。如果我们的环境非常强大，改变的会快一些，如果我们的环境力量比我们自身的力量强，比如你说你很保守，但如果你扔到一个非常开放的环境中，你马上就适应了，在国外、香港你改了随地吐痰的习惯，这就是环境的力量。在我们现实当
