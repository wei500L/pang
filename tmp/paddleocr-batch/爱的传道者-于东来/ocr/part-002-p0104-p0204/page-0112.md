# 从细节谈定价管理

时间：2010年11月18日下午5点 地点：时代会议室

目前企业有很多地方还不规范，经营是有自己的经验，但想把这种经验清晰化，不管是对商品的品类管理，还是对营销政策的管理，或是对绩效的标准等等，都要行成一个清晰的书面形式。现在还不能要求太高，因为能力做不到要求太高的话下面执行不了。以前也有过这方面的经验，现在还处于初级阶段，为什么这样调整，是不想影响现在整个的经营，逐步的往好的方面去走。主要的目的一是规范，二是提升能力，以前觉得力不从心，现在慢慢的每个部门都进入了角色。我最大的缺点就是闲不住，很多东西必须自己一步一步去做，方方面面的东西我都要考虑。但我是一个乐观的人、快乐的人，也不会被事业困住，该努力的努力，该玩的玩，这样子才感觉生活是有意义的。

现在我的心态好了很多，毕竟现在的经营状态各个方面相对的稳定一些，但企业目前经营状况下哪些东西能力是什么样，不规范是什么样，规范是什么样的，优点在哪里，缺点在哪里，大概我是知道的。如大众服装吧，比方说毛利率合到25%，按正常的好的应该达到30%，还差5个点，最重要的环节是因为你的能力还达不到，这5个点需要在你的能力上来弥补，而不是从价格上。如进服装，出厂毛线多少钱一克，加工费、设计费是多少，从这上面把价格压下来。就像咱的自营品牌一样，不能做到百分之百，但如果能降到15个点或20个点，平均下来就能做到5个点，然后慢慢往这个路上去走，哪怕5年的时间能做到初级阶段。服装第二类，设计到联营这一块，比方说毛利率40-50%，但将来要达到50你的周转是什么样，商场扣点是什么样，怎样保证毛利率，商场留多少，老板留多少，员工多少，非常清晰的一个路，销售和盈利匹配不匹配，这两条路是清晰的，让大家都明白必须往专业上走。如童装类的毛利率哪一类没有做好，专
