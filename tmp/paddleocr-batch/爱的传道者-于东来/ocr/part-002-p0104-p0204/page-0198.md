# 志愿者于东来

作者：安县 帅士象 日期：2008年6月3日

我所接待过的第一批志愿者来自河南许昌，这是一个民营商贸企业，老总叫于东来（后来我才打听明白）。大地震后，他带着自己的60个员工，全着迷彩服，第一时间驱着八辆车，两天两夜后来到绵阳市，向市政府捐了100万后，就带人来到了我们安县。

他们说他们要去北川县，车上准备了许多铁锅之类的东西，要去被摧毁的北川县城掏人。我很理解，在最惨烈的地方，过程才最为精彩。把他们带到我们的重灾地秀水镇后，我知道他们会明白他们走错了地方，晚上就会去北川的。到了晚上，我果然在破损的县城看见了他们的车队，一会儿就不见了，我知道他们一定去了北川县。

三天后，我意外地看见于东来回来了。我知道他们要回河南了，是来告别的，是否会向政府要个证明什么的，回去好向许昌市政府汇报，于是我跟在他的后面，想听他对县上的领导说些什么，他说他们要三百双手套，三百个口罩，五箱生理水，原来他们并没有离开安县，而是在安县的一个重灾地茶坪乡下面整整干了几天。看来他们还要狠干几天，我自告奋勇为他的车带路，最后在如山的救灾物资中找到了他们需要的东西。

此后，我再也没有看见于东来，不知道他们何时离开安县的，我好想再看看他的影子，看见他的影子我就肃然起敬，我想对他肃然起敬几百次。

大地震中，我看见了无数的作秀者。国家级的、省级的，他们风一样来比风走得更快，这些庸俗的灵魂，想想他们做出高贵与难过的面孔，悲天悯人的熊样，我都想发呕。

而于东来，是让我想想眼睛都会湿润的一个普通而又极不普通的志愿者。
