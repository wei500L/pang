# 与IGA马克的沟通

时间：2010年11月9日上午 地点：时代会议室

“希望我们中国更多的人明白，要真实活着、要坦荡活着、要幸福的活着、要更有自信的活着。”

企业能走多远也许并不重要的，重要的是有人去重视你这个文化，也许我不在了这个文化也就没有了，几十年后有人重拾这个文化，我希望更重要的是去感受这个过程。最终找到自己的信仰和理念，这只是个梦想，将来实现不实现无所谓，重要的是往这个路上奋斗了。

做企业文化这十几年的过程当中，看到了我们中国人的心态在很多方面不成熟，因为受中国传统文化的影响，无论遇到什么样的事情，更多的是没有自信心，因为心态的不成熟，对生命的理解，对生命的恐惧，对失败的恐惧的错误理解，而感到痛苦。在这么多年的总结当中，在这样的大环境下自我的能力，自己的创造力，自信心的这种天生的不足，而西方国家在这种尊重自然的文化当中，对生命的理解，对人类进化的理解，已经很清晰了，我们现在更多的不知道人为什么而活着，明白怎样活着，可能我们现在很多人不明白的事情，我希望我们中国更多的人明白，要真实活着、要坦荡活着、要幸福的活着、要更有自信的活着，至少活这几十年感觉是充实的、幸福的，不像现在我们总感觉我们是被这种痛苦所折磨。所以我就一直在探索能进步的文化，包括基督教、佛教、伊斯兰教等文化，不管是什么样的信仰，什么样的文化，一切都按照不违背善良，不违背大爱这种原则，去展开生命，去对待工作和生活，到现在为止我们也不是非常的清晰，但是也进步了很多，我相信只要坚持这个梦想，你会一天比一天更幸福。

我看到了我们的企业比原来更坦荡、更真实，也知道爱家人，爱朋友，爱顾客。西
