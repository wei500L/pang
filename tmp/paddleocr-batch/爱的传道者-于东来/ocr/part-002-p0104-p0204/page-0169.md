# 做人实实在在 做事精益求精

随着时间的推移，随着企业的发展过程，随着年龄的变化和周围环境的改变，使我们的阅历越来越丰富，思想越来越成熟，看问题越有深度，越敏感也越清晰，我多么高兴我们有正确理念的鞭策，我们不断强化围绕善良的发展方向，乐观的体现我们的言行的提升，我们综合能力、综合素质的提升，而且我们一定会持续紧定不移的向我们所制定的理想方向成长，每一次的重复，每一次的要求，就真的是在传递、传播正确的道理，是多么想让更多的人明白胖东来的发展，是为了想把每一个胖东来人都培养成真正乐观、坦荡、勤奋、实在、善良、有爱心的、充实的、自信的、阳光的、快乐的优秀人才，我们每一个人都有非常清晰的大信念和大理想（幸福和快乐），都有最基本的做人做事原则，不利用别人，不伤害别人，在不违背善良的原则上，为人处事。

我们做人实实在在，做事精益求精，勤奋认真，不急功近利，一点一滴的去做，有这样的心态，有这样的行为，还有什么我们不能做到，还有什么我们实现不了。大家一定要明白，不要让功利之心左右了我们的灵魂，为我们带来无尽的烦恼和痛苦，而是让名利成为激励我们健康成长的动力，自己做的好，就多帮助别人，而不是表现自己，别人优秀，就送上祝福，并认真的向别人学习，调整好自己的疾妒心，让自己向着轻松自然的方向转变。这样你才会更成熟、更大方、心胸更宽，更成熟，也更有魅力，自然就更自信。如果每一个胖东来人都能做到这样的标准，你说我们会不快乐吗？我们的团队自然是优秀的团队，是善良的团队，更是英雄的团队，我们有缘进入这个行业，我们就富有激情的热爱着商业这个行业，快乐的把商品做好，环境做好，服务做好，价格做实在合理，让顾客更满意、更放心，你说我们会没有成就感吗？顾客也一定会开心的，只有这样坚持不懈的努力，我们就永远是自己命运的主人，希望大家明白这个道理，明白
