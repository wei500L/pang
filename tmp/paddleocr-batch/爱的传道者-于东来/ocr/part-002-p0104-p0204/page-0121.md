# 强化执行力

为了持续推动企业文化发展，培养高素质的团队及每一个胖东来人的能力：公司要求每位管理人员及员工：忠诚工作、岗位标准、制度严格执行。

对于工作期间，管理、工作不作为、松懈、懒惰、不认真、抱怨、不热爱企业；专业知识、技能不合格，严重违背企业理念的，各级主管要严格履行职责直接予以清退。强化制度执行力，保证顾客满意和企业品牌的健康成长，否则当事主管直接免职。平时的表现也直接影响将来的职务晋升与福利分配，希望大家重视。

每一位胖东来人必须严格要求自己，时刻铭记公司文化理念。做一个品质优秀的、技能专业、健康乐观、意志坚强、有理想、有追求、有品位的高素质人才。使我们的工作专业、准确、高效、舒心。这样的我们才会有更好的物质回报和精神回报。下班后我们的生活才会更轻松愉悦，更有激情和活力。企业发展的目的不只是让大家有物质的满足，是要大家成为专业健康乐观幸福的人。我相信这也是每一位胖东来人来这个企业工作的目的和期望。再严格的制度只要大家认真的遵守和执行都不会累，相信我们一定努力让结果越来越好：让爱有更大的力量和体现。

于东来

2011年1月4日
