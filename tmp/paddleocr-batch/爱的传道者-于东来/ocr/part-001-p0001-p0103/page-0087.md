# 不要迷失自己 ——2010年8月13日服装部管理层讲话记录

地点：时代广场会议室

前一段时间对个别部门的管理层进行了沟通，沟通的主题是做任何事情都不要迷失自己，因为只有目标明确我们的将来才能向更好的方向发展不至于变质，遇到什么样的困难、什么样的问题，大家都要明白不管做什么，我们都要拥有一颗感恩的心。感恩的心是为了让大家快乐，同时自己也开心。如果我们做任何事情，总觉得自己付出太多，而忘了自己的责任和使命，即使公司给你再多的物质东西，你从心理和精神上也不会觉得快乐。一旦离开企业的时候总感觉

自己很委屈，可是你是否想过，你做的真的很好？

现在我们的部门是一个很有战斗力的部门，是一个很团结的部门，充满着激情的部门，随着物质条件的改变，环境的改变，慢慢的问题就出来了，如嫉妒、自私、虚伪等等，企业不需要这些不好的东西，我们需要的是乐观、正义、勇敢、节制、感恩、舍得这些积极向上的动力做为指引。所以我们一定要明确自己的方向，不要迷失自己，朝这个方向不断地去改变和进步，你会发现快乐就在你的身边。

我们企业的未来和理想是要做一个乐观的企业、一个快乐的企业、一个有品质的企业。公平、自由、快乐和博爱，是我们所倡导的理念的主题，那么我们就要坚定不移的围绕这个主题来展开我们的事业。如果每个人都认为有钱和权才算成功，那么这样给你再多的钱、再多的权、再多的名利，你快乐吗？我们再回味一下过去，现在的你们有钱了，有功利了，可你们有以前那单纯的快乐吗？有以前那简单的幸福吗？如果你不能把握好这个度，那么你就会失去一个纯真的心。随着整个环境的变化，越来越被物质所诱
