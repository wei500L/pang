# 放下功利之心去做管理 ——2010年10月9日店长会议录音记录 时间：10月9日 地点：三楼会议室

围绕着企业理念去做管理和做事的时候，就会很轻松，心里轻松，不是为了每天追求功利，而是做真实、快乐、幸福的自己，不伤害他人、利用他人、违背真理。你做事根本不知道什么是对，什么是错。所以说在做这种事业工作的时候和生活的时候，你就会没有一个清晰的目标，人遇到任何诱惑的时候，你就迷茫，迷茫了就会很累，很痛苦，企业这种氛围就感觉就是压抑的。咱有这么好的理念，引领企业的发展，最其码我在这个事业方面，我感觉我是放很开的一个人，不管对钱对啥，我对钱也很在乎，但是我能放的很开，但我对感情放不开，心眼很小，很累，不管是从感情上，从事业上能放得下，你才是真正的轻松，不是为了去追逐他的一个结果，是为享去尊重，最其码去感受生命当中点点滴滴这种故事，而不是去追逐这种功利，追逐那样一种结果，而在实现这个目标的同时，去分享你的价值，不管是在哪个层面，我是当员工也一样过的很快乐，收入没那么高，根据收入层次来规划我的生活，一级级这样去做，我的将来收入高了，有10万，有100万，有1000万，有上亿了，我根据我的层次和我的价值来分享我的生活，分享我生活的这种品质，不要去好高骛远，为啥咱们企业，你要是想挣钱，咱去开个店，稀里糊涂开个店，咱都能挣钱，别人那一般的店还能挣钱，企业还发展的那么好，我为啥发展咱们企业一直都是如履薄冰呢，不是简单的单一的为了挣钱，这里面渗透了感情的东西，让有价值一点，明白一种道理，让自己活的有价值一点，让自己也明白，让底下人明白，明白真正的道理，明白道理的目的是什么，是为了让自己开心一点，有些东西是有局限，束缚了自己，或者是物质的东西束缚了自己，或者是感情
