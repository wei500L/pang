# 用良好的心态面对严格的管理制度 ——2010年2月18日珠宝部晨会与员工沟通

从今天开始，对每个部门的标准，不管是工作标准还是环境标准、服务标准往深度考核，这样考核的目的是培养我们员工来上班的时候涵盖哪些内容，来上班的时候怎样把工作做得更细致，在各个方面，使大家的能力有更好的提升，使我们的管理越来越有序。之前虽然每天做了考核，但我们的考核还是非常虚的，没有达到标准，还是差很远。所以说公司今年2010年的目标是让整个公司的管理，团队的能力和效率有大的提升。如果团队效率提升了，我们的工作环境、工作时间都会有大的改变，同时往各个方面会有更专业化的发展。公司的目的是让企业的每个员工从各个方面都能获取能力的提升，这个时候不止是在这个企业里获取了一份工作，更重要的是不管是在胖东来工作或者是走出这个企业的能够拿更高的收入，能养活自己。所以这五天的时间在考核的时候会要求的一天比一天严，这只是一个切入点，考核的目的就是培训大家在工作方面怎么做，在生活方面怎么做。然后使我们的企业在整体方面充满了激情、阳光的团队，我们在这个企业工作，不仅仅是在工作，而是喜欢这份工作，分享这份快乐。达到这一种结果的时候就需要我们的管理能力有大的提升，我们之前更多的是注重亲情，但现在企业太大了，单一的亲情企业肯定支撑不起来，肯定要靠制度来管理这个企业，所以说将来肯定会要求越来越严，也希望大家都能够理解，严格要求自己，使自己加快提升，如果万一遇到这种考核的时候，处罚到自己的时候，要有一个良好的心态，找出自身存在的问题，然后今后慢慢去完善、改善自己，使自己越来越强，千万不要有那种抵触心理，感觉处罚到自己就很不开心，你想想，打个比方，你现在一个月工资查到一项扣10块钱，一个月罚300块钱，影响不到什么，但你的能力是不是会提升很多。下次你是不是
