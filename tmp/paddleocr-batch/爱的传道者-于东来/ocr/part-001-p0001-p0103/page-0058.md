# 创最优秀的团队 做最优秀的人

看了上期报纸刊登的《送货遭遇》、《用服务感动顾客》后：

如果每一个胖东来人从工作和生活上为别人带来无穷的温暖和幸福，让我们有更多的感动，我们将是无法战胜的团队和个人。我们真正做到了爱的天使，我们也将是世界上最快乐的人。我相信我们的每一个兄弟姐妹们。我会和大家一起不断提升，把胖东来品牌，从品质、忠诚、能力、爱心各方面打造成世界上最优秀、最快乐、会干会玩的魔鬼团队。因为我们是爱的摇篮，爱的使者，我们一定会把爱撒向人间。

每位胖东来人必须用心学习执行胖东来理念，一定落实，不走过程，保证企业的有序提升。三年时间把胖东来所有门店从环境、设计、气氛、个人能力、效率、收入、团队凝聚力、贡献度、品牌美誉度达到中国最优秀的标准，公司从各方面也按计划进行。请大家放心，只要我没有不可抗拒的原因，我会让你们因胖东来更自信、更幸福、更快乐，也更成熟。我希望你们不畏艰难险阻，坚定热爱企业和家的信念，不断完善和提升，为胖东来品牌创造更大的美誉，为顾客带来无穷的温暖。我们的目标不但不断的提升，更会不断的实现。不经意间，你会发展你的身上会有如此的潜能和无穷的才华，因为这都是兄弟姐妹相互帮助，共创环境所感染而来。认定目标，勇往直前，胜利永远属于那些不断进取的人。

目标：3年—5年国内一流；10年—20年世界知名的商业企业

只要付出一切都能实现。做到也要做，做不到创造条件也要做到。因为这是我们的责任和价值。

让更多的人生活好起来，让更多的人感受商业的快乐和幸福。

于东来

2009年12月
