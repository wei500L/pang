# 如何做一名优秀的家长 ——2010年7月15日会议内容

地点：时代广场会议室 对象：时代广场课助以上

我以前给大家说过：企业给大家带来的规划，使我们每个人都能去认识自然，认识社会，认识现实，然后知道我们所存在的位置，认识我们身上的优点和不足。我们用什么办法来对待自己，对待生活，对待工作，然后明天的结果会是什么，一年，二年，十年，都能马上看的非常清晰。

在整个企业的运作当中，因为我们处在一个比较复杂的环境状态，因为我们企业在很多方面不规范，我们的能力达不到，就会导致我们工作脱节。打个比方就是拿西方的文化体制让我们去实现民主，但我们做人的基本标准，思想的基本标准，技术的基本标准达不到这个层次，民主的结果可能会导致很多人产生功利之心。

再打个比方：民主考评的时候，我们比着拉票，等评议上去以后，基本素质达不到，他满脑子想的不是怎样去造福老百姓，造福村民，而是想着从中渔利。这样的价值观就导致大家对环境会更加失控，从而产生了混乱，小的混乱会给企业造成危害，大的可能会给国家造成伤害，导致家破人亡的结果。

在发展过程中，企业也在不断地调整，我们需要有一个制度和机制来维护企业的发展。我们生活在一个圈子里的时候，一定要用制度来规范我们的行为，所以一定要在这个制度框架之内来做事、工作和生活，绝对不会是随着个人的主观愿望想干啥就干啥。
