# 实地指导分享 （浙江杭州·沈悦里）

杭州氿悦商业管理有限公司成立于2019年，现有员工1100余人，杭州9家门店，江苏10家门店，年销售额7亿元。公司以“食品安全、生活便利、美好生活”为使命，致力于达成“顾客满意、社会认可、合作商受益、员工快乐、政府支持、企业幸福”的企业愿景。

2022年7月9日到7月11日，东来哥分别与杭州氿悦里高管、全体管理层、财务人员及门店管理层沟通了五次。分享内容较多，摘编如下。
