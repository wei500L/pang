# 实地指导分享（浙江丽水·万家惠）

浙江万家惠超市在浙江的第一家门店于2010年在温州苍南开办。浙江省的门店主要分布在浙江温州、丽水等区域。万家惠通过农超对接，以生鲜商品全品类自营的方式及质优价美的商品受到顾客广泛认可。通过业态升级、供应链优化、变革组织架构、提升商品开发和服务能力，向消费者提供优质生活解决方案。未来万家惠超市致力于成为一家“创造美好、传播美好、分享美好”的健康幸福的美好企业。
