# 实地指导分享 （云南昆明·润兴万家）

云南润兴万家商业集团初创于2006年，成立于2014年。至今有10家连锁超市，主要经营模式为集生鲜、熟食、特色小吃、食品、百货、洗化为一体的大型卖场，营业面积8万余平方米，员工2000多人。企业通过源头直采、全品类自营的方式最大程度地减少中间环节，为当地百姓带来高性价比的商品。

未来，企业将秉承“品质生活，拥抱温暖，传播爱”的企业精神，持续寻求更优质的供应链渠道、优化商品结构、提升服务质量、严格把控商品品质，爱护每一位员工，尊重每一位合作伙伴，让每一位来润兴万家的顾客买得放心、安心、舒心，让每一位员工和合作伙伴都感受到喜欢和阳光，最终实现“健康企业、幸福团队”的企业目标。
