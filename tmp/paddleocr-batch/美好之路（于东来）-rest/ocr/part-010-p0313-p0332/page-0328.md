# 实地指导分享 (四川成都·邻你生活)

成都邻你生活股份有限公司创立于2000年，是一家专注于连锁超市经营的企业，公司以“爱自己·爱伙伴·爱顾客”为核心文化，致力于成为一家幸福美好的企业，成为一所研习幸福美好的学校。公司倡导像经营家一样经营好卖场，像对待家人一样对待顾客和员工，不断发现爱、创造爱、分享爱、传播爱。目前拥有25家直营门店，区域覆盖全省，提供2000余个相关就业岗位。

邻你生活始终紧跟新时代居民生活消费升级的需求，以新零售、新业态、新模式、新科技为突破，促进购物体验、科技体验，休闲娱乐与社区文化的融合，打造更具区域辨识度、多业态发展、多元化商业的购物新场景。

2023年2月24日，东来哥与成都邻你生活超市管理层作了两次专题分享，分享内容较多，摘编如下。

## 发自内心的人性化政策

要有发自内心的人性化政策，不要形式主义。就像现在有学胖东来的，不是在心里边去做。对人好，一定是发自内心的，而不是用脑子想象对人好，心跟脑子两个是不一样的。
