# 实地指导分享 （安徽六安·绿篮子）

安徽绿篮子超市成立于2001年，是一家定位于社区加强型的综合连锁超市，立足并深耕六安市场，30多家门店遍布各大社区，服务30多万户社区家庭的日常餐桌，年营业额10亿元。绿篮子用心秉承“让顾客购买的任何商品都能放心、满意”的经营理念。绿篮子未来发展不止是规模，更是践行美好理念和生活方式的平台。
