# 点亮心中的红灯笼

作者：新乡百货/张沙沙

炎热的夏天，中午卖场内空空荡荡的，换班的时间也快到了，刚走到收银台就听见小孩子的哭声：“沙沙，你过来一下吧！”听到同事叫我，我走过去一看，一个长得瘦瘦的大约七岁的小男孩站在收银台前哭个不停。我问他：“怎么啦，小朋友？是不是找不到你妈妈了？”小男孩只顾低头哭，一句话也不说。后来同事说，小男孩是来买菜的，走到这儿发现钱丢了，还非要买，说不买东西回去，他爸爸会打他的。原来是这样，“乖乖，你丢了多少钱？”“10块钱，我刚才去里头买菜了，肯定是丢里头啦！”

小男孩边哭边说，了解事情的原由，我到生鲜区问了一圈没有人捡到。

我想有可能是找不到了！回到收银台，对同事说：“你先给他10块钱吧！就骗他说钱找到了，别让他着急，等会儿我再把钱给你。”可是

不一会儿同事跑过来对我说：“沙沙，咱骗不了这孩子，他说这块的。”听完，我呵呵乐了起来。

这孩子还真诚实，我一定要帮他。看着孩子一筹莫展的样子，

我走过去对他说：“既然钱丢了，可能也找不回来了，这样吧，这10块钱就算是姐姐借给你的好吗？长大了有钱了再还给姐姐，赶快回家吧，你爸爸还等着你把菜买回去给你做饭呢！”小孩子点点头，看着他渐渐走出超市，我的内心深处仿佛亮起了一盏红灯笼，它指引着我向企业的愿景靠近。
