# 一支笔的感触

作者：新乡广场/卢萍

那天黄昏的时候，我们下楼去吃饭，在下楼梯时，我的圆珠笔掉了，然后，我就顺手把它扔到了门口的垃圾桶里。当时外围的保洁员袁可看见了，说：“你怎么乱丢东西啊，那笔还有那么多的油。”我随口说了一句“没有弹簧了怎么用啊”，说完就走了。在我看来，这是一件最普通的事，没有必要那么认真，不就是一支圆珠笔吗？随后我就把这事给忘了。当我在后台卸货的时候，袁可又找到了我，递给我一支用胶带粘好的圆珠笔。我仔细一看，正是我扔到垃圾桶里的那支。他对我说虽然没有你以前的好，但是扔了挺可惜的，能将就着用就将就着用吧。

当我接过这支小小的圆珠笔，眼中充满着感动的泪水，一只笔包含着我们兄弟姐妹之间朴实亲情和对企业的真爱！

一滴水可以折射出太阳的光辉，一件小事可以看出一个人高尚纯洁的心灵，小事是大事的基础，大事是小事的累积，一个袋子，一声问候，一个微笑，一个小小的善举，举手之劳，并不需要我们的付出，却能换来温暖，快乐，和谐。把每件小事做好就是不简单，我们的美好生活就是在点点滴滴的小事中创造的。小的事像小溪，慢慢侵入人的心田，随着时间的流逝，慢慢散发出蕴味，耐人寻味。
