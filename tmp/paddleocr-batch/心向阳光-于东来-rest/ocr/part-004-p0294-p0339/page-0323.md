# 用心服务好每位顾客

如果您在胖东来消费过程中有不满意的地方，有员工让你不满意。请到服务台或找值班主管投诉，我们一定会积极倾听您的建议，完善我们的管理，提升我们的专业能力。针对您提出的建议经核实后，我们将给予您五百元现金奖励，这样做的目的就是希望在您的帮助监督下，让我们的员工和团队能用专业和热情的心服务好每一位顾客，让企业能够健康快乐的成长！

如果员工在工作中犯了错误，甚至遭到投诉处罚。首先要学会用好的心态，承担责任，总结自己的不足，千万不要觉得委屈和不开心。要知道吸取教训，要知道这是在帮助自己成长，内心一定要诚心、开心的感谢。想想处罚与自己的收益相比太微不足道，成熟了，回报会是无限的，一定要站在更高的位置看问题，做智慧的人！

员工要理解自己所负责经营的每一种品牌的文化、理念，要了解产品的工艺、品质。当你对产品了如指掌后，你还要了解顾客的需求，并把商品的所有亮点告知到顾客，这样你的“媒人”义务就尽到了，也就为商品找到真正爱它的人了。所有的这些，如果做到，就是专业，就是敬业，就是一位快乐的好工匠。商品也是有灵性的，有生命的，只要销售人员懂它、尊重它、爱它，它就会焕发出自身的魅力。因此，从这点来说，销售人员负有很大的责任，他们是唤醒沉睡商品的“白马王子”。

公司制度处罚的目的：是为了帮助员工健康成长，所以制定了相关的返还标准和规定。这就是要让员工知道错在哪里，让自己健康进步让成长的员工经济不受损失。真正爱员工的企业，可能处理的越重，让员工得到的也会越多，工作时间长的员工或许早已明白这个道
