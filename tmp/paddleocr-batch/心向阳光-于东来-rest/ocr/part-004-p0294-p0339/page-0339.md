# 致离开胖东来的兄弟姐妹

无论什么原因离开胖东来的兄弟姐妹，希望你们不要失落，更希望你们不要被现实和金钱左右，坚定公司信念，胸怀知足之心，勇敢的面对现实，根据自己的能力做事，做懂事，感恩，智慧的人，坎坷会让你们更成熟！更自信！希望你们勇敢乐观的面对，你们已经长大，相信自己的能力和智慧，把公司理念好的地方用在自己身上，根据自己的经济状况合理选择自己的事业，乐观快乐每一天最重要，虽然不能共事，但我依然爱永远你们！希望你们踏踏实实的做人做事，在不伤害他人，不利用他人，不违背善良的基础上做自己喜欢的事，勤奋加善良的做事，你们的当下和将来一定是充实和幸福的。

没有共同坚定的信仰与追求，没有心灵互动的感受，不可能体现共同的信念和价值观，不能做有缘的事业！做其心祝福的朋友对彼此都是关爱和幸福！无论事业相伴与否，永远不放弃为对方的幸福而祝福和付出！

祝福你们！
