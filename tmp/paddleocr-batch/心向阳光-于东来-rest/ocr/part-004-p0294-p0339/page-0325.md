# 做和阳光一样美丽的人

无论写什么，我要回到简单的梦想：还是希望我们的思想和个性越坦诚，简单，纯净越好。现在的世界，文化发达区域的人们在个性，自由的分享着，创造着生活，感受着生活的美好，他们不会把时间浪费在无聊的修正心态的事情上，他们是在充分的活自己，活当下。而我们却是在顽强的修炼着自己的内心，这样对比，我们是不是太愚昧，他们是阳光的活法，我们是纠结苦悲的活法，就这样无奈下去吗？现在即便是谈很简单的道理，人们明白却不相信，人们的心灵被功利，虚伪，嫉妒，贪婪的思想占的满满的，人们只追求成功却忘记分享眼下做好每一个小事，每一个细节的成就的快乐，忘记成功是由小事汇成的。

我们忘记了从生活休闲和工作的细节分享创造的快乐，分享当下的快乐，我们只会把幸福寄托给未来，我们已忘记了生命的时光是多么宝贵，可人们已不思考和珍惜，很多人们已远离正常的人性。让贪婪，埋怨，纠结，无奈，痛苦充实着自己整个思想和灵魂，希望人们思考这些问题，我们也需要阳光的活法。我们不要再为所为的面子而活，为别人的看法和感受而活。我们应该学会漕空自己的心灵，爱惜自己的心灵，尊重自己的心灵，知道自己的心灵到底想要什么，需要什么样的营养，因为自己的心灵健康了自己才会快乐，才会幸福。我们学会逐步把心灵中污浊的东西洗去，让心灵更纯净，轻松和自由，这才是智慧的人。
