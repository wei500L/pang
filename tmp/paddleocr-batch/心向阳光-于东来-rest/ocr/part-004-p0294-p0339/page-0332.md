# 2014年致兄弟姐妹的一封信

亲爱的兄弟姐妹们！先祝福一下，新年快乐，阖家欢乐！

回顾过去走过的每个年头，我们靠着对美好生活的向往；靠着对追求幸福的坚定信念。我们为了让生命更有激情、更有价值，更真诚、更自信、更温馨、健康、个性和自由，我们努力寻求优秀的生活理念和工作理念，我们不停的巩固我们的企业文化、企业信仰，让我们的精神更有寄托；让我们的生活和工作方向更清晰，更正确；让我们更懂得应该怎样活着，懂得什么是生活，什么是工作，懂得活着要分享生命的美好，懂得怎样活自己，怎样爱自己。我们生活中有太多迷茫和未知的道理，但我们越来越清晰追求的方向和方法，所以我们是幸运的，因为我们越来越明白怎样让幸福陪伴着我们快乐的成长。

总结我们的成长过程，无论工作和生活，虽然存在着太多的不足和问题，但我们始终坚定不移的贯彻执行我们的信仰和信念，坚定不移的提升和完善企业文化信仰、经营理念的品质和品位，坚定不移的围绕着企业文化，持续完善企业体制、制度、标准、政策，坚定不移的提升员工和团队的专业能力、品德品质、个人修养及人生事业，坚定不移的进行员工生活的规划、生活质量和幸福值的提升。我们知道我们的基础太弱，我们企业发展的大环境还很落后，负担还很重，我们的成长之路还困难重重。我们坚信我们国家的体制会越来越好，坚信为了让更多的人品德和能力更好的提升，让更多人更幸福美好的工作和生活，让更多人懂得更个性、自由、尊严、尊重的爱自己，活自己，活当下，让更多人感受到生命的美好，让生命更有激情，逐步脱离奴性文化的习惯，让身上的束缚越来越少，让精神更乐观、更自信、更轻松、更自由，让生活更温暖、浪漫、闲适和快乐。
