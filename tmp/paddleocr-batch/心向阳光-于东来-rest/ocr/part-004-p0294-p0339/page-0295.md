# 处助以上管理层会议

“就是想着活的轻松一点，爱自己一点，我知道去照顾自己，因为我现在想去改变很多人”

我的心里面还是有自己的理想，这种理想就是希望生活就像欧洲人一样，上班的人很喜欢，过的很幸福很有激情，然后做事情很认真，很喜欢的时候是一种幸福感，下班了人还很轻松很愉悦，享受生活。咱中国人都不会享受，上班不好好上班，下班后不懂得生活，要求过高了太累，要求的低了也很累。那么就是在这个思路上有一些调整，我以前觉得自己的能力很强能改变你们大家，能让大家跟随着我要求的，但是现在整天去给你们讲，你们的思想总打不开，我感觉很累。因为这么大个企业，我每个人都讲，我整天给你们讲很累。我想有自己所喜欢的一种结果，就像感情一样两个人在一起很认真的对待，要么就放弃。所以我今年就是想着活的轻松一点，爱自己一点，我知道去照顾自己，因为我现在想去改变很多人，我没有这个能力了，以前我吵你们的时候总是害怕伤害你们的自尊，其实从我心里面对你们去讲任何的东西，可能说带有一种隐瞒，或者是该怎样说就怎样说，该吵就吵，该鼓励你们就鼓励你们。如果我是违心的，帮时的人们听着很好，但是长期的是在害你们，我现在也不想那样了，总想着慢慢的一切都会好的，这么大一个企业你心里想有自己的梦想，但是底下的人跟你们差距太大了。

在座的我没有发现有任何一个人对企业的不热爱不忠诚，但是人的理解能力都是有限的，人追求的这个目标，很多东西也是不太一样。我希望大家明白我们有一个共同的信念，就像是设置了一个目标去爬山一样，我希望去咱卖场一看商品环境很整洁，员工很有激情，
