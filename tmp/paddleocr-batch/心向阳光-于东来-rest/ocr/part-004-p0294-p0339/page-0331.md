# 我们的工作指导

不知不觉我们也建立了太多的标准化管理系统，技术系统，公司的文化，体制，政策也会逐步写入公司制度，相信我们坚定依据人性化的管理经营理念，一定会建立一套实用，有效，专业性强，分工明确，先进的管理经营方式。

努力营造好的体制及工作成长平台，让更多员工能充满激情的分享工作和生活的快乐！向个性，自由的目标健康成长！思想越来越解放了，事业也越来越轻松健康的进步。

2014年的工作指导：坚持热爱，勤奋，专业，快乐的工作理念和生活理念，让大家会干会玩，分享工作和生活的快乐。工作重点：分工清晰，专注提升专业能力，文化梳理，信念与准则更清晰，体制清晰，政策量化，标准化制度化，培训考核，培养员工创业意识，能力和相关指导。始终保持向轻松快乐的工作习惯进步，为了喜欢而不是为了利益，最终的回报是物质和精神双丰收，收获的是恒久的幸福，因为你付出了真心和劳动，创造了推动社会进步的价值。

公司指导所有部门，用一颗平和的心态，热爱自己的工作和生活，忘掉利益，轻松专注的提升专业能力，培养热爱工作的感觉。轻松快乐的最多再用四年时间实现全员三星员工的综合标准，实现全员综合素质能力达到合格目标，让员工明白实现三星以上能力就真正感受到工作的快乐和价值和富足的精神财富。
