# 用爱对待我们的顾客和商品

我们要爱顾客，要想到顾客的需求，不要按照自己的想法去走，要把这种爱融入到自己的做人做事中去，不要站在自己的利益上去考虑问题，不要违背了“利他之心”的理念。爱是什么？爱是最幸福的，最美丽的，最纯洁的，带着爱去做事的时候，才会把商品的价值诠释出来，才会把最美好的东西带给顾客。

我们要牢记用爱对待商品，因它是有生命的；用爱对待顾客，因我们是天使；用爱对待所有万事万物，因我们是伟大、善良、快乐的人。

我们永远不要忘记：我们追求的不是目光短浅、贪图功利的生意人，而是具有高尚情操和社会责任感的优秀快乐的商人。

把精细化的思想融入到工作和生活中，那样我们做的商品才会有故事、有文化底蕴、有生命、有价值的。
