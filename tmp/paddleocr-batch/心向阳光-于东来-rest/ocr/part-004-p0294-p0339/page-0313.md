# 我们做企业的目的

看了网络中部分学者对胖东来的解析，他们并不真正了解胖东来，我们一直在追求实现乐观、自信、幸福的文化，从体制上围绕公平、自由、快乐、博爱的理念，践行并分享文化品位的提升过程和成长过程，改变我们自身奴性自卑的文化，逐步实现坦诚和幸福的结果。

用功利的眼光是永远解析不了追求幸福企业的真正能量、能力、经验技术和道理。不明白真理的方向，后面一切皆为零。

我们做企业的目的：

一、让我们共同努力改变劣根性与奴性的文化。

二、不断提升文化品位和加强专业能力的培养。

三、围绕平等的理念建设合理的体制。

四、制定有效的激励政策，让员工感到尊重和希望。

五、让思想持续的进步，乐观的创造和分享生命的美好！

六、让每个人都能实现尊重、尊严、个性和自由。
