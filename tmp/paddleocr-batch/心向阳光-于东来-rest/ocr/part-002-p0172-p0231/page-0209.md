# 文化和信仰的方向

我们一直在寻求一种文化和信仰，一种能让更多的人从过度的虚伪、嫉妒、贪婪、自私、自卑的痛苦中走来，明白生命的真啼，明白真理、正义、乐观、信仰、博爱公平的道理，为自己、为社会、为国家的进步和谐和繁荣昌盛，奉献我们的能力和智慧，使我们的生命更乐观自信，而不是迷茫、抱怨和失落，共同努力，生活一定更幸福。信仰的力量可以让贫穷充满快乐！可以让灾难化为平淡！可以让能量化做动力！可以把致富经验传递！可以把爱与世人分享……

像奥黛丽·赫本的心灵一样美丽，象《阿甘正传》中的阿甘一样纯纯的其爱，象耶稣一样普世爱人，明世理、活自己，心灵高贵，思想自由，活在当下，希望更多的人们脱离痛苦的虚伪，活出自信的自己。放无心之手，爱有惜之人，在不利用他人，不伤害他人，不违背善良的基础上做自己喜欢的事。

文化信仰不同对爱和其理的理解的结果完全不同，对自己能做到的事情，对于别人的帮助，东方文化理解为幸福，西方某些文化理解为对自己的不尊重。

我们追求其实的人生和生命的意义！大家以更好的心态去面对生活中的成就和挫折，最终的目的不是唯一地活着，而是让人生更有价值，生活更温暖，身体更健康，思想更充满朝气与活力，这样的人才能真正地快乐，才能自信的感受生命带给自己的精彩与历练。

做有明确目标和人生信念的人，又有鞭策自己精神和行为标准，这样的人是不会被功利诱惑，更不会迷茫，肯定更自信、更阳光，我更相信这样的人会越来越多。做一个实实在在的人，做一个品德高尚的人，做一个健康有为的人，做一个乐观幸福的人，做一个心灵轻松自由的人，这就是我们的文化和信仰的方向。
