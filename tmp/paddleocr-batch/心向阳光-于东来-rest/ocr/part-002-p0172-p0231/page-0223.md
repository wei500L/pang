# 关于追求

在这个世界上，有很多文化体制先进的国家和地区！他们从小就接受不违背自然法则、不违背人性的教育！他们了解自然！尊重自然！分享自然和生命！所以他们诚实、简单、爱自己，活自己，尊重自己，更爱他人，用行为维护文明和真理！而我们承受着虚伪、嫉妒、贪婪、痛苦的精神枷锁的折磨！没有长远的眼光来审视和分享这个世界！只能在狭隘有限的空间奋力拼搏！痛苦自己且浪费时光！可悲！

想做官还想发财！让自己不但成为功利的奴隶，而且让自己的智慧、价值和幸福完全葬送在毫无意义的计谋、应酬和耗费时光，甚至是伤害社会、伤害人民的邪恶之中！痛苦自己！伤害家人，后悔且不能自我！

你们看到的只是胖东来对员工好！对顾客好！生意好！挣多少钱！这是很浮浅的理解！是只站在利益角度的理解！而胖东来真正的追求是寻找自信、乐观、文明的文化信仰！个人财富和权力的高低并不能代表真正的正面价值！高贵心灵和博爱的美德才是社会和谐进步的源泉！
