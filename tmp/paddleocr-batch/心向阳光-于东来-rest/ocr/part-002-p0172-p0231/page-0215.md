# 关于为什么要了解宇宙

我们想要明世理，活自己，心灵高贵，思想自由，活在当下！我们就要明白自然与人类的关系，明白自然科学与文化信仰的概念及相互作用，明白信仰与道德对人们的生活起着什么样的重要作用，我们要追寻活着的本源，只有明白这世间基本的做人做事道理，才能展开自信的生命旅程…

我们要明白我们自己在那里？我们要到那里去？我们用什么办法？我们希望自己是乐观的、自信的、坦诚的、善良的、正义的、自由的、博爱的…可我们现在很多人还活在虚伪、自卑、贪婪、只知道追逐功利的迷茫状态中…我们缺乏正确的信仰，那怕你信仰的只是简单的善良！在此基础上一步一步的学习与完善。

为什么我们谈宇宙、谈人类，出发点越高，你的思维打开的越宽，你的准确性就会更好。放大自己的眼光去提升自己的能力，然后给别人做个榜样，再去带动更多的人进步。要知道去承担自己的责任，去释放自己的能量，去爱你们的员工。

我们必须要简单了解几门知识的课程：自然与科学，历史，哲学，道德与信仰！明白了这些基本知识，你就会更了解自己，更明白怎么用正确的办法对待自己的生命，对待自己的生活和事业，明白怎样规划自己的人生目标，明白怎样制定实现目标的方法和计划。
