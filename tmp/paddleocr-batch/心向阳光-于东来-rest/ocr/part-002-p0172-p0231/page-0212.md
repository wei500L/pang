# 关于为什么要梳理我们的文化

为什么要对胖东来的企业文化进行梳理整改呢？的确我们的文化层面虽然很人性化，但太大统操作性不能具体到点，不能更好的让员工理解，接受，落实…所以我们希望企业文化更清晰，更具操作性

我们要明白共同追求的目标是幸福，是快乐。我们要明白影响我们快乐的是什么？要么是英雄式的奉献，无私无我，要么过度虚伪，自私，嫉妒，贪婪的奴性文化。不考虑自己是谁，自己的个性和人格需要尊重吗。不懂得尊重自己，所以尽一切努力来证明自己，这样自卑，我们要寻求从奴性文化到个性文化的进步。

我们做企业的意义，让我们从自卑的奴性文化追求内心勇敢，坦诚，自由的个性文化。让大家懂得爱自己，活自己，爱他人，尊重他人！懂得明世理活自己，心灵高贵思想自由，活在当下的生活理念！懂得个性，自由，尊重，尊严的道理！懂得在不伤害他人，不利用他人，不违背善良的基础上做自己喜欢的事。

我们要寻求在世界范围内相对先进的文化信仰，传播，落实，让我们更乐观，健康，快乐，自信的进步，让我们在文化信仰的指导下能坦诚，勇敢，自由，轻松，幸福的创造和分享生活的美好。

我们要知道我们追求的是我们喜欢的，我们向往的，我们为的是内心的热爱与愿望，这对于我们来说已经够了，我们的目的也是心行合一，乐观自信的活自己。

我们明白了自己是谁，自己的现状怎么样，自己应该怎样活，所以我们要有清晰的文化信仰，先进的生活理念，工作理念，及相关的标准，所以我们必须制定鞭策我们思维和行为的企业文化信仰。同时也希望为人们的生活增添有价值的启迪，这也是我们这么多年做企业的感悟及意义。
