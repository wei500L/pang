# 关于周二闭店休息的公开信

亲爱的父老乡亲：你们好！

非常感谢大家对胖东来的支持和关爱，随着企业的发展和社会的进步，胖东来的企业文化制度也向着更人性化（考虑到员工的身体健康和生活质量）的方向提升和完善。由于员工常年的辛苦，很多员工的身体也因劳累患了各种各样的疾病，严重影响了员工的身体健康，同时也失去了很多与家人、孩子、朋友团聚享乐的宝贵时光。为了提高员工的生活质量，让员工分享生命中更多的幸福和温暖，也为了让员工感受到企业的进步是让大家有更好的寄托，是值得他们认可和热爱的。这样他们才会用更高的热情投入工作，在公司理念的引导下，努力提升个人品质及团队专业能力，团结一致，相互帮助，把商场的商品做得越来越丰富，质量更可靠，价格更实在，环境更整洁，服务更完善，顾客更放心，为大众生活品质的提升，展示大家的才华和能力，也让更多的人感受到生活的美好和阳光。

胖东来公司决定：从二零一二年四月份开始，每周二为胖东来闭店休息日。
