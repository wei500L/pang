# 关于胖东来的企业文化

企业文化是鞭策企业发展的思想和行为的标准和方向。很多人偏面认为企业文化只是企业的文体活动，企业文化其实就是我们企业的信仰，优秀的企业文化为员工创造幸福的工作和生活环境，为社会增添更多温暖的能量。

无论生活中发生什么，我们都能找到让我们在思想和行为上体现出个性、自由、自信、乐观状态的依据，让我们更懂得分享工作和生活的快乐，这就是我们要建立优秀企业文化的意义。

胖东来发展的目的是一直是追求让更多的人乐观、坦诚、幸福的分享生命的价值和意义！围绕善良和勤奋不断追求公平、自由、快乐、博爱的文化信仰，根据文化信仰的理念制定相关的制度和标准，完善企业的管理流程，让所有的胖东来人明白：在不利用他人，不伤害他人，不违背善良的基础上认真勤奋的学习和工作，乐观真实的生活，创造和分享生命的真谛。

相信未来每一位胖东来人都有清晰的人生目标和信仰，都能靠自己的品德和能力安排好人生各阶段的事业和生活，都能让人生的每一个阶段过的真实、轻松、快乐，真正做到热爱生活、创造生活、分享生活，切实实现明事理、活自己、心灵高贵、思想自由、活在当下的人生自我价值和社会价值的完好体现！我们坚定信念，追求和分享乐观、自信和幸福的理念永远不变！
