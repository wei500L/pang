# 关于标准制度

制度标准是用来执行的，不是说说而已！好的环境是靠大家认真维护培养出来的，好的团队一样靠严格的纪律和温暖的关怀培养出来，否则浪费了大家的时间，误了他们的青春！那样更是害大家！

很多人觉得公司的制度太严，其实是我们平时对制度的尊重太浮浅，大家都知道没规矩不可能成方圆，一个文明的环境需要每个人的付出和奉献，公司也会根据员工的能力状况，根据公司的现状，按照人性化的理念向标准化方向进步，制定更加合理的制度。

从传统到现实的环境中，很多人害怕失去已有的美好。如果有创造美的心灵，就不会为失去而消沉。看看历史剧中有多少人为了江山牺牲了自己的一生！封闭的思想，让无数人学不会去审识世界的美！在有限的围城里无奈的拼搏！学习的态度是多么重要，对于美好学会接受而非拒绝。别人能做到，相信自己就能做到！

优秀的标准制度一定是在不断的学习和反思中完善建立！在世界的范围内，对比人文，环境，文化，制度，文明的差异。完善自我，不断学习，提高整体素养，让顽固的劣根本质逐步脱离我们的思想！先进的文化信仰更能展现文明和幸福的状态。

虽然目前我们还存在很多不足，但是各个方面都在逐年健康的是进步，有了完善、规范的标准制度，我们的管理才会更具人性化，胸怀更宽广，工作更勤奋，环境更整洁，心态更乐观，生活更阳光。发展成长的过程永远有不足存在，只要我们做好每一个细节，乐观看未来！付出自然有回报。
