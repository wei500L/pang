# 关于做企业

在功利思想主导的社会，人们只知道大才是价值和成功，企业发展的模式，快速扩张、壮大或脚踏实地做精做细。对社会长期的进步是正能量或是负能量？其实真正能恒久的反而是小而美的精细化文化。传播一种爱的文化，让更多人理解，认可，使用，帮助到他们知道怎样做生意，做事业，使他们能少走弯路，能快乐的分享他们成长的过程。文化的传播更有价值。一个企业强大和更多企业强大那么好？一个人强大和一个团队强大哪个好？对比一下大家应该明白。

投入精力做品质，提升产品质量，技术，服务保障，保证合理价格和利润是企业长久战略！低价竞争，除了逐步降低商品质量，最终还会伤害社会，被社会淘汰！低价竞争，创造不出优秀品质的品牌！拥有品质，就拥有未来！做有品质事业的过程更幸福！

享受做事的过程，自然不会为生计苦恼，因为你忘记了名利，投入了热情！现实的人们，多些这样心态的人该多好！

我很难给大家形容出来，那些专心做事的人，他们心灵的感觉是多么轻松自由和幸福！在他们的生活中，是感受和分享生活的快乐，他们的精力更多是专注做好自己的事，物质对他们来说并不是最重要的，但结果是水到渠成，付出自然就有合理和超值的回报！

在胖东来工作几年的员工，基本上都通过努力有自己的住房，很多家庭也有了汽车，也知道安排更多的时间旅行和休闲，越来越会分享生命的快乐。这样很幸福！我会根据自己的力量带领大家，努力让每个家庭都生活的更幸福！

越来越多的员工沉浸在淡定而幸福的工作和生活中，他们通过努力过上了稳定幸福的生活，有这种感觉是智慧，是进步。心惰浮躁的
