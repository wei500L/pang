# 走进胖东来，解读胖东来

我，姓于，名东来。属马，狮子座，B型血。我是荷花季节出生的，我的心性像荷花一样，内心追求高贵、纯洁、自由、浪漫、朴实、简单；我的性格就像我的名字一样，于东来，鱼从东方来，逆水而行，奋力向上并分享汹涌波涛的洗礼；属马热情奔放；狮子座天性操心，王者雄心奴隶命；B型血外向，我行我素；我最大的优点是心软、善良、勤奋、大方，虽然我天性心眼小、疾妒心强、虚伪、贪婪、自私，但我依然不忘活出真实简单的自己，活出性格的天性，非常感谢父母和上天给予了我特别的个性，给予了我宝贵的生命，善良掩盖了我性格中太多的不足，阅历让我的品格不断升华，在成熟的过程中越来越自信和伟大，我调皮的天性将永远不变，那就是我的风采。

我追求唯美，崇敬耶酥，释加摩尼，穆罕默德，卢梭等有普世情怀的大爱之人。我就像追求信仰的践行者，用心灵和肉体寻求挣脱奴性文化枷锁的道路，我希望自己和更多的人走出这种让我们痛苦不堪的劣根性、奴性文化的旋窝，学会乐观的分享生命。

我觉得能成就胖东来今天的结果，首先是我的个性与人生阅历
