# 关于控制胖东来企业和团队的规模

关于发展企业，停下脚步休息休息，你会感觉生活原来也很美好。根据自身能力做好品质然后再健康轻松的发展。很多企业的老板或团队太累太累，人生的成功不是追逐金钱和面子，而是让自己轻松的做喜欢的事，自由快乐的分享生活的美好…好的理念，生活质量会更好。

作为企业家或老板，少一些事业的打拼，多一些感受生活的乐趣，更有助于你的事业健康发展。建立好的体制，好的政策，让团队和你一起成长，一起承担事业的责任，一起分享财富和价值的快乐。

胖东来发展这么多年，我一直努力希望让大家过的更好，希望把大家培养成品德高尚、知足感恩的人，因为这样才能幸福。我也尽自己最大的努力，提高大家的收入，努力建立一种相对公平的体制，让更多的人从奴性文化向乐观、自信的方向培养，从而达到更多的人理解和体现：明世理，活自己，心灵高贵，思想自由，活在当下！这种阳光的心态。使更多人活的更充实、更坦荡、更幸福，使更多人勤奋、乐观、善良的创造并分享着智慧和快乐的价值，快乐的过好生命中的每一天！

做企业，爱大家的同时也必须学会保护自己，否则自己会很累。毛主席曾经对重庆一个报社的记者说过：一个真正的勇士首先要会保护好自己，要不然还没上战场就被敌人暗杀掉，这样怎能创造和实现伟大的理想。

我要控制胖东来企业和团队的规模，能合理教育、培养、照顾到团队的每一个人，以达到整个团队的品质能合理体现我们追求的文化信仰，能充分体现良好的幸福的生活工作状态和幸福指数。对个人、对团队、对社会都是积极的促进和帮助。爱自己，活自己，爱大家！
