# 关于经营理念

经营之道：总结这么多年的经商经验，开始也只是为了满足生存的需要，多挣钱，为了让家庭生活过得更好。虽然急发财的心理让自己历经坎坷，经历无数失败，但对中国传统的经营理念还是运用的很好，如和气生财，货堆如山，灵活大方等等。把舍得，对员工好，对顾客好一直是用行动体现出来。

由于贪婪，嫉妒心强，容不下同行比自己优秀，为了维护所谓的名誉地位，为了竞争始终把心态提得很高，不停的努力奋斗，不顾健康，使自己和大家失去了很多休闲，除了满足虚荣心，所谓的责任心。从来都不明白分享经商的快乐和分享生活的美好，让这二十多年的时光过得过于紧张劳累，失去了很多应该的欢乐。还好，经历这么多人生阅历，现在越来越明白我们应该怎样去活，怎样做人，怎样经营人生，怎样经商。

实践证明只有诚实、热爱、勤奋、善良、健康、乐观、专业，不走捷径实实在在的做人做事，我们的事业和生活才能做得稳健，强大和快乐。只有不断提升和落实企业文化品位，坚定信仰，信念，做人做事的标准，在企业的文化信仰的鞭策下，围绕以人为本，造福员工，造福社会的原则，不断完善整合企业文化的内容，使文化条理更清晰，更简单明了，更实用，更有利于让员工认可接受落实。再建立相应的体制，制度，政策，标准并逐步提升完善，不断挖掘全体员工的潜能，使团队品质更专业，更优秀，幸福值更高。
