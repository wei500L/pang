# 分享胖东来的经验

大家好！非常感谢你们对胖东来的期望，关爱和帮助！

很早就想向大家介绍胖东来的发展历程、文化、思想、理念的变化，成长过程中酸甜苦辣的感人故事，从发展的道路上体现人性本能不断追求美好生活的愿望而努力的探索的感受。

虽然我们历经磨难、坎坷，但我们始终没有放弃对善良的不断追求，我们执着的寻求诚实、正义、公平、乐观、博爱、信仰的真理，并为之付出行动。我们始终鞭策自己的企业，不要骄傲自满，时刻铭记我们的责任和使命，我们的身上还存在太多的不足，我们对真理的理解还太肤浅，我们的思想心态、心灵还背负着太多沉重的包袱，如：虚伪、自私、嫉妒、贪婪，这些恶的邪念占据我们心灵的空间，使我们的思想失去自由，阻挡着我们的想象力、创造力和智慧，让很多人只是虚伪悲壮的为面子、功利而活，我们有太多人不知道如何爱自己，尊重自己，让自己能真正主宰自己的命运和生活，让自己的心灵更纯洁和轻松。我们牢记着企业的做人理念和做事理念：你心我心，将心比心，不是自己的坚决不要，不急功近利，要从一点一滴的小事做起……

用这种理念指导着我们制定企业的发展方向，鞭策着我们每一个胖东来人的思想和行为，让我们的胸怀更宽广，心态更成熟，心灵更高贵，品德更高尚，做人更其实、善良、诚实。我们在成长的过程中，逐步明白更多更深的做人做事的理念、生活的理念、思想的理念和信仰的理念，我们要明白做人首先要诚实、善良、勤奋、乐观，我们的心灵才会更高贵、品质更高尚、心态更成熟、思想更自由、更有想象力、创造力，才会逐步远离过度自私、嫉妒、虚伪、贪婪，这些
