# 萤火虫的遐想

坐在南去的列车上，心不是很净，写出的东西会有些乱，我还是要写，宝贵的六个小时，希望能为大家提供充实的感受！我在解析胖东来真实的成长过程，解析胖东来真正的愿景。

我知道人们关注更多的是胖东来生意为什么那么好，员工为什么那么忠诚，环境为什么那么整洁；我知道大家都想要这样的结果，都想让自己的事业和生活更美好，都想让自己的人生更有价值，都想让自己和家人更幸福，更快乐，都想让自己更轻松，更自由分享生命的美好时光；我知道大家对美好的期盼和向往是多么强烈。

我曾经也是那么单纯，幼稚的思维，以为人们只要你心我心，将心比心，共同努力，结果一定是好的，这样相互传承，社会一定很美好。我想的太简单了，当时并不了解什么人文，历史，信仰，环境与自然，不了解人们性格的差异，成长阅历的差异，教育环境的差异，不了解太多的道理与知识等等。

九五年当我还完账时，虽然当时对员工也很好，只是考虑他们的眼前，有房，结婚，有存款，能正常生活。随着个人财富的积累和员工之间感情的加深和社会环境的因素，自己有了更多的责任和追求，虽然更多是表现自己的能力和价值，但总是善良起着决定的作用，想用自己的人生精神财富启迪和造福更多的人。

我知道自己走过太多的弯路，当年的无知，也坑过人，伤害过人，也卖过暴利的东西，太多太多，做这些的结果收获的只是痛苦和后悔，不会有什么值得自豪和骄傲的东西，只觉得浪费了多少宝贵的人生，少了太多分享世界精彩的一面，充实的一面，健康有序的一面。
