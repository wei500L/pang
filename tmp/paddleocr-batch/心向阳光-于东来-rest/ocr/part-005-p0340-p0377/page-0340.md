# 放无心之手，爱有情之人

感谢好友送来的心灵营养液，我更了解世界和自己包括企业的位置，我一定会更加进步乐观分享和创造幸福的每一天，让自己快乐让身边的人更加轻松幸福，让大家少为我操心，无论将来如何，分享当下每天的快乐最重要，如若大家能理解就更好了。

迷茫的人为生存和名利奔波，自由的人在分享当下的快乐。尊重自己的当下，根据自己的现状，知足、乐观的让自己来主宰生命中的每一天！

自由的人可以让苦难变为力量，变成动听、幸福的故事。既是死亡还是那样的淡定和平常，这样的心胸不幸福都不可能！让自己能够主宰自己的死亡将多么从容和幸福！

放无心之手，爱有情之人。我喜欢和懂我的人交流，会放下怀疑和迷惑的人，这叫爱自己！
