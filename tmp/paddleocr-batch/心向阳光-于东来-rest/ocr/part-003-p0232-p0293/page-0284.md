# 后勤会议记录

## 感悟人生，怀抱梦想，珍惜宝贵的青春时光

我性格属于完美主义者，希望进入这个企业的每一个员工都是抱着梦想而来，或者来学经商，或者想学着锻炼自己，或者觉得胖东来不错，想在这里看看自己未来是否有希望。不管抱着什么样的梦想，既然进入到这个企业，我想这个企业最重要的是给大家提供一个好的平台，真正对大家有所收益，对自己的人生是有所收益的，不是浪费自己宝贵的青春时光。因为我性格是属于感性的，我有自己的梦想，我做任何东西是一步一步不断地提升，原来我也没有这么高的要求和层次，但是随着人生的成长，时间的推移，包括人生阅历不断地感悟，不知不觉企业走到了今天，这种规模也不是我想要的，我想要的就像世外桃源一样。

我上学时，学习成绩很差，但是我非常聪明，由于各种原因没有好好上学，因为父母经常都是搬家，总是调动工作，我记得我一年级小学上了一半，初中一年级又上了一半，初中三年级又上了一半，零零散散，在学习当中学东西是非常快的，我也知道我学东西很快，但是确实环境导致吧，我这种性格也不太喜欢学习，真正学习了我还是能静下心来融进去，所以说回头来感悟学习的时候也觉得很后悔，很多心里的东西想表达却表达不出来，后来过早的进入社会后经过历练。社会也是一所学校，这种历练还能让我讲出来一点，就跟写信一样，不是那么深，但是能表达出来。
