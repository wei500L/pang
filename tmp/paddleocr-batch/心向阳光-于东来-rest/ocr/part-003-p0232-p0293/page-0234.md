# 关于做人

做有明确目标和人生信念的人，这样的人不会被功利所诱惑更不会迷茫，肯定会更自信、更阳光，我相信这样的人会越来越多。做一个实实在在的人、品德高尚的人、健康有为的人、乐观幸福的人、心灵轻松的人！

无论是稻盛和夫、还是卢梭我们都要寻找自己的标杆，这个标杆在自己心中一定要非常清晰，不能随便的动摇，逐步的去实现和完成我们的梦想和目标，无论是北欧还是其它国家，我们都要学会取长补短，不要迷失自己。

爱永远是会传递的，不但会传递给人，也会传递到大自然的任何物质上，这样更多的爱也会回报给你，让你去分享别人的爱。千万不要把工作当做为别人而做，而应该是自己快乐生活的一部分，是为自己，爱自己，更是爱别人而不是为了功利取悦他人！

我们的心态非常重要，不影响幸福值去做人做事才是关键，我们的信仰不能变，北欧的生活状态一直是我们追寻的标杆，因为他们懂得创造价值、他们懂得分享生活、尊重自然和生命，他们不是乌托邦，他们的梦想是能实现和做到的。
