# 关于如何活好当下

关于当下，尽力做自己喜欢的事，过自己喜欢的生活方式。活着靠自己的能力和财富，合理安排自己的生活、居家、爱情和孩子等等。把命运主宰在自己手中，不委屈自己，也不为他人带来负担，尊重自己，也尊重爱护身边的人。

尊重自己的个性，活得健康、自由、热爱又富有激情。只有活好自己，才能把快乐和幸福传递给身边的人，传递给这个社会，懂得了心灵高贵是要有一个好的心态，对世理有更清晰的理解，知道人应该更关注阳光的一面，发现欣赏美的一面，更重要的是赞美生命的美好，多为人们送去美好的启迪，我们自己才能更幸福和快乐。

让心灵越来越纯净、简单，坦诚。越是这样，我们的思想就越来越轻松、自由，就越来越有想象力和创造力，更有利于智慧和潜能的体现与提升，生活才会更有乐趣和激情，才会充满更多的灿烂和阳光。活好当下，才会有未来恒久的美丽，才会懂得活好当下的价值和意义！
