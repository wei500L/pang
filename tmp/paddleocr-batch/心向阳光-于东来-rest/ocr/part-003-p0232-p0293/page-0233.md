# 关于成功

我们都能向爱的方向进步成长，我们的生活品质，我们的精神财富不富有都不可能，上天给予我们每个人的付出和回报都是均衡的，这就是自然与科学的道理，更是我们社会进化的基本道理。相信自己、相信身边的人、相信上天，爱自己、爱他人、爱万事万物。勤奋+善良=幸福人生……我们就是智慧幸福的人。

智慧的人帮助他人，悲哀的人利用他人！不需要别人的同愔与怜悯去做事情，更不要为了功利用人格去取悦他人！活的有尊严才会有骨气和幸福！

勤奋、善良、知足、乐观、快乐的过好每一天，就是最大的成功。
