# 东来谈企业文化

我们企业的文化主要就是引导我们遵循人的本性，明白自然的法则，在人类自然循环、宇宙自然进化的基础上去体现人们最基本的愿望，追求幸福和快乐。我们文化的主体就是追求善良和美好，弘扬一切美好的东西，所以我们要制定相应的法则，这种法则的主体我们把它解释为公平、自由、快乐、博爱。这种信仰的一个方向也就是公平、自由的概念，再往下解析就是民主与自由。

公司从“用其品换其心”到“创造财富、播撒文明、分享快乐”，每个过程都是思想、心灵的一个升华，这些主要是妥卢梭思想的影响，本身我骨子里面比较喜欢欧洲他们的这种思维模式，做人做事的习惯，做任何事情都会比较坦荡、比较直接，心里边比较纯净、比较轻松。我一直对法国的这种浪漫气息比较欣赏，这源于在很早以前，在看国外电影时发现外国人在交流中很少出现重复的话语，都很直接，没有那么虚伪的客套！他们的那种环境，生活当中任何事情的一种思维、反应都很坦诚。我一直崇尚北欧的这种文化，法国的文化、意大利的那种生活品味，对任何事情受到启发以后，就有一种愿望，在脑海当中无形的就会有一种梦想去追求它，生活也是一样。

在理解的时候你要从两个方面去理解，善与恶。从内心一直是希望我们的环境很浪漫、很整洁，每位胖东来人都很其实，不辍蜕，想让环境其实一点，大家轻松一点，少一点纠结。其实我跟大家一样，心里边都有很多乱七八糟的东西，有好的、恶的……其实无论是善还是恶都是很正常的，只要掌握好这个度，将不好的东西转化成激励自己的动力，最终的目的是为大家创造一个好的平台，无论是什么类型的人我们都能够去沟通，打开自己的心灵，只有相互坦诚才能更好的
