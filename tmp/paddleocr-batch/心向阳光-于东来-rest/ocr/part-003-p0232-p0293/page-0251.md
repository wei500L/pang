# 关于对活着和死亡的理解

让大家分享我对活着和死亡的理解，让生命活的自由！死的美丽！

可能是性格的原因，我从九二年的一次事故开始到至今安排遗嘱已有无数次了，几乎年年计划。生活的历练让我提升着对生命强烈而清晰的感悟，不知不觉人到中年，丰富的阅历，思想的开阔让自己对世界和生命逐步看的更加清晰和淡然，自然形成了一种观念。什么事都应有来龙去脉，但是总结到根本的源头，还是因为对爱理解的深度。其实生命中一切的喜与悲，束缚与自由都是由本能及相关环境影响的善与恶而生，由懂得爱而挣脱束缚，走向自由！

曾经的很多年前，害怕和纠结的东西太多太多，死亡、疾病、爱情，事业等等。从认识加拿大的朋友叶毓政开始，我们在一起讨论东西方文化的感受和差异，思想和思维的差异，理解的差异。谈论对爱、对性、对死亡和信仰的理解，对孩子教育等各方面的知识和信息。我的思想越来越打开了越来越懂得了其爱是让对方因自己而喜悦和快乐，因自己轻松，自由和愉悦；懂得了用行动为对方创造快乐而不只是思想的挂念和关心；懂得了只有纯净真诚的爱才能让事业，爱情，婚姻，朋友相处的更自由，幸福和恒久；懂得了有其爱生活会充满无限的美丽和浪漫！

美丽的心灵之窗好像被慢慢打开懂得了其爱，让自己过度的虚伪，嫉妒，贪婪，自卑，心胸小的性格习惯被慢慢的改变了，随着心态的成熟，心灵越来越轻松自由了，纠结的痛苦越来越小了，生活中阳光的一面越来越多了，越来越注重在活自己，活当下的基础上做自己喜欢的事业和传播美好的理念。
