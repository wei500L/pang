# 关于孩子

关于孩子，首先尊重他，希望他活出他的个性，过他热爱的生活。

养育孩子是因为喜欢，而不是其他目的，同时感谢孩子为我们带来的快乐，把他养大成人，教育他怎么面对生命和生活，怎样个性、自由地活自己，体现生命的价值和意义；怎样靠自己的智慧，能力，潜能创造生活，主宰生活，乐观地计划人生，分享自然和生命的美好。让孩子知道父母的事业和财富与孩子无关。在这个问题上我已实现完成了自己的责任和使命，孩子未来的路由他自己决定，我对孩子没什么要求，只有祝福和朋友般幸福地相处，所以自己没什么负担，更不给孩子带来负担，把自由，尊严和快乐自然传递给孩子。即便是在事业上帮助孩子，也是在有限的度以内，否则会伤害他的智慧和价值。

我们认知孩子属于社会，属于他自己，而非父母的私有，他有完整的人格和权力，父母从养育孩子的过程中分享快乐，而不是让孩子成为自己防老养老的工具，父母有养育的权力但绝对不能有占有的权力，我们知道了尊重孩子就会轻松自然的对待对孩子的教育方向和方式。

父母应该教育孩子怎样对待生命，让生命活得更自由和幸福，体现个性，能更好的展示性格中最好的方面，还有诚实做人、做事的道理，培养教育孩子生存和创造的思想和能力，充分挖掘孩子的潜能和智慧，让孩子具备正常的想像力和创造力。让孩子拥有应有的锻炼和成长的过程，让孩子成年后能轻松、快乐主宰他自己的人生。

孩子成年后父母自然放手，让他们过自己的生活，靠他们自己
