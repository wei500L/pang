# 关于践行我们的梦想

这条路注定会很漫长，正视自身的劣根性，所有的一切从自己可以主宰的环境践行，寻道，悟道，讲道，传道，让精神有踏踏实实的寄托，…专注自己，专注当下，专注事业生活的品质和结果，不影响快乐的基础上寻求优秀的文化基因。相信今年我们一定能乐观，愉快的践行我们的梦想…

传统的文化让我的心灵，沉淀了太多肮脏没用的东西，束缚着我的思想，既痛苦又无奈…我努力寻求让心灵自由的文化基因，让自己能个性，自由，乐观的分享生命的美好。我希望更多人和我一样一陪同行。

我自己知道，梦想很简单。如果让更多人明白，太难，需要很长的路要走，所以，先做好自己，做好力所能及的，美好的过程最重要，希望我们快乐的同时更能创造一片健康的乐土。

时刻记着，思路简单，让文化信仰条理简单，目标清晰，个性，自由，尊严，尊重。明世理，活自己，心灵高贵，思想自由，活在当下。只有优秀的理念才会结出更加幸福的果实。
