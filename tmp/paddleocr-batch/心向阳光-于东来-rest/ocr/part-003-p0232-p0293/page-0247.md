# 关于从奴性到个性

在现在世界的范围内，很多国家和区域的人，因明白遵循大自然进化的规律，能正视生命和情感的其谛！乐观，坦诚，自信的在大自然的怀抱中分享着宝贵的生命时光和生命阅历！

而我们的思想和心态如果不从狭隘自私的怪圈中解脱出来，再光明的未来也会渐渐远去，离自己更加遥远！愚昧的人，对于自己的有些做法，明知结果不好却偏要固执前行！伤害自己也伤害他人，真心对人好是为他人分担，让自己从狭隘痛苦中走出来，用善良的爱带给更多人温暖和阳光！让他人轻松自由的分享生活，祝福他人幸福快乐，这样他人才能给你同样的回报！

现在很多人受大环境的影响，心里只有金钱、功名和私利，不追求真理、信念和信仰，不知道活自己，活当下，分享人生美好的时光，这样真的是浪费生命。对待人生，无论做人做事，必须投入热情，这样即充实又幸福，这样的人生是分享生命的美好。不走捷径扎扎实实的做人做事，乐观对待生命，分享生活，这样的人生过程会很强大和美好。很多人做事一是为了钱，二是让别人看。学会让自己分享，让内心喜欢才是正道，个性又善良的人自然会赢得更多尊重。

期待有更多专业的机构和组织，能从中国的历史文化信仰形成及进化过程中，从历代中国人们所表现出来的个性、特点和所形成的环境特征，深度研究分析出长久形成的优点和缺点。然后和世界其它优秀文化信仰对比、学习，从而提升我们东方文化的品位和价值，促进我们民族及个人整体素质的提升！
