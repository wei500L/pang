# 关于我对人性的理解

我为什么向往、个性、自由、乐观，自信的生活理念。因我懂得过度的嫉妒、贪婪、虚伪、自私，心胸狭隘在生活中让自己多么痛苦，甚至有时让自己自卑，蜿蜒得无地自容。

我讨厌依附在人们身上的阿Q精神，我追求让自己阳光，坦诚的面对生命，我努力寻求这种理念和信仰，我的生活从此多了阳光和希望。而工作爱惜一样，没有倾心融入不可能品味到其中至纯的快乐，浪漫和幸福！

现实生活中，自己像另类，可我知道尽力个性的活自己，活当下会让生命多些轻松和激情，我希望所有的人们都能快乐的生活，可太多人并不懂得创造和分享美好的生活。只看到的一切有利于自己的东西会让生活失去色彩和阳光！

鲁迅希望从他的文章中抨击和启迪人们要看到糟粕的效性文化对人们的伤害，人们只是说：“社会就是这样，我们有什么办法。”人们只知道工作是为了生存或某种目的，这样太苦悲。在文化发达的国家，工作和生活一样开心，一样有激情！

人的生命是有限的，人生是否有价值就看我们是否懂得珍爱和分享，懂得创造生活，创造浪漫，创造美好！

都追求那份纯净的爱，可我们的心又是那么贪婪！真心付出，自然会得到属于自己的梦。

讲道理在生活中是那么苍白，可不明白道理的生活又显得那么无奈和迷茫。

环境造就人，多接受正面的熏陶，优秀的信念会让生命更淡定和坦然。想起了自己年轻时生活道理和信仰的缺失！
