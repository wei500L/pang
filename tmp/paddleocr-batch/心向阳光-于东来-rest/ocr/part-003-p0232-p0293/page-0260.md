# 管理篇

## 细节管理

各部门伏下心认认真真把自己所分管的职责标准做精做细，向着公司制定的精细化、专业化方向进步。强化喜欢学习提升商品专业知识的能力，把商品功能做的更强、品类更清晰，质量更优，价格更实在合理。把经营做到简单、实在！杜绝为提升业绩做一些为吸引人气，拉动消费的营销方法，做到踏实做事做人！

公司要在战略层面要制定清晰有效的政策标准，激励更多的人向专业化和优秀品德的方向发展！不热爱自己的工作和事业，是不可能成就专业能力的实现，更不可能感受工作的幸福，追求精细化的文化信仰真是太重要了。希望这种文化能造就更多的专业人才，造福更多的人！

## 服务管理（一）
